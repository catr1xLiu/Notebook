
## Definition

Using the language in [[3.2- Powersets]], a **function** from a set $A$ to a set $B$ is a relation $F \in A \times B$ such that every $a \in A$ appears as the first component of **exactly one** ordered pair in $F$. 
For example, given $A={1,2,3}, B={x, y}$, $F=\{(1,x), (2, x), (3,y)\}$ is a function $F: A \rightarrow B$.
- **Every $a \in A$ must be defined**. Given $A={1,2,3}$ $F=\{ (1,x)  \}$

## Hint 
Always think functions as mapping from one set to another. It is not a procedure in [[CE1A/ECE150/4 - Functions/notes|C++]]. It does not perform any operation, it is just a relationship that **exists**.
