
## Definition: Event

First, we define a sample space $S$, which is the set of all elementary events.
- We do a countable amount of experiments. (e.g. toss a coin twice)
- Collect all possible outcomes. (e.g. $(TT, TH, HT, HH)$)
Event $E \subseteq S$  is the combination of one or more elementary events happening.

Events $A, B \subseteq S$ are **mutually exclusive** if $A \cap B = \emptyset$
 
## Definition: Probably Distribution

A function $\Pr$ can be used to describe the probably distribution for sampling space $S$ $$
\Pr: \mathcal{P}(S) \rightarrow R
$$
- $\forall A \subseteq S: \quad \Pr(A) \geq 0$
- $\Pr(S) = 1$
- For two mutually exclusive events $A, B$: $A \cap B = \emptyset \implies \Pr(A) + \Pr(B) = \Pr(A \cup B)$

#### Discreteness 

A probability distribution is **discrete** if $S$ is **finite**. *We only consider finite $S$ in this course.* 

#### Uniform
A probability distribution is **uniform** if: $$
\forall \text{ elementry events }e_1, e_2, ... \in S: \quad P_n(e_i) = P_n(e_j)
$$
This implies that: $$
\forall A \subseteq S: \quad \Pr(A) = \frac{|A|}{|B|}
$$

## Hint: Relevant Claims

For event space $S$ that $|S| = n$ and probability distribution $P_n: \mathcal{P}(S) \rightarrow R$: 

#### Null Event
**Claim:**
$$
\Pr(\emptyset) = 0
$$
#### Probability Magnitude
**Claim:**
$$
\forall A, B \subseteq S:\quad A \subseteq B \implies \Pr(A) \leq \Pr(B)
$$

#### Combining
**Claim:**
$$
\Pr(A \cup B) = \Pr(A) + \Pr(B) - \Pr(A \cap B)
$$


## Definition: Conditional Probability

We denote the probability that $A$ happens given that $B$ already happened as: $$
\Pr(A\mid B) = \frac{\Pr(A \cap B)}{P(B)} \quad (\Pr(B)\neq 0)
$$
## Definition: Independence

Two events, $A$ and $B$ are said to be **independent** if: 
$$ \Pr(A \mid B) = \Pr(A) \quad \iff \quad \Pr(A \cap B) = \Pr(A) \ \Pr(B) $$

Given a large sack of $d \in \mathbb{Z}^+$ kinds of fruits, with each fruit having approximately the same number. What is the probability that grabbing 2 fruits yields two different kinds of fruit. 

**Solution**:

 Let the event of grabbing the $i$-th kind of fruit ($0 < i < d$) at the **first** grab be $A_i$, grabbing the $i$-th kind of fruit ($0 < i < d$) in the **second** grab be $B_i$. We have: $$
\forall i \in [0,d): \quad \Pr(\overline{B_i}|A_i) = \Pr(\overline{B_i}) = \frac{d-1}{d}
$$
Since no matter what kind of fruit we choose in the first grab, the probability of of getting a different fruit in the next grab is $\frac{d-1}{d}$, the probability of getting two different kinds of fruit is $\frac{d-1}{d}$

#### Independent Example

- Let $\set{W_1, W_2, W_3}$ be the events that door 1, 2, 3 have prize.
- Let $\set{S_1, S_2, S_3}$ be the events that door 1, 2, 3 is selected by the contestant.
- Let $\set{R_1, R_2, R_3}$ be the events that door 1, 2, 3 is revealed by the host.

Assume without loss of generality, that the contestant selected door 1, and that the host revealed door 2.

We need to compare $\Pr(W_1 \mid (S_1 \cap R_2))$ and $\Pr(W_3| (S_1 \cap R_2))$. Write: 
$$ \begin{aligned}
\Pr(W_1 \mid (S_1 \cap R_2)) =& \frac{\Pr(W_1 \cap S_1 \cap R_2)}{\Pr(S_1 \cap R_2)} \\
=& \frac{\Pr(W_1) \times \Pr(S_1\mid W_1) \times \boxed{\Pr(R_2 \mid (W_1 \cap S_1))}}{\Pr(W_1 \cap S_1 \cap R_2) + \Pr(W_2 \cap S_1 \cap R_2) + \Pr(W_3 \cap S_1 \cap R_2)} \\ 
=& \frac
{\frac{1}{3} \times \frac{1}{3} \times \boxed{\frac{1}{2}}}
{(\frac{1}{3} \times \frac{1}{3} \times \frac{1}{2}) + 0 + (\frac{1}{3} \times \frac{1}{3} \times 1)} \\ 
= & \boxed{\frac{1}{3}}
\\ 
\\
\Pr(W_3 \mid (S_1 \cap R_2)) = & \frac{\Pr(W_3 \cap S_1 \cap R_2)}{\Pr(S_1 \cap R_2)} \\
=& \frac{\Pr(W_3) \times \Pr(S_1\mid W_3) \times \boxed{\Pr(R_2 \mid (W_3 \cap S_1))}}{\Pr(W_1 \cap S_1 \cap R_2) + \Pr(W_2 \cap S_1 \cap R_2) + \Pr(W_3 \cap S_1 \cap R_2)} \\ 
=& \frac
{\frac{1}{3} \times \frac{1}{3} \times \boxed{1}}
{(\frac{1}{3} \times \frac{1}{3} \times \frac{1}{2}) + 0 + (\frac{1}{3} \times \frac{1}{3} \times 1)} \\ 
= & \boxed{\frac{2}{3}}
\end{aligned} $$

Using python code, we can verify:

```python
from random import randint, choice

def sample() -> tuple[bool, bool]:
    # Returns: One random sample in the boolean form
    # (Keep Door Wins, Swap Door Wins), either [T,F] or [F, T]
    prize: int = randint(1, 3)
    selection: int = randint(1, 3)

    POOL: set = {1, 2, 3}

    reveal: int = choice(list(POOL - {prize, selection}))

    swap: int = (POOL - {reveal, selection}).pop()

    return selection == prize, swap == prize


keep_door_wins, swap_door_wins = 0, 0
SAMPLE_SIZE = int(1e6)

for i in range(SAMPLE_SIZE):
    k, s = sample()
    keep_door_wins += int(k)
    swap_door_wins += int(s)

print(keep_door_wins / SAMPLE_SIZE, swap_door_wins / SAMPLE_SIZE)

```
