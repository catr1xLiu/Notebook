
> [!quote] Definition
> ## Function

Using the language in [[3.2- Powersets]], a <u><strong style="color:#dab1da">function</strong></u> from a set $A$ to a set $B$ is a relation $F \in A \times B$ such that every $a \in A$ appears as the first component of **exactly one** ordered pair in $F$.
For example, given $A=\{1,2,3\}, B=\{x, y\}$, $F=\{(1,x), (2, x), (3,y)\}$ is a function $F: A \rightarrow B$.

> [!hint] Hint
> ## Functions as Mappings

Always think functions as mapping from one set to another. It is not a procedure in [[CE1A/ECE150/4 - Functions/notes|C++]]. It does not perform any operation, it is just a relationship that **exists**.

> [!quote] Definition
> ## Domain, Co-domain and Range

#### <u>Domain</u>
is the set of inputs for which the function is *defined*. The function must be defined for each and every element in the domain.

#### <u>Codomain</u>
is the set to which the function's output is *bounded*, not all elements in the codomain is reached.

#### <u>Range</u>
is the set of output of the function for which at least one input in the domain corresponds to.
