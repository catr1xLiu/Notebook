Abstract

Aging profoundly shapes the way people move. Reduced walking velocity, shortened stride length, compensatory hip strategies, and increased double-support time are among the biomechanical hallmarks of an aging gait. Despite the clinical importance of these kinematic signatures, most generative motion models treat age as an afterthought or ignore it entirely.

We present a two-component framework that bridges gait analysis and motion synthesis. A Spatio-Temporal Graph Convolutional Network (ST-GCN) is trained on three age groups (Young, Mid-age, Elderly) to extract a latent age embedding zage from skeletal sequences. This embedding is then injected into a text-conditioned diffusion model via cross-attention, enabling age-conditioned motion generation from natural-language prompts.

Our data pipeline transforms clinical C3D motion-capture recordings from the Van Criekinge dataset (ages 21–86) into the HumanML3D representation, carefully preserving age-related kinematic cues while eliminating common SMPL fitting artifacts such as mesh inflation and crouch-walking. The resulting infrastructure provides a scalable foundation for age-representative motion synthesis with applications in rehabilitation monitoring, aging-in-place assistance, and human–robot interaction.

Motivation

Gait analysis has long served as a non-invasive window into physical health. Walking speed alone predicts survival in older adults (Studenski et al., 2011), and systematic changes in hip extension, step width, and cadence are well-documented correlates of biological age (Boyer et al., 2023). Yet existing text-to-motion generative models lack the resolution to reproduce these subtle but clinically meaningful differences.

A central question motivates this work: can data-driven models learn to capture age-related biomechanical variation from real clinical recordings, and generate motions that faithfully reflect those differences?

Answering this requires solving two sub-problems in tandem:

  • Recognition — reliably inferring age group from a skeletal motion sequence.
  • Generation — conditioning a high-capacity diffusion model on that age signal to produce biomechanically plausible, age-appropriate motion.

Early experiments with a continuous age scalar (normalized to [0,1]) injected into the diffusion model produced only speed variation: posture and gait style remained indistinguishable across age groups. This failure guided our pivot toward a discrete latent embedding learned by a dedicated graph network, which captures richer structural information about inter-joint dynamics.

Data Pipeline

Transforming raw optical marker data into a format suitable for diffusion model training requires a carefully designed multi-stage pipeline. Each stage introduces its own representation trade-offs and potential failure modes.

Stage Representation Shape Key Operation
0 Raw C3D marker trajectories (T, ~60, 3) @ 100 Hz Vicon optical capture
1 SMPL parametric body model θ: (T,72), β: (10,), t: (T,3) VPoser-based marker fitting with artifact correction
2 HumanML3D skeleton (22 joints) (T20Hz, 22, 3) Coordinate frame change + temporal resampling (100→20 Hz)
3 HumanML3D feature vector (T−1, 263) Root trajectory + joint positions/velocities/rotations + foot contacts

The pipeline achieves an overall 85× compression from raw marker data to training features while preserving clinically relevant kinematic cues. Motion is represented in a body-centered coordinate frame, making the learned representations invariant to global position and enabling better generalization across environments.

A key implementation fix involved correcting a coordinate transformation bug in the C3D-to-SMPL stage (Vicon Z-up → body-centered Y-up), which previously introduced systematic lean and descent artifacts that were incorrectly filtered as noise.

SMPL Fitting & Artifact Correction

Fitting SMPL to optical marker data introduces systematic artifacts that, if uncorrected, corrupt the age-related kinematic signal. We identify and address three main failure modes:

  • Mesh inflation — over-estimated body shape parameters (β) causing unrealistic body proportions.
  • Crouch-walking — spurious knee flexion introduced by marker occlusion or initialization errors.
  • VPoser-corrected output — applying a learned pose prior during fitting regularizes the solution and eliminates anatomically implausible poses.

Approach

1. Age Classification (ST-GCN)

A Spatio-Temporal Graph Convolutional Network operates directly on the 22-joint skeletal graph, learning to discriminate between three age groups: Young (<30), Mid-age (30–60), and Elderly (>60).

Rather than discarding the classifier after training, we extract its latent representation zage as a compact, biomechanically-grounded age embedding. This avoids the failure mode of continuous age scalars, which lack the representational capacity to encode inter-joint coordination patterns.

2. Age-Conditioned Diffusion

The diffusion model follows the Human Motion Diffusion Model (MDM) architecture. The forward diffusion process is:

q(xt | x0) = 𝒩(xt; √ᾱt x0, (1 − ᾱt) I)

where xt ∈ ℝB × T × 263 is the noisy motion sequence. Age conditioning is injected by concatenating zage with the text embedding in the cross-attention layers of the denoising transformer, enabling joint text-and-age control over generation.

The training objective minimizes the simple noise-prediction loss:

ℒ = 𝔼x₀, ε, t [ ‖ε − εθ(xt, t, ztext, zage)‖² ]

ST-GCN Network Architecture. The network processes skeletal sequences through three stages of spatio-temporal graph convolutions (ST-GCN blocks). Each stage applies spatial convolutions across the joint graph and temporal convolutions along the motion sequence. The perception layers aggregate features globally, and the classification head (yellow) maps the learned latent age embedding zage to discrete age group predictions (Young, Mid-age, Elderly).

Two-Phase Architecture. Phase 1 (Training): A frozen ST-GCN extracts the target age embedding zage from a real motion clip. A lightweight MLP g(a) is trained to reproduce this embedding from the scalar age alone, supervised by an MSE loss LMSE. Simultaneously, the frozen MDM is optimized with the diffusion loss Ldiff conditioned on the text prompt and zage via cross-attention. Phase 2 (Inference): No input motion is required. The text prompt is encoded by a frozen CLIP encoder, and the scalar age is mapped to zage by the trained MLP. Both embeddings are combined through cross-attention in the frozen MDM to generate the output motion sequence x0.

Discussion & Future Work

Our pipeline reliably transforms clinical motion-capture recordings into a representation suitable for diffusion model training, while retaining age-discriminative kinematic cues. The ST-GCN classifier successfully separates age groups, and the age embedding shows promise as a conditioning signal for generation.

Current limitations:

  • Dataset balance — older adult cohorts are systematically underrepresented in publicly available motion datasets, limiting the diversity of elderly gait patterns the model can learn from.
  • Protocol variability — differences in clinical capture protocols (marker placement, walking track length, instruction standardization) introduce confounds that constrain cross-dataset generalization.
  • Evaluation metrics — standard motion generation metrics (FID, diversity) are not designed to measure biomechanical aging fidelity; new evaluation frameworks are needed.

Planned extensions:

  • Biomechanically-informed generation with joint torque estimation as an auxiliary signal.
  • Longitudinal data integration for personalized functional trajectory modeling.
  • Transition from discrete age groups to a continuous age manifold using LoRA adapter interpolation.
