## Brand-neutralization measures

This repository does not distribute Google, Google DeepMind, Stanford, or
Stanford Digital Economy Lab logos. The derived class removes the upstream
institution-specific logo path, address, copyright notice, internal/confidential
wording, report identifier, and related output. The corresponding legacy options
raise an explanatory `\ClassError`; the derived class contains no implementation
that produces the removed branded material.

Plain-text names and links are used only as reasonably necessary to identify and
credit upstream sources. Nothing in this repository should be interpreted as a
claim of partnership, sponsorship, official status, or endorsement.

Generic logo slots are provided only for marks that a user owns or is authorized
to use. Users are responsible for rights in content and assets they add.
