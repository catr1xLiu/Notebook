# Proposal Skripsi Template

IEEEtran-based thesis proposal template for D-IV Komputasi Statistik at Politeknik Statistika STIS (Indonesian).

## Description

This template is designed for writing thesis proposals at the D-IV Komputasi Statistik program, Politeknik Statistika STIS. It follows the IEEE format guidelines adapted for Indonesian academic requirements.

## Files

- `Proposal.tex` - Main document file (edit this with your content)
- `Proposal.bib` - Bibliography file in BibTeX format
- `IEEEtran_ID.cls` - Modified IEEEtran document class
- `IEEEtran.bst` - Bibliography style file
- `litmap.png` - Example literature map figure
- `figure.png` - Example figure

## Usage

1. Edit `Proposal.tex` with your proposal content
2. Add your references to `Proposal.bib`
3. Compile with `latexmk -pdf Proposal.tex`

## Sections

The template includes guidance for:
- Latar Belakang (Background)
- Tujuan Penelitian (Research Objectives)
- Penelitian Terkait (Related Work)
- Metode Penelitian (Research Methodology)
- Rancangan Jadwal Penelitian (Research Schedule)
- Format Halaman (Page Format)
- Format Penulisan (Writing Format)
- Format Referensi (Reference Format)
