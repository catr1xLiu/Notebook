\textbf{Data pipeline.}
The dataset used in this study~\cite{vancriekinge2023dataset} provides full-body motion capture of healthy adults and stroke survivors spanning the adult lifespan. However, the clinical marker set and data format are incompatible with modern representations used for model training~\cite{guo2022generating}. Traditional methods fail due to "mesh inflation" artifacts. To address this, we developed a pipeline using VPoser latent-prior optimization~\cite{mahmood2019amass} to convert the data into valid human bodies, and then into a machine-learnable graph format through model fitting~\cite{mahmood2019amass,loper2015smpl}, with noise removal and temporal smoothing to preserve motion quality.


\textbf{Age classification.}
We train an ST-GCN~\cite{yan2018stgcn} to regress subject age from processed motion graphs. The penultimate layer of the network is a latent vector that encapsulates the biomechanical signatures of aging (e.g., velocity variance, joint motion range), denoted as $z_{age}$. Consistent age-group classification indicates that kinematic signatures are successfully extracted from the motion.


\textbf{Age-conditioned generation.}

We introduce a latent-conditioned motion diffusion model. The age-specific latent vector $z_{age}$ is reproduced using an MLP and then injected into the attention layer of the pre-trained MDM~\cite{tevet2023human}. This allows "age" to be interpreted as a continuous style token, enabling fine-grained control over biological age in generated motion.
