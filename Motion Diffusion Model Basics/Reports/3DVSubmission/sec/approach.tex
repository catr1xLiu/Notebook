\textbf{Data Pipeline.}
The dataset used in this study~\cite{vancriekinge2023dataset} provides full-body motion capture of healthy adults and stroke survivors spanning the entire adult lifespan. However, the clinical marker set and data format are incompatible with the modern representation for model training~\cite{guo2022generating}. Traditional methods fail fatally due to "mesh inflation" artifacts. To address this, a pipeline using VPoser latent-prior optimization~\cite{mahmood2019amass} was developed to convert data into valid human bodies, and then into a machine-learnable graph format through model fitting~\cite{mahmood2019amass,loper2015smpl}, with noise removal and temporal smoothing to preserve motion quality.


\textbf{Age Classification.}
We train an ST-GCN~\cite{yan2018stgcn} to regress subject age from processed motion graphs. The penultimate layer of the network is a latent vector that encapsulates the biomechanical signatures of aging (e.g\. velocity variance, joint motion range), denoted as $z_{age}$. Consistent age group classification justifies that kinematics signatures are successfully extracted from the motion.


\textbf{Age-Conditioned Generation.}

We introduce a Latent-Conditioned Motion Diffusion Model. The age-specific latent vector $z_{age}$ is reproduced using an MLP, then injected into the attention layer of the pre-trained MDM~\cite{tevet2023human}. This allows "Age" to be interpreted as a continuous style token, enabling fine-grained control over the biological age in generated motion.
