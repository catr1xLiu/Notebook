# Week 2 — Notes

This folder is the role model template for weekly reports. Follow these rules when creating new Week folders:

- Keep a single Typst file named `weekN report.typ` as the primary source.
- Place any images referenced by the report in this folder (relative paths in Typst).
- If helper scripts are required (Python/Bash), add them here and document `usage` in this README.

Files in this folder:
- `week2 report.typ` — primary Typst source (use as tone & structure example).
- `Drawing1.svg`, `Drawing3.svg`, `Drawing 1.16.svg` — figures referenced by the report.

When attaching assets from this folder in other reports, always run `ls -l WeeklyReports/Week2/` to capture exact filenames and sizes.
