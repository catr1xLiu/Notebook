> [!example] Question 253 · Jane Street
> ## Trader Intern Interview

What is the set of numbers between 2 and 30, where no two numbers share a common factor greater than 1 (i.e., the set is pairwise coprime), that gives the maximum possible sum? Using the same rules, what is the highest possible number you can have in a set of 1000?

[Source](https://www.thewallstreetquants.com/ebook#p=254)

> [!success]- Solution (Click to expand)
> Let the required set be a subset $S$ of $\{2,3,\dots,n\}$ such that any two distinct elements of $S$ are relatively prime; that is, for all distinct $a,b \in S$,
> $$
> \gcd(a,b)=1.
> $$
> We seek a set with maximum possible sum.
>
> ## Key observation
>
> If two numbers are both divisible by the same prime $p$, then their gcd is at least $p$, which is forbidden. Thus:
>
> - for each prime $p$, at most one chosen number may be divisible by $p$.
>
> So the problem is one of assigning each available prime to at most one number that uses it, choosing those numbers to maximize the total sum.
>
> ## Primes with no useful multiple in range
>
> For $n=30$, consider a prime $p$ with $15<p\le 30$: namely $17,19,23,29$. The smallest multiple of $p$ other than $p$ itself is $2p>30$, so no composite number in $\{2,\dots,30\}$ can use these primes at all. Consequently including $17,19,23,29$ costs nothing — no other candidate competes for these prime slots — so an optimal set always contains all four of them.
>
> ## Primes with a genuine trade-off
>
> The remaining primes up to $30$, namely $2,3,5,7,11,13$, each satisfy $p\le 15$, so multiples of $p$ other than $p$ itself do lie in range. For these, using the prime itself competes against using some composite built from it.
>
> Compare the options directly:
>
> - **Prime $5$:** the pure power $25=5^2$ uses only the "slot" for $5$ and is worth $25$, versus $5$ alone. Taking $25$ instead of $5$ gains $20$ for free.
> - **Prime $3$:** the pure power $27=3^3$ likewise uses only the slot for $3$, worth $27$ versus $3$. Taking $27$ instead of $3$ gains $24$.
> - **Primes $2$ and $7$ together:** pairing them as $28=2^2\cdot 7$ uses both slots at once and is worth $28$, versus $2+7=9$ if used separately, or versus the best single-slot alternative for $2$ alone ($16$) plus $7$ alone ($23$ combined). Since $28>23$, pairing wins: taking $28$ instead of using $2$ and $7$ separately gains $19$.
> - **Primes $11$ and $13$:** the only composites available are $22=2\cdot 11$ and $26=2\cdot 13$, both of which also consume the slot for $2$. Using either would force giving up $28$ (worth $28$ for the slots $2,7$ together) in favor of, say, $22$ plus $7$ alone $=29$ — far worse than $28+11=39$. So $11$ and $13$ are best left as themselves, with no composite improving on them.
>
> Also check that no larger grouping of small primes helps: for instance $30=2\cdot3\cdot5$ ties up the slots for $2,3,5$ simultaneously but is worth only $30$, versus $28+27+25=80$ for those same slots (plus $7$, already included in $28$) — vastly worse. So consolidating multiple small primes into one composite is never beneficial here; the best allocation keeps $3$ and $5$ as pure prime powers and pairs only $2$ with $7$.
>
> ## The optimal set for $n=30$
>
> Combining the forced primes $17,19,23,29$ with the best use of the small-prime slots — $11,13$ kept as themselves, and $25,27,28$ replacing $5,3,\{2,7\}$ respectively — gives the set
> $$
> \{11,13,17,19,23,25,27,28,29\}.
> $$
> These nine numbers are pairwise coprime: $25=5^2$, $27=3^3$, $28=2^2\cdot 7$, and $11,13,17,19,23,29$ are distinct primes not dividing any of the others.
>
> Their sum is
> $$
> 11+13+17+19+23+25+27+28+29=192.
> $$
>
> No other pairwise-coprime subset of $\{2,\dots,30\}$ achieves a larger sum: the four large primes are compulsory, and for each of the small-prime slots the comparisons above show the stated choice is at least as good as any alternative use of that slot.
>
> ---
>
> ## General case: largest possible size of such a set in $\{2,3,\dots,1000\}$
>
> Now the question changes from maximum sum to maximum possible number of elements.
>
> To maximize the number of elements, note again that no two chosen numbers may share a prime factor. Each chosen number must therefore use a set of primes disjoint from all others.
>
> Every number $\ge 2$ has at least one prime divisor. Since distinct chosen numbers cannot share a prime divisor, each chosen number must be assigned a different prime.
>
> Therefore the number of chosen elements is at most the number of primes $\le 1000$.
>
> This bound is achievable by taking all primes $\le 1000$, since any two distinct primes are relatively prime.
>
> Hence the maximum possible size is exactly
> $$
> \pi(1000),
> $$
> where $\pi(x)$ is the number of primes up to $x$.
>
> It is known that
> $$
> \pi(1000)=168.
> $$
>
> So the largest possible number of elements in such a set from $\{2,3,\dots,1000\}$ is $168$.
>
> ## Final answers
>
> - For the numbers between $2$ and $30$, a maximum-sum set is $\{11,13,17,19,23,25,27,28,29\}$, with maximum sum $192$.
> - Under the same pairwise-coprime rule, the largest possible size of a subset of $\{2,3,\dots,1000\}$ is $168$.
