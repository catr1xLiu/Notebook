> [!example] Question 617 · Jane Street
> ## Assistant Trader Interview

If I roll two dice, what is the probability that the second die shows a higher number than the first?

[Source](https://www.thewallstreetquants.com/ebook#p=618)

> [!success]- Solution (Click to expand)
> Let the first die show $X$ and the second die show $Y$. Each die is fair, so there are
>
> $$6 \times 6 = 36$$
>
> equally likely ordered outcomes $(X,Y)$.
>
> We want the probability that the second die is higher than the first, that is,
>
> $$P(Y > X).$$
>
> Count the favorable outcomes:
>
> - If $X=1$, then $Y$ can be $2,3,4,5,6$: $5$ outcomes.
> - If $X=2$, then $Y$ can be $3,4,5,6$: $4$ outcomes.
> - If $X=3$, then $Y$ can be $4,5,6$: $3$ outcomes.
> - If $X=4$, then $Y$ can be $5,6$: $2$ outcomes.
> - If $X=5$, then $Y$ can be $6$: $1$ outcome.
> - If $X=6$, then there are $0$ outcomes.
>
> Thus the total number of favorable outcomes is
>
> $$5+4+3+2+1=15.$$
>
> Therefore,
>
> $$P(Y>X)=\frac{15}{36}=\frac{5}{12}.$$
>
> So the probability that the second die is higher than the first is
>
> $$\boxed{\frac{5}{12}}.$$
