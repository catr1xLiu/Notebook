> ## Quantitative Researcher Interview

Write a program in a language of your choice that has a method to store name-sequence pairs (such as assigning the name 'jump' to the sequence 'ABC'), and another method that, given a sequence of characters as input, prints all names associated with that sequence.

> For the programming task, the goal is to support two operations:
>
> 1. store a pair consisting of a name and a character sequence,
> 2. given a sequence, print all names associated with it.
>
> The natural data structure is a map from sequence to a list of names. Then:
>
> - to store a pair $(\text{name}, \text{sequence})$, append the name to the list at key $\text{sequence}$,
> - to query a sequence, print the list stored at that key.
>
> ## Approach
>
> Use a hash map:
> - key: a sequence such as `"ABC"`,
> - value: a list of names associated with that sequence.
>
> This gives:
> - insertion in expected $O(1)$ time,
> - lookup in expected $O(1)$ time.
>
> ## Example solution in Python
>
> ```python
> class NameSequenceStore:
>     def __init__(self):
>         self.sequence_to_names = {}
>
>     def add_pair(self, name, sequence):
>         if sequence not in self.sequence_to_names:
>             self.sequence_to_names[sequence] = []
>         self.sequence_to_names[sequence].append(name)
>
>     def print_names_for_sequence(self, sequence):
>         if sequence in self.sequence_to_names:
>             for name in self.sequence_to_names[sequence]:
>                 print(name)
>         else:
>             print("No names found")
>
>
> # Example usage
> store = NameSequenceStore()
>
> store.add_pair("jump", "ABC")
> store.add_pair("run", "ABC")
> store.add_pair("slide", "XYZ")
>
> store.print_names_for_sequence("ABC")
> store.print_names_for_sequence("XYZ")
> store.print_names_for_sequence("DEF")
> ```
>
> ## How it works
>
> If the input pairs are:
>
> - `("jump", "ABC")`
> - `("run", "ABC")`
> - `("slide", "XYZ")`
>
> then the map becomes:
>
> ```python
> {
>     "ABC": ["jump", "run"],
>     "XYZ": ["slide"]
> }
> ```
>
> A query for `"ABC"` prints:
>
> ```python
> jump
> run
> ```
>
> A query for `"DEF"` prints:
>
> ```python
> No names found
> ```
>
> ## Complexity
>
> Let $k$ be the number of names stored for a given sequence.
>
> - `add_pair`: expected $O(1)$
> - `print_names_for_sequence`: expected $O(k)$, since all associated names must be printed
>
> ## Final answer
>
> Use a hash map from sequence to list of names. Store each $(\text{name}, \text{sequence})$ by appending the name to the list for that sequence, and answer queries by printing the list at the requested sequence. This is simple and efficient, with expected $O(1)$ insertion and expected $O(k)$ query time.
