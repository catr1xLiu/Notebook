> [!example] Question 665 · Jane Street
> ## Quant Trader Intern Interview

100 coins are flipped in a sequence. What six yes/no questions would you ask to maximize your chance of guessing the sequence?

[Source](https://www.thewallstreetquants.com/ebook#p=666)

> [!success]- Solution (Click to expand)
> To maximize the chance of identifying one exact outcome among all possible sequences of $100$ coin flips using only $6$ yes/no questions, the key observation is that $6$ yes/no questions can distinguish at most
>
> $$
> 2^6 = 64
> $$
>
> different possibilities.
>
> But the number of possible sequences of $100$ coin flips is
>
> $$
> 2^{100},
> $$
>
> which is vastly larger than $64$.
>
> Thus, no strategy can uniquely determine the sequence in all cases. The best possible approach is to use the $6$ questions to partition the set of all $2^{100}$ sequences into $64$ classes as evenly as possible, and then guess one representative sequence from the class identified by the answers. This maximizes the probability of success.
>
> ## Optimal strategy
>
> Interpret the $6$ yes/no answers as the binary representation of a number from $0$ to $63$. To do this, preassign each possible $100$-flip sequence to one of $64$ groups, each as equal in size as possible.
>
> Since
>
> $$
> \frac{2^{100}}{64} = 2^{94},
> $$
>
> we can partition the set of all sequences into exactly $64$ groups, each containing
>
> $$
> 2^{94}
> $$
>
> sequences.
>
> Then ask $6$ questions that determine which group the actual sequence belongs to.
>
> For example, if the groups are labeled by $6$-bit strings $b_1b_2b_3b_4b_5b_6$, ask:
>
> 1. Is the sequence in one of the groups whose first label bit is $1$?
> 2. Is the sequence in one of the groups whose second label bit is $1$?
> 3. Is the sequence in one of the groups whose third label bit is $1$?
> 4. Is the sequence in one of the groups whose fourth label bit is $1$?
> 5. Is the sequence in one of the groups whose fifth label bit is $1$?
> 6. Is the sequence in one of the groups whose sixth label bit is $1$?
>
> After the $6$ answers, you know exactly which of the $64$ groups contains the true sequence. Then guess a fixed representative sequence from that group.
>
> ## Probability of success
>
> Since each group has size $2^{94}$ and all $2^{100}$ sequences are equally likely, the probability that the true sequence equals your chosen representative is
>
> $$
> \frac{1}{2^{94}}.
> $$
>
> This is optimal, because after $6$ yes/no questions you can distinguish at most $64$ cases, so no strategy can achieve success probability greater than
>
> $$
> \frac{64}{2^{100}} = \frac{1}{2^{94}}.
> $$
>
> ## Final answer
>
> An optimal set of $6$ yes/no questions is any set that identifies which one of $64$ equal-sized preassigned classes the $100$-flip sequence belongs to. Concretely, label each possible sequence with a $6$-bit code and ask for the $6$ bits of that code via yes/no questions.
>
> This achieves the maximum possible probability of correctly guessing the exact sequence:
>
> $$
> \boxed{\frac{1}{2^{94}}}.
> $$
>
> So the best possible “$6$ questions” are not about individual flips, but about a balanced partition of all $2^{100}$ sequences into $64$ classes.
