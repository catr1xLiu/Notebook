> [!example] Question 41 · Jane Street
> ## Quantitative Researcher Interview

Build a tree data structure where each parent node can have any number of children. Then, given a quadratic polynomial and the value of y at an arbitrary x, determine the coefficient of the quadratic term.

[Source](https://www.thewallstreetquants.com/ebook#p=42)

> [!success]- Solution (Click to expand)
> ## 1. Tree in which a parent can have any number of children
>
> Such a tree is called a **general tree** or **$n$-ary tree**.
>
> ### Common node structure
> Each node stores:
> - a value,
> - a list of children.
>
> A typical representation is:
>
> ```text
> Node:
>     value
>     children = [child1, child2, child3, ...]
> ```
>
> ### Example
> If node $A$ has children $B, C, D$, and $B$ has children $E, F$, then:
>
> ```text
> A
> ├── B
> │   ├── E
> │   └── F
> ├── C
> └── D
> ```
>
> This can be stored as:
>
> ```python
> class Node:
>     def __init__(self, value):
>         self.value = value
>         self.children = []
>
> # Example construction
> A = Node("A")
> B = Node("B")
> C = Node("C")
> D = Node("D")
> E = Node("E")
> F = Node("F")
>
> A.children.extend([B, C, D])
> B.children.extend([E, F])
> ```
>
> Thus, the appropriate tree structure is one where each node contains a dynamic list of children.
>

> ## 2. Coefficients of a quadratic polynomial from known values
>
> Let the quadratic polynomial be
>
> $$
> y = ax^2 + bx + c.
> $$
>
> The coefficients are $a$, $b$, and $c$.
>
> To determine them, one needs the values of $y$ at **three distinct values** of $x$.
>
> Suppose the known points are
>
> $$
> (x_1, y_1), \quad (x_2, y_2), \quad (x_3, y_3).
> $$
>
> Then they satisfy
>
> $$
> a x_1^2 + b x_1 + c = y_1,
> $$
>
> $$
> a x_2^2 + b x_2 + c = y_2,
> $$
>
> $$
> a x_3^2 + b x_3 + c = y_3.
> $$
>
> This gives a system of three linear equations in the three unknowns $a$, $b$, and $c$:
>
> $$
> \begin{cases}
> a x_1^2 + b x_1 + c = y_1, \\
> a x_2^2 + b x_2 + c = y_2, \\
> a x_3^2 + b x_3 + c = y_3.
> \end{cases}
> $$
>
> Solving this system yields the coefficients.
>
> ### Matrix form
> The system can be written as
>
> $$
> \begin{bmatrix}
> x_1^2 & x_1 & 1 \\
> x_2^2 & x_2 & 1 \\
> x_3^2 & x_3 & 1
> \end{bmatrix}
> \begin{bmatrix}
> a \\ b \\ c
> \end{bmatrix}
> =
> \begin{bmatrix}
> y_1 \\ y_2 \\ y_3
> \end{bmatrix}.
> $$
>
> If the $x_i$ are distinct, this matrix is invertible, so the coefficients are uniquely determined.
>
> ### Conclusion
> - A tree where each parent may have any number of children is a **general tree** implemented by storing a list of children in each node.
> - A quadratic polynomial
>
> $$
> y = ax^2 + bx + c
> $$
>
> is determined by **three distinct points**, and the coefficients are found by solving the corresponding $3 \times 3$ linear system.
