> [!example] Question 661 · Jane Street
> ## Quant Trader Intern Interview

Given a phone number with one omitted digit, what is the minimum number of phone calls needed to guarantee reaching the correct number?

[Source](https://www.thewallstreetquants.com/ebook#p=662)

> [!success]- Solution (Click to expand)
> A phone number has one omitted digit, so there are $10$ possible completions: the missing digit could be any of $0,1,2,\dots,9$.
>
> To guarantee reaching the correct number, one may need to try every possible completion in the worst case. If the correct number happens to be the last one tried, then all $10$ calls are necessary.
>
> Therefore, the number of calls needed to guarantee reaching the correct number is
>
> $$10.$$
