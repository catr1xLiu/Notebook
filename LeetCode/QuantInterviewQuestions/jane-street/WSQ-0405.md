> [!example] Question 405 · Jane Street
> ## Trader Interview

In Linux, how can you find the total number of files in the current folder, including all subfolders?

[Source](https://www.thewallstreetquants.com/ebook#p=406)

> [!success]- Solution (Click to expand)
> To count all **regular files** in the current directory and all its subdirectories, use:
>
> ```bash
> find . -type f | wc -l
> ```
>
> ### Explanation
> - `find .` starts searching from the current directory.
> - `-type f` restricts the results to regular files only.
> - `wc -l` counts how many lines are returned, which equals the number of files.
>
> ### Final answer
> ```bash
> find . -type f | wc -l
> ```
