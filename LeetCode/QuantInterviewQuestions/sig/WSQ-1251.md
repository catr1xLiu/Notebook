> [!example] Question 1251 · SIG
> ## Technology Associate Interview

Write a function to traverse a binary search tree using both recursive and non-recursive methods.

[Source](https://www.thewallstreetquants.com/ebook#p=1252)

> [!success]- Solution (Click to expand)
> ## Binary Search Tree Traversal
>
> A binary search tree can be traversed in several standard orders. The most common are:
>
> - **Inorder**: left subtree $\to$ root $\to$ right subtree
> - **Preorder**: root $\to$ left subtree $\to$ right subtree
> - **Postorder**: left subtree $\to$ right subtree $\to$ root
>
> Below are recursive and non-recursive implementations. Since the tree is a binary search tree, **inorder traversal** visits the keys in sorted order.
>
> ## Node definition
>
> ```python
> class TreeNode:
>     def __init__(self, val):
>         self.val = val
>         self.left = None
>         self.right = None
> ```
>
> ---
>
> ## 1. Recursive traversal
>
> ### Inorder traversal
>
> ```python
> def inorder_recursive(root):
>     result = []
>
>     def dfs(node):
>         if not node:
>             return
>         dfs(node.left)
>         result.append(node.val)
>         dfs(node.right)
>
>     dfs(root)
>     return result
> ```
>
> ### Preorder traversal
>
> ```python
> def preorder_recursive(root):
>     result = []
>
>     def dfs(node):
>         if not node:
>             return
>         result.append(node.val)
>         dfs(node.left)
>         dfs(node.right)
>
>     dfs(root)
>     return result
> ```
>
> ### Postorder traversal
>
> ```python
> def postorder_recursive(root):
>     result = []
>
>     def dfs(node):
>         if not node:
>             return
>         dfs(node.left)
>         dfs(node.right)
>         result.append(node.val)
>
>     dfs(root)
>     return result
> ```
>
> ---
>
> ## 2. Non-recursive traversal
>
> ### Inorder traversal
>
> The idea is to simulate recursion with a stack. Repeatedly move left, pushing nodes onto the stack. When no further left child exists, pop, visit, and move right.
>
> ```python
> def inorder_iterative(root):
>     result = []
>     stack = []
>     curr = root
>
>     while curr or stack:
>         while curr:
>             stack.append(curr)
>             curr = curr.left
>
>         curr = stack.pop()
>         result.append(curr.val)
>         curr = curr.right
>
>     return result
> ```
>
> ### Preorder traversal
>
> Visit the current node first, then push the right child before the left child so that the left subtree is processed first.
>
> ```python
> def preorder_iterative(root):
>     if not root:
>         return []
>
>     result = []
>     stack = [root]
>
>     while stack:
>         node = stack.pop()
>         result.append(node.val)
>
>         if node.right:
>             stack.append(node.right)
>         if node.left:
>             stack.append(node.left)
>
>     return result
> ```
>
> ### Postorder traversal
>
> One common method is to use two stacks, or one stack with a pointer. The two-stack method is straightforward.
>
> ```python
> def postorder_iterative(root):
>     if not root:
>         return []
>
>     result = []
>     stack1 = [root]
>     stack2 = []
>
>     while stack1:
>         node = stack1.pop()
>         stack2.append(node)
>
>         if node.left:
>             stack1.append(node.left)
>         if node.right:
>             stack1.append(node.right)
>
>     while stack2:
>         result.append(stack2.pop().val)
>
>     return result
> ```
>

> ## Example
>
> ```python
> # Construct the BST
> #         4
> #       /   \
> #      2     6
> #     / \   / \
> #    1   3 5   7
>
> root = TreeNode(4)
> root.left = TreeNode(2)
> root.right = TreeNode(6)
> root.left.left = TreeNode(1)
> root.left.right = TreeNode(3)
> root.right.left = TreeNode(5)
> root.right.right = TreeNode(7)
>
> print(inorder_recursive(root))     # [1, 2, 3, 4, 5, 6, 7]
> print(inorder_iterative(root))     # [1, 2, 3, 4, 5, 6, 7]
>
> print(preorder_recursive(root))    # [4, 2, 1, 3, 6, 5, 7]
> print(preorder_iterative(root))    # [4, 2, 1, 3, 6, 5, 7]
>
> print(postorder_recursive(root))   # [1, 3, 2, 5, 7, 6, 4]
> print(postorder_iterative(root))   # [1, 3, 2, 5, 7, 6, 4]
> ```
>
> ## Complexity
>
> For all traversal methods:
>
> - Time complexity: $O(n)$, where $n$ is the number of nodes
> - Space complexity:
>   - Recursive: $O(h)$ due to the call stack
>   - Iterative: $O(h)$ for the explicit stack
>
> where $h$ is the height of the tree.
>
> ## Final answer
>
> A recursive traversal uses function calls to process the left and right subtrees, while a non-recursive traversal uses an explicit stack to simulate that process. The implementations above provide both recursive and iterative versions of inorder, preorder, and postorder traversal for a binary search tree.
