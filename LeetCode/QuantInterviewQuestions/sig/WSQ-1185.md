> [!example] Question 1185 · SIG
> ## Software Developer Interview

Given a CSV file where each row contains: person name, car name, miles driven since last fill-up (float), gallons filled at this fill-up (integer), and the fill-up date, write a program to calculate the miles per gallon (MPG) for each car a person has driven during a specific date range (inclusive). Implement a function GetRangeMPG(PersonName, StartDate, EndDate) that returns a list of objects containing (CarName, MPG), where MPG is calculated as total miles driven divided by total gallons filled within the date range.

[Source](https://www.thewallstreetquants.com/ebook#p=1186)

> [!success]- Solution (Click to expand)
> ```python
> from dataclasses import dataclass
> from typing import List, Dict
> import csv
> from collections import defaultdict
> from datetime import datetime
>
>
> @dataclass
> class CarMPG:
>     carName: str
>     mpg: float
>
>
> @dataclass
> class FillupRecord:
>     person: str
>     carName: str
>     milesDriven: float
>     gallonsFilled: int
>     fillupDate: datetime
>
>
> class Solution:
>     def __init__(self, filename: str):
>         self.records: List[FillupRecord] = []
>         self._load_data(filename)
>
>     def _load_data(self, filename: str) -> None:
>         with open(filename, newline="") as csvfile:
>             reader = csv.reader(csvfile)
>             for row in reader:
>                 if len(row) != 5:
>                     continue
>
>                 person = row[0].strip()
>                 car_name = row[1].strip()
>                 miles = float(row[2].strip())
>                 gallons = int(row[3].strip())
>                 fillup_date = self._parse_date(row[4].strip())
>
>                 self.records.append(
>                     FillupRecord(
>                         person=person,
>                         carName=car_name,
>                         milesDriven=miles,
>                         gallonsFilled=gallons,
>                         fillupDate=fillup_date,
>                     )
>                 )
>
>     def _parse_date(self, date_str: str) -> datetime:
>         formats = [
>             "%Y-%m-%d",
>             "%m/%d/%Y",
>             "%Y/%m/%d",
>             "%m-%d-%Y",
>         ]
>         for fmt in formats:
>             try:
>                 return datetime.strptime(date_str, fmt)
>             except ValueError:
>                 continue
>         raise ValueError(f"Unsupported date format: {date_str}")
>
>     def GetRangeMPG(self, personName: str, startDate: str, endDate: str) -> List[CarMPG]:
>         start = self._parse_date(startDate)
>         end = self._parse_date(endDate)
>
>         totals: Dict[str, List[float]] = defaultdict(lambda: [0.0, 0.0])
>
>         for record in self.records:
>             if record.person != personName:
>                 continue
>             if start <= record.fillupDate <= end:
>                 totals[record.carName][0] += record.milesDriven
>                 totals[record.carName][1] += record.gallonsFilled
>
>         result: List[CarMPG] = []
>         for car_name, (total_miles, total_gallons) in totals.items():
>             mpg = total_miles / total_gallons if total_gallons != 0 else 0.0
>             result.append(CarMPG(carName=car_name, mpg=mpg))
>
>         return result
> ```
>
> ## Explanation
>
> The required task is to compute, for a given person and inclusive date range, the MPG of each car driven by that person.
>
> ### Approach
>
> Each CSV row contains:
>
> - person name
> - car name
> - miles driven
> - gallons filled
> - fill-up date
>
> For a query `GetRangeMPG(PersonName, StartDate, EndDate)`, the program must:
>
> 1. parse the input dates,
> 2. examine all records for the specified person,
> 3. keep only records whose dates satisfy
>    $$\text{StartDate} \le \text{fillupDate} \le \text{EndDate},$$
> 4. group those records by car name,
> 5. compute
>    $$\text{MPG} = \frac{\text{total miles driven}}{\text{total gallons filled}},$$
> 6. return a list of objects containing `(CarName, MPG)`.
>
> ### Key Details
>
> - The date comparison is **inclusive**.
> - A person may own multiple cars, so the result may contain multiple entries.
> - Totals are accumulated separately for each car.
> - If total gallons is $0$, the code returns $0.0$ to avoid division by zero.
>
> ### Time Complexity
>
> If there are $n$ records, each query scans the records once, so the running time is
>
> $$O(n).$$
>
> ### Final Result
>
> The program above fully implements the required functionality through:
>
> - loading CSV data,
> - storing records,
> - and answering `GetRangeMPG(personName, startDate, endDate)` queries by returning a list of `(CarName, MPG)` objects.
