> [!example] Question 1144 · SIG
> ## Software Developer Interview

Reverse a given string.

[Source](https://www.thewallstreetquants.com/ebook#p=1145)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To reverse a string, read its characters from the end to the beginning and construct a new string in that order.
>
> ### Method
> Given a string $s$ of length $n$:
>
> 1. Start at index $n-1$.
> 2. Move backward to index $0$.
> 3. Append each character to a new string.
>
> ### Example
> If the string is
>
> $$
> s = \text{"hello"}
> $$
>
> then reading from right to left gives
>
> $$
> \text{"olleh"}
> $$
>
> ### Python implementation
>
> ```python
> def reverse_string(s):
>     return s[::-1]
> ```
>
> ### Result
> The reversed version of a string $s$ is the string whose characters appear in the opposite order.
