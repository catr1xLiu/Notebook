> [!example] Question 1145 · SIG
> ## Software Engineer Interview

Given two strings, return the characters that are common to both strings.

[Source](https://www.thewallstreetquants.com/ebook#p=1146)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To find the characters common to two strings, treat each string as a collection of characters and determine their intersection.
>
> ### Approach
>
> 1. Convert both strings into sets of characters.
>    - A set automatically removes duplicates.
> 2. Compute the intersection of the two sets.
> 3. The result is the set of characters that appear in both strings.
>
> ### Example
>
> Let the two strings be:
>
> - $s_1 = \text{"hello"}$
> - $s_2 = \text{"world"}$
>
> Convert to sets:
>
> $$
> \{\text{'h'}, \text{'e'}, \text{'l'}, \text{'o'}\}
> $$
>
> and
>
> $$
> \{\text{'w'}, \text{'o'}, \text{'r'}, \text{'l'}, \text{'d'}\}
> $$
>
> Their intersection is:
>
> $$
> \{\text{'l'}, \text{'o'}\}
> $$
>
> So the common characters are:
>
> $$
> \text{'l', 'o'}
> $$
>
> ### Python implementation
>
> ```python
> def common_characters(s1, s2):
>     return set(s1) & set(s2)
>
> # Example
> print(common_characters("hello", "world"))  # {'l', 'o'}
> ```
>
> ### Final Answer
>
> Use set intersection:
>
> ```python
> set(string1) & set(string2)
> ```
>
> This returns the characters common to both strings.
