> [!example] Question 1186 · SIG
> ## Software Engineer Interview

Check if a given string is a permutation of a palindrome without using any additional data structures.

[Source](https://www.thewallstreetquants.com/ebook#p=1187)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A string is a permutation of a palindrome if and only if its characters can be rearranged so that:
>
> - every character appears an even number of times, or
> - exactly one character appears an odd number of times.
>
> Thus, the problem reduces to checking how many characters have odd frequencies.
>
> The restriction is to avoid using any additional data structure such as a hash map, array, or set. A simple way to do this is:
>
> 1. Sort the characters of the string in place.
> 2. Scan the sorted string and count how many groups of equal characters have odd length.
> 3. If the number of odd-length groups is at most $1$, then the string is a permutation of a palindrome.
>
> ---
>
> ## Algorithm
>
> Let the input string be $s$ of length $n$.
>
> ### Step 1: Sort the string
>
> After sorting, equal characters become contiguous.
>
> For example:
>
> - $``carrace'' \to ``aaccerr''$
>
> ### Step 2: Count odd-sized blocks
>
> Traverse the sorted string and compute the size of each maximal block of identical characters.
>
> If a block has odd size, increment a counter $odd$.
>
> ### Step 3: Decide
>
> - If $odd \le 1$, return true.
> - Otherwise, return false.
>
> ---
>
> ## Correctness
>
> Suppose the sorted string has character counts
>
> $$
> f_1, f_2, \dots, f_k
> $$
>
> where each $f_i$ is the frequency of one distinct character.
>
> A palindrome can have:
>
> - all $f_i$ even, when the length is even, or
> - exactly one $f_i$ odd, when the length is odd.
>
> Therefore, the string is a permutation of a palindrome exactly when the number of odd $f_i$ values is at most $1$.
>
> Sorting does not change frequencies; it only makes equal characters adjacent, so scanning the sorted string correctly recovers each $f_i$. Hence the algorithm returns true exactly in the required cases.
>
> ---
>
> ## Time and Space Complexity
>
> - Sorting takes $O(n \log n)$.
> - The scan takes $O(n)$.
> - Extra space is $O(1)$ if the sort is performed in place.
>
> So the overall complexity is:
>
> $$
> O(n \log n) \text{ time and } O(1) \text{ extra space}
> $$
>
> ---
>
> ## Example Implementation
>
> ### C++
>
> ```cpp
> #include <algorithm>
> #include <string>
> using namespace std;
>
> bool isPermutationOfPalindrome(string s) {
>     sort(s.begin(), s.end());
>
>     int odd = 0;
>     int n = s.size();
>
>     for (int i = 0; i < n; ) {
>         int j = i;
>         while (j < n && s[j] == s[i]) {
>             j++;
>         }
>
>         int count = j - i;
>         if (count % 2 != 0) {
>             odd++;
>             if (odd > 1) return false;
>         }
>
>         i = j;
>     }
>
>     return true;
> }
> ```
>
> ---
>
> ## Final Answer
>
> Sort the string in place, count the frequency of each consecutive character block, and check how many counts are odd. The string is a permutation of a palindrome if and only if at most one character has an odd count. This uses no auxiliary data structure and requires $O(n \log n)$ time and $O(1)$ extra space.
