> [!example] Question 1196 · SIG
> ## Quant Trader Intern Interview

How much would you pay for the option to reroll a die, given that you receive the dollar value of the number you roll, and can choose to reroll once if you wish?

[Source](https://www.thewallstreetquants.com/ebook#p=1197)

> [!success]- Solution (Click to expand)
> Let the payoff from a single fair die roll be the number shown, in dollars.
>
> With the option to reroll once after seeing the first result, the optimal strategy is to keep the first roll if it is sufficiently large and reroll if it is small. Since a reroll has expected value
>
> $$
> E[\text{reroll}] = \frac{1+2+3+4+5+6}{6} = 3.5,
> $$
>
> it is optimal to:
>
> - reroll if the first roll is $1,2,3$,
> - keep if the first roll is $4,5,6$.
>
> Thus the expected value with the option is
>
> $$
> E[\text{with option}]
> = \frac{1}{6}(3.5+3.5+3.5+4+5+6).
> $$
>
> Compute:
>
> $$
> 3.5+3.5+3.5+4+5+6 = 25.5,
> $$
>
> so
>
> $$
> E[\text{with option}] = \frac{25.5}{6} = 4.25.
> $$
>
> Without the option, the expected value of one roll is
>
> $$
> E[\text{without option}] = 3.5.
> $$
>
> Therefore, the value of the option is
>
> $$
> 4.25 - 3.5 = 0.75.
> $$
>
> So the most one should pay for this option is
>
> $$
> \boxed{\$0.75}.
> $$
