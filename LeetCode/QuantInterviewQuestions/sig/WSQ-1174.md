> [!example] Question 1174 · SIG
> ## Software Engineer Interview

Given an unsorted array of integers, find the k-th largest element in the array.

[Source](https://www.thewallstreetquants.com/ebook#p=1175)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To find the $k$th largest element in an array, the most direct approach is:
>
> 1. Sort the array in **descending** order.
> 2. Return the element at index $k-1$.
>
> ### Algorithm
>
> Given an array $A$ of length $n$:
>
> 1. Sort $A$ so that
>    $$
>    A_1 \ge A_2 \ge \cdots \ge A_n
>    $$
> 2. The $k$th largest element is
>    $$
>    A_{k}
>    $$
>    in $1$-based indexing, or
>    $$
>    A[k-1]
>    $$
>    in $0$-based indexing.
>
> ### Example
>
> Let
> $$
> A = [7, 10, 4, 3, 20, 15], \quad k = 3
> $$
>
> After sorting in descending order:
> $$
> [20, 15, 10, 7, 4, 3]
> $$
>
> The $3$rd largest element is:
> $$
> 10
> $$
>
> ### Python implementation
>
> ```python
> def kth_largest(arr, k):
>     arr.sort(reverse=True)
>     return arr[k - 1]
> ```
>
> ### Complexity
>
> - Sorting takes
>   $$
>   O(n \log n)
>   $$
> - Accessing the $k$th element takes
>   $$
>   O(1)
>   $$
>
> Thus, the total time complexity is
> $$
> O(n \log n)
> $$
> with space complexity
> $$
> O(1)
> $$
> if sorting is done in place.
>
> ### Final Answer
>
> The $k$th largest element in an array can be found by sorting the array in descending order and returning the element at index $k-1$.
