> [!example] Question 1142 · SIG
> ## Software Engineer Interview

Implement a Stack data structure with methods such as push(), pop(), and top(), in a programming language of your choice (preferably C\#). The stack should accept only 12-bit integer numbers as input, and all exceptions should be handled properly.

[Source](https://www.thewallstreetquants.com/ebook#p=1143)

> [!success]- Solution (Click to expand)
> ## Stack Implementation in C\#
>
> A stack is a **Last-In, First-Out** ($\text{LIFO}$) data structure.  
> The required operations typically include:
>
> - $\text{Push}(x)$: insert an element onto the stack
> - $\text{Pop}()$: remove and return the top element
> - $\text{Top}()$: return the top element without removing it
> - $\text{IsEmpty}()$: check whether the stack is empty
> - $\text{Count}$: number of elements currently in the stack
> - optionally, $\text{Clear}()$
>
> The problem also requires that:
>
> 1. values must be valid **$12$-bit integers**
> 2. exceptions must be handled properly
>
> A signed $12$-bit integer ranges from
>
> $$
> -2^{11} \text{ to } 2^{11}-1
> $$
>
> that is,
>
> $$
> -2048 \text{ to } 2047
> $$
>
> Thus, every inserted value must lie in this range.
>
> ---
>
> ## Approach
>
> Implement a custom stack class in C# using an internal array.  
> This gives full control over:
>
> - stack behavior
> - capacity expansion
> - validation of $12$-bit integer range
> - exception handling
>
> The stack will support:
>
> - $\text{Push}(int\ value)$
> - $\text{Pop}()$
> - $\text{Top}()$
> - $\text{IsEmpty}()$
> - $\text{Count}$
> - $\text{Clear}()$
>
> ---
>
> ## C\# Implementation
>
> ```csharp
> using System;
>
> public class TwelveBitStack
> {
>     private const int MinValue = -2048;
>     private const int MaxValue = 2047;
>
>     private int[] _items;
>     private int _top;
>
>     public TwelveBitStack(int capacity = 10)
>     {
>         if (capacity <= 0)
>             throw new ArgumentOutOfRangeException(nameof(capacity), "Capacity must be greater than 0.");
>
>         _items = new int[capacity];
>         _top = -1;
>     }
>
>     public int Count
>     {
>         get { return _top + 1; }
>     }
>
>     public bool IsEmpty()
>     {
>         return _top == -1;
>     }
>
>     public void Push(int value)
>     {
>         ValidateTwelveBitRange(value);
>
>         if (_top == _items.Length - 1)
>         {
>             Resize();
>         }
>
>         _items[++_top] = value;
>     }
>
>     public int Pop()
>     {
>         if (IsEmpty())
>             throw new InvalidOperationException("Stack is empty. Cannot pop.");
>
>         int value = _items[_top];
>         _items[_top] = 0;
>         _top--;
>         return value;
>     }
>
>     public int Top()
>     {
>         if (IsEmpty())
>             throw new InvalidOperationException("Stack is empty. No top element.");
>
>         return _items[_top];
>     }
>
>     public void Clear()
>     {
>         Array.Clear(_items, 0, _items.Length);
>         _top = -1;
>     }
>
>     private void Resize()
>     {
>         int newCapacity = _items.Length * 2;
>         int[] newArray = new int[newCapacity];
>         Array.Copy(_items, newArray, _items.Length);
>         _items = newArray;
>     }
>
>     private void ValidateTwelveBitRange(int value)
>     {
>         if (value < MinValue || value > MaxValue)
>             throw new ArgumentOutOfRangeException(
>                 nameof(value),
>                 $"Value must be a signed 12-bit integer in the range [{MinValue}, {MaxValue}].");
>     }
> }
> ```

>
> A simple program can be written to demonstrate usage and exception handling.
>
> ```csharp
> using System;
>
> class Program
> {
>     static void Main()

>
>         try

>             stack.Push(100);

>         }
>         catch (InvalidOperationException ex)
>         {
>             Console.WriteLine("Operation Error: " + ex.Message);
>         }

>         {
>             Console.WriteLine("Unexpected Error: " + ex.Message);
>         }

>             stack.Clear();

>         }

>         {
>             Console.WriteLine("Operation Error: " + ex.Message);
>         }
>     }
> }

> ## Explanation of Exception Handling
>
> ### $1.$ Invalid capacity
> If the stack is created with nonpositive capacity, the constructor throws
>
> $$
> \text{ArgumentOutOfRangeException}
> $$
>
> because the initial size must be valid.
>
> ### $2.$ Invalid input value
> If a pushed number is not within the signed $12$-bit range
>
> $$
> [-2048, 2047]
> $$
>
> the method throws
>
> $$
> \text{ArgumentOutOfRangeException}
> $$
>
> ### $3.$ Pop from empty stack
> If $\text{Pop}()$ is called on an empty stack, it throws
>
> $$
> \text{InvalidOperationException}
> $$
>
> ### $4.$ Top from empty stack
> If $\text{Top}()$ is called on an empty stack, it also throws
>
> $$
> \text{InvalidOperationException}
> $$
>
> These are the appropriate built-in exceptions because the operation is invalid for the current state of the object.
>

> ## Time Complexity
>
> Let $n$ be the number of elements in the stack.
>
> - $\text{Push}(x)$: $O(1)$ on average, $O(n)$ when resizing occurs
> - $\text{Pop}()$: $O(1)$
> - $\text{Top}()$: $O(1)$
> - $\text{IsEmpty}()$: $O(1)$
> - $\text{Count}$: $O(1)$
> - $\text{Clear}()$: $O(n)$
>

> ## Final Answer
>
> A correct C# solution is to implement a custom stack class backed by an array, validate every pushed value to ensure it lies in the signed $12$-bit integer range $[-2048, 2047]$, and throw proper exceptions such as $\text{ArgumentOutOfRangeException}$ and $\text{InvalidOperationException}$ when invalid input or invalid stack operations occur. The implementation above satisfies all of these requirements.
