How do you reverse a linked list?

[Source](https://www.thewallstreetquants.com/ebook#p=1190)

> [!success]- Solution (Click to expand)
> ## Reversing a Linked List
>
> To reverse a singly linked list, the idea is to change each node’s `next` pointer so that it points to the previous node instead of the next one.
>
> ### Iterative method
>
> Maintain three pointers:
>
> - `prev`: the previous node, initially `null`
> - `curr`: the current node, initially the head
> - `next`: temporarily stores the next node
>
> ### Steps
>
> For each node:
>
> 1. Save the next node.
> 2. Reverse the current node’s pointer.
> 3. Move `prev` and `curr` one step forward.
>
> ### Code
>
> ```python
> class ListNode:
>     def __init__(self, val=0, next=None):
>         self.val = val
>         self.next = next
>
> def reverseList(head):
>     prev = None
>     curr = head
>
>     while curr:
>         nxt = curr.next
>         curr.next = prev
>         prev = curr
>         curr = nxt
>
>     return prev
> ```
>
> ### Example
>
> Given
>
> ```text
> 1 -> 2 -> 3 -> None
> ```
>
> After reversal:
>
> ```text
> 3 -> 2 -> 1 -> None
> ```
>
> ### Complexity
>
> - Time: $O(n)$
> - Space: $O(1)$
>
> ## Recursive method
>
> A recursive solution is also possible.
>
> ```python
> def reverseList(head):
>     if not head or not head.next:
>         return head
>
>     new_head = reverseList(head.next)
>     head.next.next = head
>     head.next = None
>     return new_head
> ```
>
> ### Complexity
>
> - Time: $O(n)$
> - Space: $O(n)$ due to recursion stack
>
> The iterative version is usually preferred because it uses constant extra space.
