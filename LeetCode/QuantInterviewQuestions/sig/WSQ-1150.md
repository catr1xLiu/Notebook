> ### 1. What is Object-Oriented Programming?
>
> Object-Oriented Programming, or $\text{OOP}$, is a programming paradigm in which software is organized around **objects** rather than just functions and logic. An object represents an entity that contains:
>
> - **Data**: called **attributes** or **properties**
> - **Behavior**: called **methods** or **functions**
>
> For example, a `Car` object may have attributes such as color, model, and speed, and methods such as start, stop, and accelerate.
>
> ### Main principles of $\text{OOP}$
>
> #### a. Encapsulation
> Encapsulation means bundling data and methods together inside a class and restricting direct access to some parts of the object. This helps protect data and maintain control over how it is used.
>
> #### b. Abstraction
> Abstraction means showing only the essential features of an object while hiding internal implementation details. This makes programs easier to use and understand.
>
> #### c. Inheritance
> Inheritance allows one class to acquire the properties and behaviors of another class. This promotes code reuse.
>
> For example, if `Vehicle` is a base class, then `Car` and `Bike` can inherit from it.
>
> #### d. Polymorphism
> Polymorphism means that the same method or interface can behave differently depending on the object using it. This allows flexibility and extensibility in programs.
>
> ### Advantages of $\text{OOP}$
>
> - Better code organization
> - Reusability through inheritance
> - Easier maintenance
> - Improved scalability
> - Better data security through encapsulation

> ### 2. Develop an algorithm to reverse a string
>
> #### Approach
>
> To reverse a string, use two pointers:
>
> - One pointer starts at the beginning of the string
> - The other starts at the end
> - Swap the characters at these positions
> - Move the left pointer forward and the right pointer backward
> - Continue until the pointers meet
>
> #### Algorithm
>
> Suppose the input string is $S$ of length $n$.
>
> 1. Convert the string into a mutable character array.
> 2. Set $left = 0$
> 3. Set $right = n - 1$
> 4. While $left < right$:
>    - Swap $S[left]$ and $S[right]$
>    - Increment $left$ by $1$
>    - Decrement $right$ by $1$
> 5. Output the reversed string
>
> #### Pseudocode
>
> ```text
> Algorithm ReverseString(S):
>     Convert S into array A
>     left ← 0
>     right ← length(A) - 1
>
>     while left < right do
>         temp ← A[left]
>         A[left] ← A[right]
>         A[right] ← temp
>
>         left ← left + 1
>         right ← right - 1
>     end while
>
>     return string formed from A
> ```
>
> #### Example
>
> Let $S = \text{"HELLO"}$
>
> Initial array:
>
> $\text{H E L L O}$
>
> - Swap positions $0$ and $4$: $\text{O E L L H}$
> - Swap positions $1$ and $3$: $\text{O L L E H}$
>
> Now $left \geq right$, so stop.
>
> Reversed string:
>
> $\text{"OLLEH"}$
>
> #### Time and space complexity
>
> - Time complexity: $O(n)$
> - Space complexity: $O(1)$ if the string is mutable, otherwise $O(n)$ if a new string or array is created
