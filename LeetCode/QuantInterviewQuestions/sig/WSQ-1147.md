> [!example] Question 1147 · SIG
> ## Software Engineer Interview

Check if a string is a permutation of a palindrome without using any additional data structures.

[Source](https://www.thewallstreetquants.com/ebook#p=1148)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A string is a permutation of a palindrome if and only if its characters can be rearranged so that:
>
> - every character appears an even number of times, or
> - exactly one character appears an odd number of times.
>
> This follows from the structure of a palindrome: characters on the left and right must match in pairs, with at most one unpaired middle character.
>
> ### Approach
>
> Without using any additional data structure such as a hash table or array, one direct method is:
>
> 1. For each character in the string, count how many times it appears in the entire string.
> 2. Track how many characters have odd frequency.
> 3. If more than one character has odd frequency, the string cannot be a permutation of a palindrome.
>
> To avoid recounting the same character multiple times, compare only with earlier positions and skip a character if it has already appeared before.
>
> ### Algorithm
>
> For each index $i$:
>
> - Check whether $s[i]$ has appeared in any position $< i$.
>   - If yes, skip it.
>   - If no, count its total frequency in the string.
> - If that frequency is odd, increment the number of odd-frequency characters.
> - If the number of odd-frequency characters exceeds $1$, return `false`.
>
> If the loop completes, return `true`.
>
> ### Pseudocode
>
> ```text
> function isPalindromePermutation(s):
>     oddCount = 0
>     n = length(s)
>
>     for i from 0 to n - 1:
>         alreadySeen = false
>         for k from 0 to i - 1:
>             if s[k] == s[i]:
>                 alreadySeen = true
>                 break
>
>         if alreadySeen:
>             continue
>
>         count = 0
>         for j from 0 to n - 1:
>             if s[j] == s[i]:
>                 count = count + 1
>
>         if count mod 2 == 1:
>             oddCount = oddCount + 1
>
>         if oddCount > 1:
>             return false
>
>     return true
> ```
>
> ### Example
>
> Consider $s = \text{"carrace"}$.
>
> - $\text{'c'}$ appears $2$ times
> - $\text{'a'}$ appears $2$ times
> - $\text{'r'}$ appears $2$ times
> - $\text{'e'}$ appears $1$ time
>
> Exactly one character has odd frequency, so the string is a permutation of a palindrome.
>
> ### Complexity
>
> Let $n$ be the length of the string.
>
> - Time complexity: $O(n^2)$
> - Extra space: $O(1)$
>
> ### Final Answer
>
> Yes, it can be checked without any other data structure by counting character frequencies directly with nested loops and verifying that at most one character has an odd count. The method uses $O(1)$ extra space and $O(n^2)$ time.
