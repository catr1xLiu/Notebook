> [!example] Question 1146 · SIG
> ## Software Developer Interview

A group of friends are tracking the miles per gallon (MPG) for each of their cars. Each time they fill up their gas tank, they record the following in a CSV file: person name, car name, miles driven since last fill-up (float), gallons filled at this fill-up (integer), and the fill-up date. Write a program that lets a group member determine the MPG for each of their cars during a specific time range. The principal function for querying MPG is: GetRangeMPG(PersonName, StartDate, EndDate), which returns a list of objects containing (CarName, MPG), where MPG is calculated as (total miles driven during the time period) / (total gallons filled during that time period). The query's date range should be treated inclusively.

[Source](https://www.thewallstreetquants.com/ebook#p=1147)

> [!success]- Solution (Click to expand)
> ## Solution
>
> The task is to process fuel-fill records from a CSV file and answer queries of the form
>
> $$
> \text{GetRangeMPG}(\text{PersonName}, \text{StartDate}, \text{EndDate})
> $$
>
> by returning, for the given person, the MPG of each of that person's cars over the inclusive date range. For each car,
>
> $$
> \text{MPG} = \frac{\text{total miles driven in range}}{\text{total gallons filled in range}}.
> $$
>
> A person may own multiple cars, so the result is a list of $$(\text{CarName}, \text{MPG})$$ pairs.
>
> ---
>
> ## Approach
>
> Each CSV row contains
>
> $$
> (\text{person}, \text{carName}, \text{milesDriven}, \text{gallonsFilled}, \text{fillupDate})
> $$
>
> The natural strategy is:
>
> 1. Read and parse every row into a record object.
> 2. Store all records in memory.
> 3. For a query:
>    - filter records by person,
>    - keep only records whose date satisfies
>      $$
>      \text{StartDate} \le \text{fillupDate} \le \text{EndDate},
>      $$
>    - group the remaining records by car name,
>    - for each car, sum miles and gallons,
>    - compute MPG.
>
> This yields a clear and correct implementation.
>
> ---
>
> ## Data structures
>
> Use one class to represent each fill-up record:
>
> ```java
> class FillupRecord {
>     String person;
>     String carName;
>     double milesDriven;
>     int gallonsFilled;
>     LocalDate fillupDate;
> }
> ```
>
> Use another class for the query result:
>
> ```java
> class CarMPG {
>     String carName;
>     double mpg;
> }
> ```
>
> The main class stores all parsed records in a list:
>
> ```java
> List<FillupRecord> records;
> ```
>
> ---
>
> ## Parsing the CSV
>
> For each line:
>
> 1. Split on commas.
> 2. Parse:
>    - person as `String`,
>    - car name as `String`,
>    - miles driven as `double`,
>    - gallons filled as `int`,
>    - fillup date as `LocalDate`.
>
> If the date format is standard ISO format such as `"2024-03-15"`, then `LocalDate.parse(...)` is sufficient.
>
> ---
>
> ## Query algorithm
>
> For `GetRangeMPG(personName, startDate, endDate)`:
>
> 1. Create a map from car name to accumulated totals.
> 2. Traverse every record.
> 3. If the record matches the person and its date lies in the inclusive range, add:
>    - miles to that car’s total miles,
>    - gallons to that car’s total gallons.
> 4. After processing all records, compute MPG for each car:
>    $$
>    \text{MPG} = \frac{\text{totalMiles}}{\text{totalGallons}}.
>    $$
>
> If a car somehow has total gallons equal to $0$, it should be skipped or handled safely to avoid division by zero.
>
> ---
>
> ## Correctness
>
> For a fixed person and date range, the algorithm examines every record exactly once.
>
> - A record contributes to a car’s totals **if and only if**:
>   1. its person matches the query person, and
>   2. its date is in the inclusive interval
>      $$
>      [\text{StartDate}, \text{EndDate}].
>      $$
>
> Thus, for each car, the accumulated totals are exactly the sum of all qualifying miles and gallons in the requested period. Therefore the computed value
>
> $$
> \frac{\text{total miles in range}}{\text{total gallons in range}}
> $$
>
> is precisely the MPG required by the problem statement.
>
> Hence the method is correct.
>
> ---
>
> ## Time complexity
>
> Let $n$ be the number of records.
>
> - Loading the file takes $$O(n)$$.
> - Each query scans all records once, so it takes $$O(n)$$.
> - The extra space used by the grouping map is $$O(k)$$, where $k$ is the number of distinct cars for that person in the range.
>
> ---
>
> ## Java implementation
>
> ```java
> import java.io.*;
> import java.nio.file.*;
> import java.time.LocalDate;
> import java.util.*;
>
> class FillupRecord {
>     String person;
>     String carName;
>     double milesDriven;
>     int gallonsFilled;
>     LocalDate fillupDate;
>
>     FillupRecord(String person, String carName, double milesDriven, int gallonsFilled, LocalDate fillupDate) {
>         this.person = person;
>         this.carName = carName;
>         this.milesDriven = milesDriven;
>         this.gallonsFilled = gallonsFilled;
>         this.fillupDate = fillupDate;
>     }
> }
>
> class CarMPG {
>     String carName;
>     double mpg;
>
>     CarMPG(String carName, double mpg) {
>         this.carName = carName;
>         this.mpg = mpg;
>     }
>
>     @Override
>     public String toString() {
>         return carName + "," + mpg;
>     }
> }
>
> public class Solution {
>
>     private static class Totals {
>         double miles = 0.0;
>         int gallons = 0;
>     }
>
>     private final List<FillupRecord> records = new ArrayList<>();
>
>     public Solution(String csvFilePath) throws IOException {
>         loadRecords(csvFilePath);
>     }
>
>     private void loadRecords(String csvFilePath) throws IOException {
>         List<String> lines = Files.readAllLines(Paths.get(csvFilePath));
>
>         for (String line : lines) {
>             if (line == null || line.trim().isEmpty()) {
>                 continue;
>             }
>
>             String[] parts = line.split(",");
>             if (parts.length != 5) {
>                 continue;
>             }
>
>             String person = parts[0].trim();
>             String carName = parts[1].trim();
>             double milesDriven = Double.parseDouble(parts[2].trim());
>             int gallonsFilled = Integer.parseInt(parts[3].trim());
>             LocalDate fillupDate = LocalDate.parse(parts[4].trim());
>
>             records.add(new FillupRecord(person, carName, milesDriven, gallonsFilled, fillupDate));
>         }
>     }
>
>     public List<CarMPG> GetRangeMPG(String personName, LocalDate startDate, LocalDate endDate) {
>         Map<String, Totals> byCar = new HashMap<>();
>
>         for (FillupRecord record : records) {
>             if (!record.person.equals(personName)) {
>                 continue;
>             }
>
>             if (record.fillupDate.isBefore(startDate) || record.fillupDate.isAfter(endDate)) {
>                 continue;
>             }
>
>             Totals totals = byCar.computeIfAbsent(record.carName, k -> new Totals());
>             totals.miles += record.milesDriven;
>             totals.gallons += record.gallonsFilled;
>         }
>
>         List<CarMPG> result = new ArrayList<>();
>
>         for (Map.Entry<String, Totals> entry : byCar.entrySet()) {
>             String carName = entry.getKey();
>             Totals totals = entry.getValue();
>
>             if (totals.gallons != 0) {
>                 double mpg = totals.miles / totals.gallons;
>                 result.add(new CarMPG(carName, mpg));
>             }
>         }
>
>         return result;
>     }
> }
> ```

> ## Example
>
> Suppose the CSV file contains:
>
> ```csv
> Alice,Civic,300.5,10,2024-01-10
> Alice,Civic,280.0,8,2024-01-20
> Alice,Corolla,150.0,5,2024-01-15
> Bob,Ford,200.0,10,2024-01-12
> ```
>
> Query:
>
> ```java
> GetRangeMPG("Alice", LocalDate.parse("2024-01-01"), LocalDate.parse("2024-01-31"))
> ```
>
> For `Civic`:
>
> $$
> \text{total miles} = 300.5 + 280.0 = 580.5
> $$
>
> $$
> \text{total gallons} = 10 + 8 = 18
> $$
>
> $$
> \text{MPG} = \frac{580.5}{18} = 32.25
> $$
>
> For `Corolla`:
>
> $$
> \text{MPG} = \frac{150.0}{5} = 30.0
> $$
>
> So the returned list contains:
>
> - `("Civic", 32.25)`
> - `("Corolla", 30.0)`
>
> ---
>
> ## Final answer
>
> Store each CSV row as a parsed record, then implement `GetRangeMPG` by filtering records for the given person and inclusive date range, grouping by car, summing miles and gallons, and computing
>
> $$
> \text{MPG} = \frac{\text{total miles}}{\text{total gallons}}.
> $$
>
> The provided Java implementation satisfies the requirements and runs in $$O(n)$$ time per query, where $n$ is the number of fill-up records.
