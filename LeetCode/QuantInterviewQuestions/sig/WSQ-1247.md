> [!example] Question 1247 · SIG
> ## Technology Associate Interview

What is a hash tree?

[Source](https://www.thewallstreetquants.com/ebook#p=1248)

> [!success]- Solution (Click to expand)
> A **hash tree**, more commonly called a **Merkle tree**, is a tree-structured data structure in which:
>
> - each **leaf node** stores the hash of a data block, and
> - each **internal node** stores the hash of the concatenation of its children’s hashes.
>
> Thus, the value at the root, called the **root hash** or **Merkle root**, is a compact cryptographic summary of all the data in the tree.
>
> ## Structure
>
> Suppose the data blocks are $D_1, D_2, D_3, D_4$. First compute the leaf hashes:
>
> $$
> h_1 = H(D_1), \quad h_2 = H(D_2), \quad h_3 = H(D_3), \quad h_4 = H(D_4),
> $$
>
> where $H$ is a cryptographic hash function.
>
> Then compute parent hashes:
>
> $$
> h_{12} = H(h_1 \| h_2), \qquad h_{34} = H(h_3 \| h_4),
> $$
>
> and finally the root hash:
>
> $$
> h_{\text{root}} = H(h_{12} \| h_{34}).
> $$
>
> Here, $\|$ denotes concatenation.
>
> ## Purpose
>
> A hash tree allows efficient verification that a piece of data belongs to a larger dataset without needing the entire dataset. This is useful because:
>
> - a small change in any data block changes its leaf hash,
> - which changes all hashes on the path to the root,
> - so the root hash detects tampering.
>
> ## Verification
>
> To verify that $D_3$ is included in the tree, one does not need all data blocks. It is enough to know:
>
> - $H(D_3) = h_3$,
> - its sibling hash $h_4$,
> - and the hash of the other subtree, $h_{12}$.
>
> Then compute:
>
> $$
> h_{34} = H(h_3 \| h_4),
> $$
>
> followed by
>
> $$
> h_{\text{root}} = H(h_{12} \| h_{34}).
> $$
>
> If this matches the known root hash, then $D_3$ is verified as part of the dataset.
>
> ## Advantages
>
> Hash trees provide:
>
> - **integrity checking** of large datasets,
> - **efficient proofs of membership** in $O(\log n)$ hash values,
> - **compact representation** through a single root hash,
> - **scalability** for distributed systems.
>
> ## Applications
>
> Hash trees are widely used in:
>
> - **blockchains** and cryptocurrencies,
> - **distributed file systems**,
> - **version control systems**,
> - **peer-to-peer networks**,
> - **database consistency verification**.
>
> ## Final Definition
>
> A hash tree is a tree of hashes in which leaves represent hashed data blocks and internal nodes represent hashes of their children, enabling efficient and secure verification of data integrity.
