> [!example] Question 1246 · SIG
> ## Technology Associate Interview

Write a program to check if a given input string is a palindrome.

[Source](https://www.thewallstreetquants.com/ebook#p=1247)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A string is a palindrome if it reads the same forward and backward.  
> To check this, compare the string with its reverse.
>
> ### Algorithm
> 1. Read the input string.
> 2. Reverse the string.
> 3. If the original string is equal to the reversed string, print `"Palindrome"`.
> 4. Otherwise, print `"Not Palindrome"`.
>
> ### Program in Python
>
> ```python
> s = input()
>
> if s == s[::-1]:
>     print("Palindrome")
> else:
>     print("Not Palindrome")
> ```
>
> ### Example
> For input:
>
> ```python
> madam
> ```
>
> the output is:
>
> ```python
> Palindrome
> ```
>
> Thus, the program correctly determines whether the input string is a palindrome.
