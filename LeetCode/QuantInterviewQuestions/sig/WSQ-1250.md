> [!example] Question 1250 · SIG
> ## Technology Associate Interview

Write a function to determine whether a given point lies within a triangle in 2D space.

[Source](https://www.thewallstreetquants.com/ebook#p=1251)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A point $P$ lies inside a triangle with vertices $A$, $B$, and $C$ if it is on the same side of each edge as the opposite vertex. A standard and efficient way to test this in $2$D is to use signed areas via the $2$D cross product.
>
> ### Idea
>
> For three points $U$, $V$, and $W$, define
>
> $$
> \operatorname{cross}(U, V, W) = (V_x - U_x)(W_y - U_y) - (V_y - U_y)(W_x - U_x)
> $$
>
> This value is:
>
> - positive if $W$ is to the left of directed edge $\overrightarrow{UV}$,
> - negative if $W$ is to the right,
> - zero if the points are collinear.
>
> For triangle $ABC$, compute:
>
> $$
> d_1 = \operatorname{cross}(A, B, P)
> $$
>
> $$
> d_2 = \operatorname{cross}(B, C, P)
> $$
>
> $$
> d_3 = \operatorname{cross}(C, A, P)
> $$
>
> If all three values are nonnegative, or all three are nonpositive, then $P$ lies inside the triangle or on its boundary.
>
> ### Python implementation
>
> ```python
> def point_in_triangle(p, a, b, c):
>     def cross(u, v, w):
>         return (v[0] - u[0]) * (w[1] - u[1]) - (v[1] - u[1]) * (w[0] - u[0])
>
>     d1 = cross(a, b, p)
>     d2 = cross(b, c, p)
>     d3 = cross(c, a, p)
>
>     has_neg = (d1 < 0) or (d2 < 0) or (d3 < 0)
>     has_pos = (d1 > 0) or (d2 > 0) or (d3 > 0)
>
>     return not (has_neg and has_pos)
> ```
>
> ### How it works
>
> - If the signs of $d_1$, $d_2$, and $d_3$ are mixed, then $P$ is outside the triangle.
> - If they are all the same sign, then $P$ is inside.
> - If one or more are $0$, then $P$ lies on an edge or vertex, which this function counts as inside.
>
> ### Example
>
> ```python
> triangle_a = (0, 0)
> triangle_b = (5, 0)
> triangle_c = (0, 5)
>
> print(point_in_triangle((1, 1), triangle_a, triangle_b, triangle_c))  # True
> print(point_in_triangle((5, 5), triangle_a, triangle_b, triangle_c))  # False
> print(point_in_triangle((0, 2), triangle_a, triangle_b, triangle_c))  # True
> ```
>
> ### Final answer
>
> Use signed cross products of the point with each triangle edge. If the resulting signs are all nonnegative or all nonpositive, the point lies inside the triangle or on its boundary.
