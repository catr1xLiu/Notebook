> [!example] Question 1255 · SIG
> ## Sr Software Engineer Interview

Write a method that returns a stock ticker value based on a company name found within a string of text, which may also contain random words in addition to the company name. Optimize the method for performance, assuming there could be millions of companies to search through.

> ## 1. Coding Session: Return a stock ticker from noisy text, optimized for millions of companies
>
> ### Approach
>
> The task is to identify a company name embedded in arbitrary text and return its stock ticker. Since the company dictionary may contain millions of entries, a naive scan over all companies for each query is too slow. The correct design is to preprocess the company names into a structure that supports fast multi-pattern matching over text.
>
> The standard high-performance solution is:
>
> - normalize company names and input text,
> - build a trie over tokenized company names,
> - augment it with failure links using the Aho–Corasick algorithm,
> - scan the input text in linear time.
>
> This yields:
>
> - preprocessing time: proportional to the total number of tokens across all company names,
> - query time: proportional to the number of tokens in the input text plus the number of matches found.
>
> If the goal is to return a single ticker, one must also define how to resolve ambiguity when multiple company names match. A common rule is:
>
> - prefer the longest match,
> - if tied, prefer the highest-priority company entry.
>
> ### Normalization
>
> To make matching robust:
>
> - convert to lowercase,
> - remove punctuation,
> - collapse whitespace,
> - optionally remove corporate suffixes such as $"\mathrm{inc}"$, $"\mathrm{corp}"$, $"\mathrm{ltd}"$ if desired,
> - tokenize on whitespace.
>
> For example,
>
> - input text: `"I was reading about Apple in the news today."`
> - normalized tokens: $\left[\text{"i"}, \text{"was"}, \text{"reading"}, \text{"about"}, \text{"apple"}, \text{"in"}, \text{"the"}, \text{"news"}, \text{"today"}\right]$
>
> ### Data structure
>
> Each company name is represented as a sequence of tokens. For example:
>
> - `"apple"` $\to$ $\left[\text{"apple"}\right]$
> - `"bank of america"` $\to$ $\left[\text{"bank"}, \text{"of"}, \text{"america"}\right]$
>
> Insert these token sequences into a trie. Each terminal node stores one or more ticker records.
>
> Then compute failure links to support efficient matching across token boundaries.
>
> ### Java implementation
>
> ```java
> import java.util.*;
>
> public class StockTickerMatcher {
>
>     private static class Match {
>         String ticker;
>         int tokenLength;
>         int priority;
>
>         Match(String ticker, int tokenLength, int priority) {
>             this.ticker = ticker;
>             this.tokenLength = tokenLength;
>             this.priority = priority;
>         }
>     }
>
>     private static class Node {
>         Map<String, Node> children = new HashMap<>();
>         Node fail;
>         List<Match> outputs = new ArrayList<>();
>     }
>
>     public static class CompanyEntry {
>         String companyName;
>         String ticker;
>         int priority;
>
>         public CompanyEntry(String companyName, String ticker, int priority) {
>             this.companyName = companyName;
>             this.ticker = ticker;
>             this.priority = priority;
>         }
>     }
>
>     private final Node root = new Node();
>
>     public StockTickerMatcher(List<CompanyEntry> companies) {
>         buildTrie(companies);
>         buildFailureLinks();
>     }
>
>     private void buildTrie(List<CompanyEntry> companies) {
>         for (CompanyEntry company : companies) {
>             List<String> tokens = tokenize(company.companyName);
>             if (tokens.isEmpty()) {
>                 continue;
>             }
>
>             Node current = root;
>             for (String token : tokens) {
>                 current = current.children.computeIfAbsent(token, k -> new Node());
>             }
>
>             current.outputs.add(new Match(company.ticker, tokens.size(), company.priority));
>         }
>     }
>
>     private void buildFailureLinks() {
>         Queue<Node> queue = new ArrayDeque<>();
>
>         root.fail = root;
>         for (Node child : root.children.values()) {
>             child.fail = root;
>             queue.offer(child);
>         }
>
>         while (!queue.isEmpty()) {
>             Node current = queue.poll();
>
>             for (Map.Entry<String, Node> entry : current.children.entrySet()) {
>                 String token = entry.getKey();
>                 Node child = entry.getValue();
>
>                 Node fallback = current.fail;
>                 while (fallback != root && !fallback.children.containsKey(token)) {
>                     fallback = fallback.fail;
>                 }
>
>                 if (fallback.children.containsKey(token) && fallback.children.get(token) != child) {
>                     child.fail = fallback.children.get(token);
>                 } else {
>                     child.fail = root;
>                 }
>
>                 child.outputs.addAll(child.fail.outputs);
>                 queue.offer(child);
>             }
>         }
>     }
>
>     public String findTicker(String text) {
>         List<String> tokens = tokenize(text);
>         Node current = root;
>
>         Match best = null;
>
>         for (String token : tokens) {
>             while (current != root && !current.children.containsKey(token)) {
>                 current = current.fail;
>             }
>
>             if (current.children.containsKey(token)) {
>                 current = current.children.get(token);
>             } else {
>                 current = root;
>             }
>
>             for (Match match : current.outputs) {
>                 if (best == null
>                         || match.tokenLength > best.tokenLength
>                         || (match.tokenLength == best.tokenLength && match.priority > best.priority)) {
>                     best = match;
>                 }
>             }
>         }
>
>         return best == null ? null : best.ticker;
>     }
>
>     private static List<String> tokenize(String text) {
>         String normalized = normalize(text);
>         if (normalized.isEmpty()) {
>             return Collections.emptyList();
>         }
>         return Arrays.asList(normalized.split("\\s+"));
>     }
>
>     private static String normalize(String text) {
>         return text.toLowerCase()
>                 .replaceAll("[^a-z0-9\\s]", " ")
>                 .replaceAll("\\s+", " ")
>                 .trim();
>     }
>
>     public static void main(String[] args) {
>         List<CompanyEntry> companies = Arrays.asList(
>                 new CompanyEntry("Apple", "AAPL", 10),
>                 new CompanyEntry("Microsoft", "MSFT", 10),
>                 new CompanyEntry("Bank of America", "BAC", 10)
>         );
>
>         StockTickerMatcher matcher = new StockTickerMatcher(companies);
>
>         System.out.println(matcher.findTicker("Random words before Apple and after")); // AAPL
>         System.out.println(matcher.findTicker("I use Microsoft products")); // MSFT
>         System.out.println(matcher.findTicker("News about Bank of America today")); // BAC
>     }
> }
> ```
>
> ### Why this is performant
>
> If there are $N$ companies with total token count $T$, then:
>
> - trie construction is $O(T)$,
> - failure-link construction is $O(T)$,
> - each query over $L$ tokens runs in $O(L + M)$, where $M$ is the number of matches reported.
>
> This is far superior to checking every company against the text, which would be roughly $O(N)$ or worse per query.
>
> ### Further optimizations for production
>
> For truly massive scale:
>
> - replace string tokens with integer token IDs,
> - use a compact trie representation instead of object-heavy nodes,
> - memory-map the automaton if it is too large,
> - shard by first token if needed,
> - cache frequent queries,
> - support synonym tables such as `"google"` $\leftrightarrow$ `"alphabet"`.
>
> ### Final result
>
> The appropriate method is a multi-pattern token matcher based on Aho–Corasick over normalized company names. It provides near-linear query time and is well suited when the company universe contains millions of entries.

> ## 2. System Design Session: Point of sale system with coupon support
>
> ### Requirements
>
> A minimal point of sale system should support:
>
> - adding items to a cart,
> - computing subtotal,
> - applying coupons,
> - computing final total,
> - allowing different coupon types.
>
> A clean design uses:
>
> - domain objects for items and cart lines,
> - a coupon abstraction,
> - a checkout service that applies coupons.
>
> ### Design
>
> Core entities:
>
> - `Product`: item definition with SKU, name, and price,
> - `CartItem`: product plus quantity,
> - `Cart`: collection of cart items,
> - `Coupon`: interface for discounts,
> - `CheckoutService`: calculates totals.
>
> Coupon examples:
>
> - percentage off,
> - fixed amount off,
> - conditional coupon such as $"\text{\textdollar}10$ off when subtotal is at least $\text{\textdollar}100$".
>
> ### Java code
>
> ```java
> import java.math.BigDecimal;
> import java.math.RoundingMode;
> import java.util.*;
>
> class Product {
>     private final String sku;
>     private final String name;
>     private final BigDecimal price;
>
>     public Product(String sku, String name, BigDecimal price) {
>         this.sku = sku;
>         this.name = name;
>         this.price = price;
>     }
>
>     public String getSku() {
>         return sku;
>     }
>
>     public String getName() {
>         return name;
>     }
>
>     public BigDecimal getPrice() {
>         return price;
>     }
> }
>
> class CartItem {
>     private final Product product;
>     private final int quantity;
>
>     public CartItem(Product product, int quantity) {
>         if (quantity <= 0) {
>             throw new IllegalArgumentException("Quantity must be positive");
>         }
>         this.product = product;
>         this.quantity = quantity;
>     }
>
>     public BigDecimal getLineTotal() {
>         return product.getPrice().multiply(BigDecimal.valueOf(quantity));
>     }
>
>     public Product getProduct() {
>         return product;
>     }
>
>     public int getQuantity() {
>         return quantity;
>     }
> }
>
> class Cart {
>     private final List<CartItem> items = new ArrayList<>();
>
>     public void addItem(Product product, int quantity) {
>         items.add(new CartItem(product, quantity));
>     }
>
>     public List<CartItem> getItems() {
>         return Collections.unmodifiableList(items);
>     }
>
>     public BigDecimal getSubtotal() {
>         BigDecimal subtotal = BigDecimal.ZERO;
>         for (CartItem item : items) {
>             subtotal = subtotal.add(item.getLineTotal());
>         }
>         return subtotal;
>     }
> }
>
> interface Coupon {
>     String code();
>     BigDecimal discount(Cart cart);
> }
>
> class PercentageCoupon implements Coupon {
>     private final String code;
>     private final BigDecimal percent;
>
>     public PercentageCoupon(String code, BigDecimal percent) {
>         this.code = code;
>         this.percent = percent;
>     }
>
>     @Override
>     public String code() {
>         return code;
>     }
>
>     @Override
>     public BigDecimal discount(Cart cart) {
>         return cart.getSubtotal()
>                 .multiply(percent)
>                 .divide(BigDecimal.valueOf(100), 2, RoundingMode.HALF_UP);
>     }
> }
>
> class FixedAmountCoupon implements Coupon {
>     private final String code;
>     private final BigDecimal amount;
>
>     public FixedAmountCoupon(String code, BigDecimal amount) {
>         this.code = code;
>         this.amount = amount;
>     }
>
>     @Override
>     public String code() {
>         return code;
>     }
>
>     @Override
>     public BigDecimal discount(Cart cart) {
>         return amount.min(cart.getSubtotal());
>     }
> }
>
> class ThresholdCoupon implements Coupon {
>     private final String code;
>     private final BigDecimal threshold;
>     private final BigDecimal amount;
>
>     public ThresholdCoupon(String code, BigDecimal threshold, BigDecimal amount) {
>         this.code = code;
>         this.threshold = threshold;
>         this.amount = amount;
>     }
>
>     @Override
>     public String code() {
>         return code;
>     }
>
>     @Override
>     public BigDecimal discount(Cart cart) {
>         return cart.getSubtotal().compareTo(threshold) >= 0
>                 ? amount.min(cart.getSubtotal())
>                 : BigDecimal.ZERO;
>     }
> }
>
> class Receipt {
>     private final BigDecimal subtotal;
>     private final BigDecimal discount;
>     private final BigDecimal total;
>
>     public Receipt(BigDecimal subtotal, BigDecimal discount, BigDecimal total) {
>         this.subtotal = subtotal;
>         this.discount = discount;
>         this.total = total;
>     }
>
>     public BigDecimal getSubtotal() {
>         return subtotal;
>     }
>
>     public BigDecimal getDiscount() {
>         return discount;
>     }
>
>     public BigDecimal getTotal() {
>         return total;
>     }
> }
>
> class CheckoutService {
>     private final Map<String, Coupon> coupons = new HashMap<>();
>
>     public void registerCoupon(Coupon coupon) {
>         coupons.put(coupon.code(), coupon);
>     }
>
>     public Receipt checkout(Cart cart, String couponCode) {
>         BigDecimal subtotal = cart.getSubtotal();
>         BigDecimal discount = BigDecimal.ZERO;
>
>         if (couponCode != null && coupons.containsKey(couponCode)) {
>             discount = coupons.get(couponCode).discount(cart);
>         }
>
>         if (discount.compareTo(subtotal) > 0) {
>             discount = subtotal;
>         }
>
>         BigDecimal total = subtotal.subtract(discount);
>         return new Receipt(subtotal, discount, total);
>     }
> }
>
> public class POSDemo {
>     public static void main(String[] args) {
>         Product apple = new Product("SKU1", "Apple", new BigDecimal("1.50"));
>         Product bread = new Product("SKU2", "Bread", new BigDecimal("3.00"));
>
>         Cart cart = new Cart();
>         cart.addItem(apple, 4);
>         cart.addItem(bread, 2);
>
>         CheckoutService checkoutService = new CheckoutService();
>         checkoutService.registerCoupon(new PercentageCoupon("SAVE10", new BigDecimal("10")));
>         checkoutService.registerCoupon(new FixedAmountCoupon("LESS5", new BigDecimal("5.00")));
>         checkoutService.registerCoupon(new ThresholdCoupon("OVER20", new BigDecimal("20.00"), new BigDecimal("3.00")));
>
>         Receipt receipt = checkoutService.checkout(cart, "SAVE10");
>
>         System.out.println("Subtotal: " + receipt.getSubtotal());
>         System.out.println("Discount: " + receipt.getDiscount());
>         System.out.println("Total: " + receipt.getTotal());
>     }
> }
> ```
>
> ### Design notes
>
> This implementation keeps the design minimal while preserving extensibility:
>
> - new coupon types can be added by implementing `Coupon`,
> - checkout logic stays simple,
> - pricing logic is isolated from cart management.
>
> In a fuller design, one would add:
>
> - coupon validation rules,
> - expiration dates,
> - stacking rules,
> - product/category-specific discounts,
> - taxes,
> - inventory integration,
> - persistence and audit logging.
>
> ### Final result
>
> A minimal but extensible POS design consists of:
>
> - `Product`,
> - `CartItem`,
> - `Cart`,
> - `Coupon`,
> - `CheckoutService`,
> - `Receipt`.
>
> The coupon mechanism is implemented using a strategy-style interface so that additional discount behaviors can be introduced without changing checkout code.
