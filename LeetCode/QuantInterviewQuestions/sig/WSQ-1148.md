> [!example] Question 1148 · SIG
> ## Software Developer Interview

Given an array of integers, write a program in the language of your choice to do the following: (1) reverse the array; (2) find all perfect numbers in the array.

[Source](https://www.thewallstreetquants.com/ebook#p=1149)

> [!success]- Solution (Click to expand)
> ## Python Solution
>
> ```python
> # Reverse an array
> arr = [1, 2, 3, 4, 5]
> reversed_arr = arr[::-1]
> print("Reversed array:", reversed_arr)
>
> # Find all perfect numbers in an array
> def is_perfect(n):
>     if n < 2:
>         return False
>     divisors_sum = 1
>     for i in range(2, int(n ** 0.5) + 1):
>         if n % i == 0:
>             divisors_sum += i
>             if i != n // i:
>                 divisors_sum += n // i
>     return divisors_sum == n
>
> numbers = [6, 10, 28, 12, 496, 15]
> perfect_numbers = [x for x in numbers if is_perfect(x)]
>
> print("Perfect numbers:", perfect_numbers)
> ```
>
> ## Output
>
> ```python
> Reversed array: [5, 4, 3, 2, 1]
> Perfect numbers: [6, 28, 496]
> ```
>
> ## Explanation
>
> A **perfect number** is a positive integer equal to the sum of its proper divisors.
>
> Examples:
>
> - $6 = 1 + 2 + 3$
> - $28 = 1 + 2 + 4 + 7 + 14$
>
> Thus, in the given list, the perfect numbers are:
>
> $$[6,\ 28,\ 496]$$
