> [!example] Question 1182 · SIG
> ## Software Engineer Interview

Given a matrix, if an element is 0, set its entire row and column to 0. Modify the matrix in place.

[Source](https://www.thewallstreetquants.com/ebook#p=1183)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Given a matrix, the task is to set an entire row and an entire column to zero whenever any element in that row or column is zero.
>
> ### Approach
>
> A direct way is:
>
> 1. Scan the matrix and record which rows contain a zero.
> 2. Record which columns contain a zero.
> 3. Scan the matrix again and set entry $a_{ij}$ to zero if either:
>    - row $i$ contains a zero, or
>    - column $j$ contains a zero.
>
> This ensures that all rows and columns affected by at least one zero are fully zeroed.
>
> ---
>
> ## Algorithm
>
> Let the matrix have $m$ rows and $n$ columns.
>
> 1. Create two boolean arrays:
>    - `zeroRow` of size $m$
>    - `zeroCol` of size $n$
>
> 2. First pass:
>    - For every element $a_{ij}$:
>      - if $a_{ij} = 0$, mark:
>        - `zeroRow[i] = true`
>        - `zeroCol[j] = true`
>
> 3. Second pass:
>    - For every element $a_{ij}$:
>      - if `zeroRow[i]` or `zeroCol[j]` is true, set $a_{ij} = 0$
>
> ---
>
> ## Example
>
> For
>
> $$
> \begin{bmatrix}
> 1 & 2 & 3 \\
> 4 & 0 & 6 \\
> 7 & 8 & 9
> \end{bmatrix}
> $$
>
> The zero is at position $(1,1)$, so:
>
> - row $1$ must become zero
> - column $1$ must become zero
>
> Result:
>
> $$
> \begin{bmatrix}
> 1 & 0 & 3 \\
> 0 & 0 & 0 \\
> 7 & 0 & 9
> \end{bmatrix}
> $$
>
> ---
>
> ## Python Implementation
>
> ```python
> def set_zeroes(matrix):
>     if not matrix or not matrix[0]:
>         return
>
>     m, n = len(matrix), len(matrix[0])
>     zero_row = [False] * m
>     zero_col = [False] * n
>
>     # First pass: find rows and columns containing zero
>     for i in range(m):
>         for j in range(n):
>             if matrix[i][j] == 0:
>                 zero_row[i] = True
>                 zero_col[j] = True
>
>     # Second pass: set elements to zero
>     for i in range(m):
>         for j in range(n):
>             if zero_row[i] or zero_col[j]:
>                 matrix[i][j] = 0
> ```
>
> ---
>
> ## Complexity
>
> The matrix is scanned twice, so the time complexity is
>
> $$
> O(mn)
> $$
>
> The extra space used is for the two marker arrays, so the space complexity is
>
> $$
> O(m+n)
> $$
>
> ---
>
> ## Final Answer
>
> To fill matrix rows and columns with zeroes whenever a zero appears, mark all rows and columns containing a zero in a first pass, then zero out every cell belonging to any marked row or column in a second pass. This yields a solution with:
>
> $$
> \text{Time} = O(mn), \qquad \text{Space} = O(m+n)
> $$
