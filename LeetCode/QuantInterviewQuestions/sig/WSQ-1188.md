> ### What is Object-Oriented Programming?
> Object-Oriented Programming, or $\text{OOP}$, is a programming paradigm based on the concept of **objects**, which combine **data** and **behavior** into a single unit.
>
> An object typically contains:
>
> - **Attributes**: the data or state of the object
> - **Methods**: the functions or behavior of the object
>
> The main principles of $\text{OOP}$ are:
>
> 1. **Encapsulation**  
>    Bundling data and methods together, and restricting direct access to some internal details.
>
> 2. **Abstraction**  
>    Hiding complex implementation details and showing only the essential features.
>
> 3. **Inheritance**  
>    Allowing one class to acquire the properties and behaviors of another class.
>
> 4. **Polymorphism**  
>    Allowing the same method or interface to behave differently for different objects.
>
> **Example:**  
> A class called `Car` may have attributes such as color and speed, and methods such as start, stop, and accelerate.
>
> $\text{OOP}$ helps make programs more modular, reusable, maintainable, and easier to scale.

> ### Develop an algorithm to reverse a string
>
> #### Approach
> To reverse a string, place the characters in the opposite order. One standard method is to use two pointers:
>
> - One pointer starts at the beginning of the string
> - Another pointer starts at the end
> - Swap the characters at these positions
> - Move the pointers toward each other
> - Stop when the pointers meet or cross
>
> ---
>
> ### Algorithm
> Suppose the string is stored as an array of characters $S$ of length $n$.
>
> 1. Set $i = 0$
> 2. Set $j = n - 1$
> 3. While $i < j$:
>    - Swap $S[i]$ and $S[j]$
>    - Increment $i$ by $1$
>    - Decrement $j$ by $1$
> 4. Output the modified string
>
> ---
>
> ### Pseudocode
>
> ```text
> ReverseString(S):
>     i ← 0
>     j ← length(S) - 1
>
>     while i < j do
>         temp ← S[i]
>         S[i] ← S[j]
>         S[j] ← temp
>
>         i ← i + 1
>         j ← j - 1
>     end while
>
>     return S
> ```
>
> ---
>
> ### Example
> For the string `"HELLO"`:
>
> - Initial: `H E L L O`
> - Swap first and last: `O E L L H`
> - Swap second and fourth: `O L L E H`
>
> Reversed string: `"OLLEH"`
>
> ---
>
> ### Complexity
> - **Time complexity:** $O(n)$
> - **Space complexity:** $O(1)$ if the string is mutable
>
> If the string is immutable, then a new reversed string must be created, which may require $O(n)$ extra space.
>
> ## Final Answer
>
> - **Object-Oriented Programming** is a programming style based on objects that combine data and methods, built on the principles of encapsulation, abstraction, inheritance, and polymorphism.
> - **String reversal algorithm:** use two pointers, swap characters from the beginning and end, and continue until the middle is reached. The algorithm runs in $O(n)$ time.
