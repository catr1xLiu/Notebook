> [!example] Question 1153 · SIG
> ## Intern Interview

Given an array of numbers, find the maximum value in the array.

[Source](https://www.thewallstreetquants.com/ebook#p=1154)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To find the maximum element of an array, scan through the array while keeping track of the largest value seen so far.
>
> ### Algorithm
> 1. Initialize a variable `max` to the first element of the array.
> 2. Traverse the remaining elements of the array.
> 3. For each element, compare it with `max`.
>    - If the current element is larger, update `max`.
> 4. After the traversal, `max` is the largest element in the array.
>
> ### Pseudocode
> ```text
> max = array[0]
> for i = 1 to n - 1:
>     if array[i] > max:
>         max = array[i]
> return max
> ```
>
> ### Example
> For the array
>
> ```text
> [3, 7, 2, 9, 4]
> ```
>
> - Start with `max = 3`
> - Compare with `7` $\rightarrow$ update `max = 7`
> - Compare with `2` $\rightarrow$ no change
> - Compare with `9` $\rightarrow$ update `max = 9`
> - Compare with `4` $\rightarrow$ no change
>
> Thus, the maximum value is
>
> $$9$$
>
> ### Time and Space Complexity
> - Time complexity: $$O(n)$$
> - Space complexity: $$O(1)$$
>
> ### Final Answer
> The maximum of an array can be found by a single linear scan, updating the largest value seen so far.
