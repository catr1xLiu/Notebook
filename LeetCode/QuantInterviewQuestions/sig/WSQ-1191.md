> [!example] Question 1191 · SIG
> ## Trading Intern Interview

A painting has an 80% chance of being fake. If it is real, it is worth \$500,000; if fake, it is worth \$10,000. The seller asks for \$120,000. Based on this information, should you buy the painting?

[Source](https://www.thewallstreetquants.com/ebook#p=1192)

> [!success]- Solution (Click to expand)
> Compute the painting’s expected value.
>
> Let $R$ denote the event that the painting is real, and $F$ the event that it is fake.
>
> Given:
> - $P(F)=0.8$
> - $P(R)=0.2$
> - Value if real: $\text{\textdollar}500{,}000$
> - Value if fake: $\text{\textdollar}10{,}000$
>
> The expected value is
> $$
> E[V]=P(R)\cdot 500{,}000 + P(F)\cdot 10{,}000.
> $$
>
> Substitute:
> $$
> E[V]=0.2\cdot 500{,}000 + 0.8\cdot 10{,}000
> =100{,}000+8{,}000
> =108{,}000.
> $$
>
> The seller asks for $\text{\textdollar}120{,}000$, which is greater than the expected value:
> $$
> 120{,}000 > 108{,}000.
> $$
>
> Therefore, on expected monetary value grounds, you should **not** buy the painting.
>
> The fair price would be at most
> $$
> \$108{,}000.
> $$
