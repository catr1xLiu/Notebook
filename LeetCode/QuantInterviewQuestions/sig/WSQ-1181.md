How does a dictionary work?

> ## How a Dictionary Works
>
> A **dictionary** is a reference book or data structure used to **store pairs of information**:
>
> - a **key**: the word or identifier you look up
> - a **value**: the meaning, definition, or associated information
>
> ### Ordinary Dictionary
>
> In a language dictionary:
>
> - the **key** is a word, such as “tree”
> - the **value** is the definition, pronunciation, usage, and related information
>
> To use it:
>
> 1. Find the word by its alphabetical order.
> 2. Read the information listed under that word.
>
> So the process is:
>
> $$
> \text{word} \longrightarrow \text{definition}
> $$
>
> ### Dictionary as a Data Structure
>
> In computing, a dictionary stores **key–value pairs**. For example,
>
> $$
> \{
> \text{"name"} : \text{"Alice"},
> \text{"age"} : 25
> \}
> $$
>
> Here:
>
> - $\text{"name"}$ is a key with value $\text{"Alice"}$
> - $\text{"age"}$ is a key with value $25$
>
> A computer dictionary works by allowing you to:
>
> 1. **insert** a key–value pair
> 2. **search** for a value using its key
> 3. **update** the value for an existing key
> 4. **delete** a key–value pair
>
> Symbolically,
>
> $$
> \text{key} \mapsto \text{value}
> $$
>
> ### How It Is Implemented
>
> A common implementation uses a **hash table**.
>
> #### Step 1: Hash the key
>
> The dictionary applies a **hash function** to the key:
>
> $$
> h(\text{key}) = \text{index}
> $$
>
> This converts the key into a number that tells where the value should be stored.
>
> #### Step 2: Store or find the value
>
> Using that index, the dictionary:
>
> - stores the value in a location in memory, or
> - goes to that location to retrieve the value
>
> This makes lookup very fast, often close to
>
> $$
> O(1)
> $$
>
> on average.
>
> ### Collision Handling
>
> Sometimes two different keys produce the same index:
>
> $$
> h(k_1) = h(k_2)
> $$
>
> This is called a **collision**.
>
> To handle collisions, dictionaries use methods such as:
>
> - **chaining**: store multiple items in the same location
> - **open addressing**: search for another empty spot
>
> ### Summary
>
> A dictionary works by associating each **key** with a **value** so that information can be found quickly.
>
> - In a language dictionary, keys are words and values are definitions.
> - In computing, keys are identifiers and values are stored data.
> - Efficient implementations often use hashing:
>
> $$
> \text{key} \to h(\text{key}) \to \text{storage location} \to \text{value}
> $$
>
> Thus, a dictionary is fundamentally a system for **fast lookup by key**.
