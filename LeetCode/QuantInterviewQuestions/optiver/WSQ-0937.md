> [!example] Question 937 · Optiver
> ## Software Developer Interview

Given a list containing all numbers from 1 to n except one missing number, find the missing number.

[Source](https://www.thewallstreetquants.com/ebook#p=938)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To find the missing number in a list containing the integers from $1$ to $n$ with exactly one number missing, use the formula for the sum of the first $n$ positive integers.
>
> ### Step 1: Compute the expected sum
>
> The sum of all integers from $1$ to $n$ is
>
> $$
> S = \frac{n(n+1)}{2}.
> $$
>
> ### Step 2: Compute the actual sum of the given list
>
> Let the sum of the numbers present in the list be $T$.
>
> ### Step 3: Subtract to find the missing number
>
> The missing number is
>
> $$
> \text{Missing} = S - T = \frac{n(n+1)}{2} - T.
> $$
>
> ## Final Answer
>
> If the list contains all numbers from $1$ to $n$ except one, then the missing number is
>
> $$
> \boxed{\frac{n(n+1)}{2} - \sum \text{(elements of the list)}}.
> $$
>
> For example, if $n=5$ and the list is $[1,2,3,5]$, then
>
> $$
> \frac{5 \cdot 6}{2} = 15,\qquad 1+2+3+5=11,
> $$
>
> so the missing number is
>
> $$
> 15-11=4.
> $$
