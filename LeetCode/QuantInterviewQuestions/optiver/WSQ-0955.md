> [!example] Question 955 · Optiver
> ## Software Engineer Intern Interview

Design a double-ended queue (deque) data structure that supports efficient insertion and deletion from both ends. Explain the operations and their time complexities.

[Source](https://www.thewallstreetquants.com/ebook#p=956)

> [!success]- Solution (Click to expand)
> ## Design a Double-Ended Queue
>
> A double-ended queue, or **deque**, supports insertion and deletion at both the front and the rear. A standard design provides the following operations in constant time, $O(1)$.
>
> ### Required Operations
>
> - `insertFront()`
> - `insertLast()`
> - `deleteFront()`
> - `deleteLast()`
> - `getFront()`
> - `getRear()`
> - `isEmpty()`
> - `isFull()`
>
> A convenient implementation uses a **circular array**.
>
> ---
>
> ## Data Structure
>
> Maintain:
>
> - an array `q` of size $k$
> - an integer `front`
> - an integer `rear`
> - an integer `size`
>
> Interpretation:
>
> - `front` points to the first element
> - `rear` points to the last element
> - `size` is the current number of elements
>
> Initially:
>
> - `front = 0`
> - `rear = -1`
> - `size = 0`
>
> ---
>
> ## Circular Movement
>
> To wrap indices around the array:
>
> - move forward: $(i + 1) \bmod k$
> - move backward: $(i - 1 + k) \bmod k$
>
> This makes both ends usable without shifting elements.
>
> ---
>
> ## Operations
>
> ### 1. `insertFront(value)`
>
> If the deque is full, return `false`.
>
> If empty, the new element becomes both front and rear.
>
> Otherwise, move `front` backward by one position and place the value there.
>
> $$
> \text{front} = (\text{front} - 1 + k) \bmod k
> $$
>
> Then set:
>
> $$
> q[\text{front}] = \text{value}
> $$
>
> Increase `size`.
>
> ---
>
> ### 2. `insertLast(value)`
>
> If full, return `false`.
>
> Move `rear` forward:
>
> $$
> \text{rear} = (\text{rear} + 1) \bmod k
> $$
>
> Store the value at `rear`, then increase `size`.
>
> If this is the first element, `front` already correctly identifies it when initialized properly with size tracking.
>
> ---
>
> ### 3. `deleteFront()`
>
> If empty, return `false`.
>
> Remove the front element by moving `front` forward:
>
> $$
> \text{front} = (\text{front} + 1) \bmod k
> $$
>
> Decrease `size`.
>
> If after deletion the deque becomes empty, reset:
>
> - `front = 0`
> - `rear = -1`
>
> ---
>
> ### 4. `deleteLast()`
>
> If empty, return `false`.
>
> Move `rear` backward:
>
> $$
> \text{rear} = (\text{rear} - 1 + k) \bmod k
> $$
>
> Decrease `size`.
>
> If the deque becomes empty, reset:
>
> - `front = 0`
> - `rear = -1`
>
> ---
>
> ### 5. `getFront()`
>
> If empty, return `-1`; otherwise return:
>
> $$
> q[\text{front}]
> $$
>
> ---
>
> ### 6. `getRear()`
>
> If empty, return `-1`; otherwise return:
>
> $$
> q[\text{rear}]
> $$
>
> ---
>
> ### 7. `isEmpty()`
>
> Return whether:
>
> $$
> \text{size} = 0
> $$
>
> ---
>
> ### 8. `isFull()`
>
> Return whether:
>
> $$
> \text{size} = k
> $$
>
> ---
>
> ## Correctness
>
> Because the array is circular, every insertion or deletion only updates one index and possibly one array cell. No shifting is required. Thus:
>
> - front operations are $O(1)$
> - rear operations are $O(1)$
> - access operations are $O(1)$
>
> The structure uses $O(k)$ space.
>
> ---
>
> ## Reference Implementation
>
> ```python
> class MyCircularDeque:
>
>     def __init__(self, k: int):
>         self.k = k
>         self.q = [0] * k
>         self.front = 0
>         self.rear = -1
>         self.size = 0
>
>     def insertFront(self, value: int) -> bool:
>         if self.isFull():
>             return False
>         if self.size == 0:
>             self.front = 0
>             self.rear = 0
>             self.q[self.front] = value
>         else:
>             self.front = (self.front - 1 + self.k) % self.k
>             self.q[self.front] = value
>         self.size += 1
>         return True
>
>     def insertLast(self, value: int) -> bool:
>         if self.isFull():
>             return False
>         self.rear = (self.rear + 1) % self.k
>         self.q[self.rear] = value
>         if self.size == 0:
>             self.front = self.rear
>         self.size += 1
>         return True
>
>     def deleteFront(self) -> bool:
>         if self.isEmpty():
>             return False
>         self.size -= 1
>         if self.size == 0:
>             self.front = 0
>             self.rear = -1
>         else:
>             self.front = (self.front + 1) % self.k
>         return True
>
>     def deleteLast(self) -> bool:
>         if self.isEmpty():
>             return False
>         self.size -= 1
>         if self.size == 0:
>             self.front = 0
>             self.rear = -1
>         else:
>             self.rear = (self.rear - 1 + self.k) % self.k
>         return True
>
>     def getFront(self) -> int:
>         if self.isEmpty():
>             return -1
>         return self.q[self.front]
>
>     def getRear(self) -> int:
>         if self.isEmpty():
>             return -1
>         return self.q[self.rear]
>
>     def isEmpty(self) -> bool:
>         return self.size == 0
>
>     def isFull(self) -> bool:
>         return self.size == self.k
> ```
>
> ---
>
> ## Complexity
>
> Each operation runs in
>
> $$
> O(1)
> $$
>
> time, and the total space used is
>
> $$
> O(k)
> $$
>
> where $k$ is the deque capacity.
