> [!example] Question 935 · Optiver
> ## Software Engineer Interview

Given an encoded tree represented as a list of pairs of nodes, verify that the input is a valid tree and check whether there are any cycles in the structure.

[Source](https://www.thewallstreetquants.com/ebook#p=936)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Represent the input as a directed graph whose edges are the given pairs $(u,v)$, meaning that $u$ is the parent of $v$.
>
> To verify correctness, the following conditions must hold:
>
> 1. **Each child has at most one parent.**
> 2. **There is exactly one root** (a node with in-degree $0$).
> 3. **The graph is connected** when viewed from the root.
> 4. **There are no cycles.**
>
> ---
>
> ### Step 1: Build the graph
>
> For every pair $(u,v)$:
>
> - add $v$ to the adjacency list of $u$,
> - increase the in-degree of $v$,
> - ensure both $u$ and $v$ are recorded as existing nodes.
>
> While doing this, if some node $v$ receives more than one parent, the input is invalid.
>
> ---
>
> ### Step 2: Find the root
>
> After all pairs are processed, count nodes with in-degree $0$.
>
> - If the number of such nodes is not exactly $1$, the structure is not a tree.
> - Let that unique node be the root.
>
> ---
>
> ### Step 3: Detect cycles and check connectivity
>
> Perform a depth-first search starting from the root.
>
> During DFS, maintain for each node one of three states:
>
> - $0$: unvisited,
> - $1$: currently in recursion stack,
> - $2$: fully processed.
>
> When exploring an edge from $u$ to $v$:
>
> - if $v$ has state $1$, a back edge exists, hence there is a cycle;
> - if $v$ has state $0$, continue DFS on $v$.
>
> After DFS finishes:
>
> - if a cycle was found, the input is invalid;
> - if some node was never visited, the graph is disconnected, so it is not a tree.
>
> ---
>
> ## Correctness
>
> A directed graph is a rooted tree exactly when:
>
> - every node except the root has exactly one parent,
> - the root has no parent,
> - every node is reachable from the root,
> - and no directed cycle exists.
>
> The algorithm checks these properties directly:
>
> - multiple parents are detected while reading edges;
> - the unique root is determined from in-degrees;
> - DFS detects cycles via recursion-stack revisits;
> - DFS visitation count ensures connectivity.
>
> Therefore, the algorithm accepts exactly correct encoded trees and rejects all invalid inputs, including those containing cycles.
>
> ---
>
> ## Complexity
>
> Let $n$ be the number of nodes and $m$ the number of pairs.
>
> - Building the graph: $O(m)$
> - Root search: $O(n)$
> - DFS: $O(n+m)$
>
> Thus the total running time is
>
> $$
> O(n+m),
> $$
>
> with memory usage
>
> $$
> O(n+m).
> $$
>
> ---
>
> ## Final answer
>
> To read and verify an encoded tree:
>
> 1. construct the directed graph from the pairs,
> 2. ensure no node has more than one parent,
> 3. ensure exactly one root exists,
> 4. run DFS from the root to detect cycles,
> 5. verify that all nodes are reached.
>
> If all checks pass, the input encodes a valid tree; otherwise it is incorrect.
