> [!example] Question 972 · Optiver
> ## Senior Software Developer Interview

Given a mapping of 7 letters to their respective Morse code representations and a string of dots and dashes (with no spaces), find all valid interpretations of the Morse code string as sequences of those letters.

[Source](https://www.thewallstreetquants.com/ebook#p=973)

> [!success]- Solution (Click to expand)
> ## Solution
>
> This is a standard **string decoding** problem. We are given:
>
> - a mapping from each of $7$ letters to a Morse code string of dots and dashes,
> - one long Morse string $s$ with no separators,
>
> and we must find **all possible ways** to split $s$ into valid codewords from the mapping.
>
> ---
>
> ## Key idea
>
> A decoding is valid if the string can be partitioned into consecutive pieces such that each piece is exactly the Morse code of one of the letters.
>
> This naturally suggests **backtracking**:
>
> - At position $i$ in the Morse string,
> - try every letter whose Morse code matches the prefix starting at $i$,
> - recursively decode the remainder,
> - when we reach the end of the string, we have found one complete interpretation.
>
> If only the number of interpretations were needed, dynamic programming would suffice. Since the problem asks for **all valid interpretations**, we must actually build them.
>
> ---
>
> ## Recursive formulation
>
> Let:
>
> - $s$ be the Morse string of length $n$,
> - $code(c)$ be the Morse code for letter $c$.
>
> Define $decode(i)$ to be the set of all valid letter strings that decode the suffix $s[i:]$.
>
> Then:
>
> - Base case:
>   - if $i = n$, there is one valid decoding of the empty suffix: the empty string.
> - Transition:
>   - for every letter $c$ such that $s[i:]$ starts with $code(c)$,
>     append $c$ to every decoding in $decode(i + |code(c)|)$.
>
> This gives the recurrence
> $$
> decode(i)
> =
> \bigcup_{\substack{c \\ s[i:i+|code(c)|] = code(c)}}
> \{\, c + t \mid t \in decode(i+|code(c)|)\,\}.
> $$
>
> ---
>
> ## Memoization
>
> Without memoization, the same suffix may be decoded many times.  
> To avoid repeated work, store the result of $decode(i)$ after computing it once.
>
> Thus each index $i$ is solved at most one time.
>
> ---
>
> ## Algorithm
>
> 1. Store the $7$ letter-to-Morse mappings.
> 2. Use a depth-first search from index $0$.
> 3. At each index, test all $7$ codes:
>    - if a code matches the string at that position, recurse on the next position.
> 4. Combine the current letter with all suffix decodings.
> 5. Return all full decodings from index $0$.
>
> ---
>
> ## Pseudocode
>
> ```python
> def all_decodings(s, mapping):
>     # mapping: letter -> morse
>     n = len(s)
>     memo = {}
>
>     def dfs(i):
>         if i == n:
>             return [""]   # one way to decode empty suffix
>         if i in memo:
>             return memo[i]
>
>         ans = []
>         for letter, morse in mapping.items():
>             if s.startswith(morse, i):
>                 suffixes = dfs(i + len(morse))
>                 for suf in suffixes:
>                     ans.append(letter + suf)
>
>         memo[i] = ans
>         return ans
>
>     return dfs(0)
> ```
>
> If the output should show letters separated for clarity, one may store lists of letters instead of concatenated strings.
>
> ---
>
> ## Example
>
> Suppose the mapping is
>
> $$
> A \to .
> \qquad
> B \to -
> \qquad
> C \to ..
> \qquad
> D \to .-
> \qquad
> E \to -.
> \qquad
> F \to --
> \qquad
> G \to ...
> $$
>
> and the input is
>
> $$
> s = ...
> $$
>
> From the beginning:
>
> - $.$ matches $A$, leaving $..$
> - $..$ matches $C$, leaving $.$
> - $...$ matches $G$, leaving nothing
>
> Exploring all branches gives:
>
> - $AAA$
> - $AC$
> - $CA$
> - $G$
>
> and possibly others depending on the exact mapping.
>
> The method systematically finds every valid interpretation.
>
> ---
>
> ## Correctness argument
>
> We prove that the algorithm returns exactly all valid decodings.
>
> ### Lemma
> For any index $i$, $dfs(i)$ returns all valid decodings of the suffix $s[i:]$.
>
> ### Proof
> By induction on the suffix length $n-i$.
>
> - **Base case:** If $i=n$, the suffix is empty. There is exactly one decoding of the empty suffix: the empty string. The algorithm returns $[""]$, so the result is correct.
>
> - **Inductive step:** Assume the claim holds for all larger indices. At index $i$, any valid decoding of $s[i:]$ must begin with some letter $c$ whose Morse code matches the prefix of $s[i:]$. After choosing $c$, the remainder must be a valid decoding of the suffix starting at $i+|code(c)|$. By the induction hypothesis, $dfs(i+|code(c)|)$ returns exactly all such remainder decodings. Therefore, concatenating $c$ with each of them yields exactly all valid decodings beginning with $c$. Taking the union over all matching letters gives exactly all valid decodings of $s[i:]$.
>
> Thus $dfs(i)$ is correct for all $i$, in particular for $i=0$.
>
> $\square$
>
> ---
>
> ## Complexity
>
> Let:
>
> - $n = |s|$,
> - $k = 7$ be the number of letters.
>
> At each position, we test up to $k$ Morse codes. With memoization, there are only $n+1$ subproblems.
>
> So the structural work is
> $$
> O(nk).
> $$
>
> However, the total running time must also include the size of the output, since there may be many valid interpretations. If there are $R$ results of average length $L$, then total time is at least
> $$
> \Omega(RL).
> $$
>
> Hence the full complexity is
> $$
> O(nk + \text{total output size}).
> $$
>
> The memo table stores all decodings for suffixes, so space usage is also proportional to the total stored output.
>
> ---
>
> ## Final answer
>
> Use **recursive backtracking with memoization** on the Morse string index:
>
> - from each position, try every letter whose Morse code matches there,
> - recursively decode the remaining suffix,
> - collect all complete letter sequences.
>
> This produces **all valid interpretations** of the Morse string, even when there are no spaces between letters.
