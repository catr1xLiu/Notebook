> [!example] Question 999 · Optiver
> ## Trader Interview

Find the largest 5-digit number such that the pairwise digit sums of its digits are all unique. Find the smallest 5-digit number with the same property. Explain why this property does not work for 7-digit numbers. Does it work for 6-digit numbers?

[Source](https://www.thewallstreetquants.com/ebook#p=1000)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Interpret the condition as follows: for a number with digits $d_1,d_2,\dots,d_n$, all pairwise sums
> $$
> d_i+d_j \qquad (1\le i<j\le n)
> $$
> must be distinct.
>
> Thus the set of digits used must have the property that all of its pairwise sums are different. This is exactly the condition that the set of digits forms a **Sidon set** within $\{0,1,2,\dots,9\}$: if two different pairs had the same sum, the condition would fail.
>
> For a fixed valid digit set, the largest number using those digits is obtained by arranging them in descending order (with the largest digit first), and the smallest is obtained by arranging them in ascending order, but with the smallest *nonzero* digit placed first so that the number does not begin with $0$.
>
> ---
>
> ## 1. Largest $5$-digit number
>
> To maximize the number, choose the digits from largest to smallest, at each step taking the largest remaining digit that keeps all pairwise sums, among the digits chosen so far, distinct.
>
> Start with the three largest digits, $9,8,7$. Their pairwise sums are
> $$
> 9+8=17,\qquad 9+7=16,\qquad 8+7=15,
> $$
> all distinct, so $\{9,8,7\}$ is valid so far.
>
> For the fourth digit, try the largest remaining candidate, $6$: it gives $9+6=15$, which collides with $8+7=15$, so $6$ is rejected. The next candidate, $5$, gives sums $9+5=14$, $8+5=13$, $7+5=12$, none of which collide with $17,16,15$, so $5$ is accepted. The set so far is $\{9,8,7,5\}$.
>
> For the fifth digit, the remaining candidates in decreasing order are $6,4,3,2,1,0$ ($6$ having already failed at the previous step regardless of what else is chosen, since $9+6=8+7$ always). Checking in order:
>
> - $4$: gives $9+4=13$, which collides with $8+5=13$; rejected.
> - $3$: gives $9+3=12$, which collides with $7+5=12$; rejected.
> - $2$: gives $9+2=11$, $8+2=10$, $7+2=9$, $5+2=7$, none of which collide with the six sums already in use ($17,16,15,14,13,12$); accepted.
>
> This gives the digit set
> $$
> \{2,5,7,8,9\},
> $$
> whose ten pairwise sums are
> $$
> 7,9,10,11,12,13,14,15,16,17,
> $$
> all distinct. Arranging these digits in descending order gives the largest valid $5$-digit number:
> $$
> \boxed{98752}.
> $$
>
> Since at each position this construction always chose the largest digit for which a valid completion exists (each choice was in fact completed successfully), no larger arrangement of any valid digit set can produce a bigger number.
>
> ---
>
> ## 2. Smallest $5$-digit number
>
> To minimize the number, choose digits from smallest to largest, at each step taking the smallest remaining candidate (skipping $0$ only for the very first, leading digit) that keeps all pairwise sums distinct so far.
>
> The leading digit cannot be $0$, so take the smallest allowed value, $1$.
>
> For the second digit, try $0$: the set $\{1,0\}$ has the single sum $0+1=1$, trivially fine. Accept $0$.
>
> For the third digit, try the smallest remaining candidate, $2$: the set $\{0,1,2\}$ has sums $0+1=1$, $0+2=2$, $1+2=3$, all distinct. Accept $2$.
>
> For the fourth digit, try $3$: the set $\{0,1,2,3\}$ has $0+3=3$, which collides with $1+2=3$; rejected. Try $4$: the set $\{0,1,2,4\}$ has sums $0+1=1$, $0+2=2$, $0+4=4$, $1+2=3$, $1+4=5$, $2+4=6$, all distinct. Accept $4$.
>
> For the fifth digit, the remaining candidates in increasing order are $3,5,6,7,8,9$. Checking in order:
>
> - $3$: $\{0,1,2,3,4\}$ again has $0+3=3=1+2$; rejected.
> - $5$: $\{0,1,2,4,5\}$ has $0+5=5$, which collides with $1+4=5$; rejected.
> - $6$: $\{0,1,2,4,6\}$ has $0+6=6$, which collides with $2+4=6$; rejected.
> - $7$: $\{0,1,2,4,7\}$ has sums $1,2,4,7,3,5,8,6,9,11$, all distinct; accepted.
>
> This gives the digit set
> $$
> \{0,1,2,4,7\}.
> $$
>
> Arranging these digits with the smallest nonzero digit first, then the rest in ascending order, gives the smallest valid $5$-digit number:
> $$
> \boxed{10247}.
> $$
>
> ---
>
> ## 3. Why it does not work for $7$-digit numbers
>
> For $7$ digits, there are
> $$
> \binom{7}{2}=21
> $$
> pairwise sums to make distinct.
>
> Since digits must be distinct (otherwise the two equal digits alone would force a repeated sum with any third digit) and lie in $\{0,1,\dots,9\}$, every pairwise sum lies between
> $$
> 0+1=1
> $$
> and
> $$
> 9+8=17.
> $$
>
> So there are at most $17$ possible values for the pairwise sums, but $21$ distinct sums would be needed. Since
> $$
> 21>17,
> $$
> this is impossible. Therefore no $7$-digit number can have this property.
>
> ---
>
> ## 4. Does it work for $6$-digit numbers?
>
> For $6$ digits, there are
> $$
> \binom{6}{2}=15
> $$
> pairwise sums, and since the possible sums lie among $1,2,\dots,17$, there are $17$ possible values — so the counting argument used above does not rule this case out by itself.
>
> A direct check is needed instead. A systematic check of all
> $$
> \binom{10}{6}=210
> $$
> six-element subsets of $\{0,1,\dots,9\}$ shows that every one of them contains at least one repeated pairwise sum: no $6$-element Sidon subset of $\{0,1,\dots,9\}$ exists. Hence no $6$-digit number can have this property either.
>
> ---
>
> ## Summary
>
> - largest $5$-digit number:
> $$
> \boxed{98752}
> $$
> - smallest $5$-digit number:
> $$
> \boxed{10247}
> $$
> - $7$-digit numbers: impossible, since
> $$
> \binom{7}{2}=21>17
> $$
> - $6$-digit numbers: also impossible, as confirmed by checking all $210$ candidate digit sets.
