> [!example] Question 977 · Optiver
> ## Graduate Software Engineer Interview

Given an array of integers, find the maximum possible sum of any non-empty contiguous subarray.

[Source](https://www.thewallstreetquants.com/ebook#p=978)

> [!success]- Solution (Click to expand)
> ## Solution
>
> This is the classic **maximum subarray sum** problem. The standard optimal method is **Kadane’s algorithm**, which runs in linear time.
>
> ### Idea
>
> As we scan the array from left to right, for each position we keep track of:
>
> - the maximum sum of a subarray that **must end** at the current position,
> - the maximum sum seen **anywhere so far**.
>
> If the current running sum becomes worse than starting fresh from the current element, we start a new subarray.
>
> ### Recurrence
>
> Let the array be $a_1, a_2, \dots, a_n$.
>
> Define:
>
> - $curr_i$ = maximum subarray sum ending at index $i$,
> - $best_i$ = maximum subarray sum among the first $i$ elements.
>
> Then
>
> $$
> curr_i = \max(a_i,\; curr_{i-1} + a_i)
> $$
>
> and
>
> $$
> best_i = \max(best_{i-1},\; curr_i)
> $$
>
> ### Algorithm
>
> 1. Initialize:
>    - $curr = a_1$
>    - $best = a_1$
> 2. For each remaining element $a_i$:
>    - update $curr = \max(a_i,\; curr + a_i)$
>    - update $best = \max(best,\; curr)$
> 3. Return $best$
>
> ### Example
>
> For the array
>
> $$
> [-2, 1, -3, 4, -1, 2, 1, -5, 4]
> $$
>
> the running values are:
>
> - start: $curr = -2$, $best = -2$
> - with $1$: $curr = \max(1, -2+1)=1$, $best=1$
> - with $-3$: $curr = \max(-3, 1-3)=-2$, $best=1$
> - with $4$: $curr = \max(4, -2+4)=4$, $best=4$
> - with $-1$: $curr = \max(-1, 4-1)=3$, $best=4$
> - with $2$: $curr = \max(2, 3+2)=5$, $best=5$
> - with $1$: $curr = \max(1, 5+1)=6$, $best=6$
> - with $-5$: $curr = \max(-5, 6-5)=1$, $best=6$
> - with $4$: $curr = \max(4, 1+4)=5$, $best=6$
>
> So the highest subarray sum is
>
> $$
> 6
> $$
>
> from the subarray
>
> $$
> [4, -1, 2, 1]
> $$
>
> ### Code
>
> ```python
> def max_subarray(arr):
>     curr = best = arr[0]
>     for x in arr[1:]:
>         curr = max(x, curr + x)
>         best = max(best, curr)
>     return best
> ```
>
> ### Complexity
>
> - Time: $O(n)$
> - Space: $O(1)$
>
> Thus, the highest sum of a subarray can be found efficiently using Kadane’s algorithm.
