> [!example] Question 883 · Optiver
> ## Software Engineer Interview

How much memory is required to store a linked list with 1,000 elements?

[Source](https://www.thewallstreetquants.com/ebook#p=884)

> [!success]- Solution (Click to expand)
> For a linked list, the memory usage is the sum of:
>
> 1. the memory for each **data field**, and  
> 2. the memory for each **pointer** to the next node.
>
> If the list has $1000$ elements, then:
>
> $$
> \text{Total memory} = 1000 \times (\text{size of data} + \text{size of pointer})
> $$
>
> ### Common example
> If each node stores:
>
> - an `int` of size $4$ bytes, and
> - one pointer of size $8$ bytes on a $64$-bit system,
>
> then each node uses:
>
> $$
> 4 + 8 = 12 \text{ bytes}
> $$
>
> So for $1000$ nodes:
>
> $$
> 1000 \times 12 = 12000 \text{ bytes}
> $$
>
> That is approximately:
>
> $$
> \frac{12000}{1024} \approx 11.7 \text{ KB}
> $$
>
> ### With structure padding
> In practice, many systems align memory, so a node with a $4$-byte `int` and an $8$-byte pointer may actually occupy $16$ bytes rather than $12$.
>
> Then the total is:
>
> $$
> 1000 \times 16 = 16000 \text{ bytes}
> $$
>
> which is about
>
> $$
> \frac{16000}{1024} \approx 15.6 \text{ KB}
> $$
>
> ### Final answer
> For a $1000$-element linked list, the memory is
>
> $$
> 1000 \times (\text{data size} + \text{pointer size})
> $$
>
> For the common case of an `int` and one next pointer, it is typically about:
>
> - $12000$ bytes ideally, or
> - $16000$ bytes with padding/alignment.
