> ## Software Engineer Interview

Describe how you would store and sort the prices of items coming from multiple exchanges. Write code to demonstrate your approach.

> ## Storing and Sorting Prices from Multiple Exchanges
>
> A convenient way to represent prices coming from multiple exchanges is to store each quote as a record containing:
>
> - the exchange name,
> - the item name,
> - the price.
>
> Then, all records can be collected in a list and sorted by any field of interest, such as price, exchange, or item.
>
> A natural data structure is:
>
> - a **dictionary** for each quote, or
> - a **class/dataclass** for stronger structure.
>
> The general idea is:
>
> 1. Collect quotes from all exchanges.
> 2. Store them in a single list.
> 3. Sort the list using a key such as price.
>
> ---
>
> ## Example Using Python `dataclass`
>
> ```python
> from dataclasses import dataclass
>
> @dataclass
> class Quote:
>     exchange: str
>     item: str
>     price: float
>
> quotes = [
>     Quote("ExchangeA", "BTC", 67250.10),
>     Quote("ExchangeB", "BTC", 67180.55),
>     Quote("ExchangeC", "BTC", 67310.00),
>     Quote("ExchangeA", "ETH", 3450.25),
>     Quote("ExchangeB", "ETH", 3442.10),
>     Quote("ExchangeC", "ETH", 3461.75),
> ]
>
> # Sort all quotes by price ascending
> quotes_by_price = sorted(quotes, key=lambda q: q.price)
>
> for q in quotes_by_price:
>     print(q)
> ```
>
> ### Output behavior
> This produces the quotes ordered from the lowest price to the highest price.
>
> ---
>
> ## Grouping by Item First
>
> If multiple items are present, it is often useful to group quotes by item and then sort within each group.
>
> ```python
> from collections import defaultdict
> from dataclasses import dataclass
>
> @dataclass
> class Quote:
>     exchange: str
>     item: str
>     price: float
>
> quotes = [
>     Quote("ExchangeA", "BTC", 67250.10),
>     Quote("ExchangeB", "BTC", 67180.55),
>     Quote("ExchangeC", "BTC", 67310.00),
>     Quote("ExchangeA", "ETH", 3450.25),
>     Quote("ExchangeB", "ETH", 3442.10),
>     Quote("ExchangeC", "ETH", 3461.75),
> ]
>
> grouped = defaultdict(list)
>
> for q in quotes:
>     grouped[q.item].append(q)
>
> for item in grouped:
>     grouped[item].sort(key=lambda q: q.price)
>
> for item, item_quotes in grouped.items():
>     print(f"\n{item}:")
>     for q in item_quotes:
>         print(f"  {q.exchange}: {q.price}")
> ```
>
> This stores all prices for each item and sorts them from cheapest to most expensive across exchanges.
>

> ## Using a Nested Dictionary
>
> Another useful structure is a nested dictionary of the form:
>
> ```python
> prices = {
>     "BTC": {
>         "ExchangeA": 67250.10,
>         "ExchangeB": 67180.55,
>         "ExchangeC": 67310.00,
>     },
>     "ETH": {
>         "ExchangeA": 3450.25,
>         "ExchangeB": 3442.10,
>         "ExchangeC": 3461.75,
>     }
> }
> ```
>
> To sort exchanges by price for a given item:
>
> ```python
> prices = {
>     "BTC": {
>         "ExchangeA": 67250.10,
>         "ExchangeB": 67180.55,
>         "ExchangeC": 67310.00,
>     },
>     "ETH": {
>         "ExchangeA": 3450.25,
>         "ExchangeB": 3442.10,
>         "ExchangeC": 3461.75,
>     }
> }
>
> for item, exchange_prices in prices.items():
>     sorted_exchanges = sorted(exchange_prices.items(), key=lambda x: x[1])
>     print(f"\n{item}:")
>     for exchange, price in sorted_exchanges:
>         print(f"  {exchange}: {price}")
> ```
>
> ---
>
> ## Best Practical Choice
>
> If the goal is flexibility and easy sorting, use a **list of structured records** such as `Quote`.  
> If the goal is fast lookup of a particular item and exchange, use a **nested dictionary**.
>
> A strong combined approach is:
>
> - store raw data in a nested dictionary for lookup,
> - convert to a list when sorting or ranking is needed.
>
> ---
>
> ## Example with Both Storage and Best-Price Query
>
> ```python
> from dataclasses import dataclass
>
> @dataclass
> class Quote:
>     exchange: str
>     item: str
>     price: float
>
> prices = {
>     "BTC": {
>         "ExchangeA": 67250.10,
>         "ExchangeB": 67180.55,
>         "ExchangeC": 67310.00,
>     },
>     "ETH": {
>         "ExchangeA": 3450.25,
>         "ExchangeB": 3442.10,
>         "ExchangeC": 3461.75,
>     }
> }
>
> # Convert nested dictionary to a flat list of Quote objects
> quotes = [
>     Quote(exchange, item, price)
>     for item, exchanges in prices.items()
>     for exchange, price in exchanges.items()
> ]
>
> # Sort by item, then by price
> quotes_sorted = sorted(quotes, key=lambda q: (q.item, q.price))
>
> for q in quotes_sorted:
>     print(q)
>
> # Find best price for each item
> for item, exchanges in prices.items():
>     best_exchange, best_price = min(exchanges.items(), key=lambda x: x[1])
>     print(f"Best price for {item}: {best_price} at {best_exchange}")
> ```
>
> ## Conclusion
>
> To store prices from multiple exchanges, use either:
>
> - a list of records such as `Quote(exchange, item, price)`, or
> - a nested dictionary such as `prices[item][exchange] = price`.
>
> To sort prices, use Python’s `sorted(..., key=...)` or list `.sort(...)`, typically with price as the sorting key. The list-of-records approach is best for ranking and reporting, while the nested-dictionary approach is best for direct lookup.
