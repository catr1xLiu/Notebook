> [!example] Question 886 · Optiver
> ## Software Engineer Interview

Given an array of stock prices over n days, return the maximum profit that can be achieved with at most k transactions. Implement the function int stock(int\* prices, int k, int n).

[Source](https://www.thewallstreetquants.com/ebook#p=887)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A transaction consists of one buy followed by one sell, and at most $k$ such transactions are allowed. The goal is to maximize total profit.
>
> ---
>
> ## Dynamic Programming Formulation
>
> Let
>
> $$
> dp[t][i]
> $$
>
> denote the maximum profit obtainable using at most $t$ transactions in the first $i+1$ days, that is, among prices indexed from $0$ to $i$.
>
> For each day $i$ and transaction count $t$:
>
> - Either no transaction ends on day $i$, so the profit remains
>
> $$
> dp[t][i-1]
> $$
>
> - Or the $t$-th transaction sells on day $i$. Suppose it was bought on day $j < i$. Then the profit is
>
> $$
> dp[t-1][j-1] + prices[i] - prices[j]
> $$
>
> Taking the best over all $j$ gives
>
> $$
> dp[t][i] = \max\left(dp[t][i-1], \max_{0 \le j < i}\left(dp[t-1][j-1] + prices[i] - prices[j]\right)\right)
> $$
>
> To avoid the inner $j$ loop, maintain
>
> $$
> best = \max_{0 \le j < i}\left(dp[t-1][j-1] - prices[j]\right)
> $$
>
> Then
>
> $$
> dp[t][i] = \max(dp[t][i-1], prices[i] + best)
> $$
>
> and update
>
> $$
> best = \max(best, dp[t-1][i-1] - prices[i])
> $$
>
> This reduces the time complexity to $O(kn)$.
>
> ---
>
> ## Special Case
>
> If
>
> $$
> k \ge \left\lfloor \frac{n}{2} \right\rfloor
> $$
>
> then the transaction limit is effectively irrelevant, because one can complete as many profitable upward moves as possible. In that case, the answer is simply
>
> $$
> \sum_{i=1}^{n-1} \max(0, prices[i] - prices[i-1])
> $$
>
> which runs in $O(n)$ time.
>
> ---
>
> ## Algorithm
>
> 1. If $n = 0$ or $k = 0$, return $0$.
> 2. If $k \ge n/2$, use the unlimited-transactions greedy solution.
> 3. Otherwise, compute the dynamic programming table using the optimized recurrence.
>
> ---
>
> ## C Implementation
>
> ```c
> #include <stdlib.h>
>
> int stock(int* prices, int k, int n) {
>     if (n <= 1 || k == 0) return 0;
>
>     /* Unlimited transactions case */
>     if (k >= n / 2) {
>         int profit = 0;
>         for (int i = 1; i < n; i++) {
>             if (prices[i] > prices[i - 1]) {
>                 profit += prices[i] - prices[i - 1];
>             }
>         }
>         return profit;
>     }
>
>     int** dp = (int**)malloc((k + 1) * sizeof(int*));
>     for (int t = 0; t <= k; t++) {
>         dp[t] = (int*)calloc(n, sizeof(int));
>     }
>
>     for (int t = 1; t <= k; t++) {
>         int best = -prices[0];
>         for (int i = 1; i < n; i++) {
>             int candidate = prices[i] + best;
>             dp[t][i] = dp[t][i - 1] > candidate ? dp[t][i - 1] : candidate;
>
>             int value = dp[t - 1][i - 1] - prices[i];
>             if (value > best) best = value;
>         }
>     }
>
>     int ans = dp[k][n - 1];
>
>     for (int t = 0; t <= k; t++) {
>         free(dp[t]);
>     }
>     free(dp);
>
>     return ans;
> }
> ```
>
> ---
>
> ## Complexity
>
> - In the general case, the time complexity is
>
> $$
> O(kn)
> $$
>
> - The space complexity is
>
> $$
> O(kn)
> $$
>
> This can be reduced to $O(n)$ by keeping only the previous and current transaction rows.
>
> ---
>
> ## Final Answer
>
> The maximum profit with at most $k$ transactions can be computed using dynamic programming in $O(kn)$ time with the recurrence
>
> $$
> dp[t][i] = \max(dp[t][i-1], prices[i] + best)
> $$
>
> where
>
> $$
> best = \max(best, dp[t-1][i-1] - prices[i]).
> $$
>
> The provided implementation correctly returns the required maximum profit.
