> [!example] Question 932 · Optiver
> ## Software Engineer Interview

Given an array of integers, find the third largest number in the array.

[Source](https://www.thewallstreetquants.com/ebook#p=933)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To find the **third largest number in an array**, the simplest method is:
>
> 1. Remove duplicates if “third largest” means the third distinct value.
> 2. Sort the array in decreasing order.
> 3. Take the element at index $2$.
>
> ### Example
>
> Given the array
>
> $$
> [4, 1, 7, 9, 3, 7, 5]
> $$
>
> The distinct values are
>
> $$
> [4, 1, 7, 9, 3, 5]
> $$
>
> Sorting in descending order gives
>
> $$
> [9, 7, 5, 4, 3, 1]
> $$
>
> Thus, the third largest number is
>
> $$
> 5
> $$
>
> ---
>
> ## Algorithm
>
> For an array $A$:
>
> 1. Convert $A$ to a set to remove duplicates.
> 2. If the number of distinct elements is less than $3$, then the third largest does not exist.
> 3. Otherwise, sort the distinct elements in descending order.
> 4. Return the element at position $3$.
>
> ---
>
> ## Python implementation
>
> ```python
> def third_largest(arr):
>     distinct = list(set(arr))
>     if len(distinct) < 3:
>         return None
>     distinct.sort(reverse=True)
>     return distinct[2]
> ```
>
> ### Example run
>
> ```python
> arr = [4, 1, 7, 9, 3, 7, 5]
> print(third_largest(arr))
> ```
>
> Output:
>
> ```python
> 5
> ```
>
> ---
>
> ## More efficient approach
>
> A sorting-based method takes $O(n \log n)$ time.  
> A more efficient method scans the array once and keeps track of the top three distinct values.
>
> ### Python implementation
>
> ```python
> def third_largest(arr):
>     first = second = third = None
>
>     for x in arr:
>         if x == first or x == second or x == third:
>             continue
>
>         if first is None or x > first:
>             third = second
>             second = first
>             first = x
>         elif second is None or x > second:
>             third = second
>             second = x
>         elif third is None or x > third:
>             third = x
>
>     return third
> ```
>
> This method runs in $O(n)$ time and uses $O(1)$ extra space.
>
> ## Final answer
>
> The **third largest number** is the third highest **distinct** value in the array. It can be found either by:
>
> - sorting the distinct elements and taking the third one, or
> - scanning once while maintaining the largest, second largest, and third largest values.
>
> For the example array $[4, 1, 7, 9, 3, 7, 5]$, the third largest number is
>
> $$
> 5
> $$
