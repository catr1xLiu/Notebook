> ## SWE Intern Interview

What is memory fragmentation, and how can it impact performance?

[Source](https://www.thewallstreetquants.com/ebook#p=962)

> [!success]- Solution (Click to expand)
> ## Memory Fragmentation
>
> Memory fragmentation is a condition in which available memory becomes split into many small, noncontiguous pieces over time, making it harder for a system to use memory efficiently.
>
> There are two main kinds of fragmentation:
>
> ### 1. External Fragmentation
> External fragmentation occurs when free memory exists, but it is scattered into small blocks separated by allocated regions. As a result, a program may fail to obtain a large contiguous block of memory even though the total amount of free memory is sufficient.
>
> For example, suppose the free blocks have sizes $10$, $15$, and $20$ units. The total free memory is $45$ units, but a request for $30$ contiguous units cannot be satisfied if no single block is large enough.
>
> ### 2. Internal Fragmentation
> Internal fragmentation occurs when a memory allocator gives a process a block larger than requested, and the unused space inside that allocated block is wasted.
>
> For example, if memory is allocated in fixed-size blocks of $8$ units and a program requests $6$ units, then $2$ units are unused inside the block.
>
> ## How Fragmentation Impacts Performance
>
> Fragmentation can degrade performance in several ways:
>
> ### Reduced Usable Memory
> Even if the system has a significant amount of total free memory, fragmentation can prevent effective use of that memory. This may lead to allocation failures or force the system to request more memory from the operating system.
>
> ### Slower Allocation and Deallocation
> As memory becomes fragmented, allocators may need to search through longer lists of free blocks to find suitable space. This increases the time required for memory allocation and deallocation.
>
> ### Poor Cache and Locality Behavior
> When data that should be stored close together becomes scattered in memory, spatial locality worsens. This can increase cache misses and reduce overall execution speed.
>
> ### Increased Paging or Swapping
> In systems using virtual memory, inefficient memory layout can contribute to more page faults or greater paging activity, which significantly slows performance.
>
> ### Need for Compaction or Garbage Collection Overhead
> Some systems attempt to reduce fragmentation by compacting memory or moving objects during garbage collection. While this can restore efficiency, it also consumes CPU time and may pause program execution.
>
> ## Summary
>
> Memory fragmentation is the inefficient use of memory caused by scattered free space or wasted space inside allocated blocks. It can reduce the amount of usable memory, slow allocation, hurt cache performance, and increase system overhead.
