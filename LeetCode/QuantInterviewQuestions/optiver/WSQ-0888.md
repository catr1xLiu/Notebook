> [!example] Question 888 · Optiver
> ## Software Engineer Interview

Implement a queue data structure class without being able to resize the underlying memory allocation.

[Source](https://www.thewallstreetquants.com/ebook#p=889)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To implement a queue without resizing memory, use a **circular array** (also called a **ring buffer**).  
> This allows all operations to run in $O(1)$ time while using a fixed-size block of memory.
>
> A queue supports:
>
> - **enqueue**: insert at the rear
> - **dequeue**: remove from the front
> - **front**: read the front element
> - **empty/full** checks
>
> ---
>
> ## Idea: Circular Buffer
>
> If a fixed array of size $n$ is used, then after some dequeues there may be free space at the beginning of the array.  
> Instead of shifting elements, treat the array as circular.
>
> Maintain:
>
> - `data`: fixed-size array
> - `head`: index of the front element
> - `tail`: index where the next element will be inserted
> - `count`: current number of elements
> - `capacity`: maximum number of elements
>
> Then:
>
> - enqueue at index `tail`
> - advance `tail` by one modulo `capacity`
> - dequeue from index `head`
> - advance `head` by one modulo `capacity`
>
> The modulo operation wraps indices back to the start:
>
> $$
> \text{next}(i) = (i+1) \bmod \text{capacity}
> $$
>
> ---
>
> ## C++ Implementation
>
> ```cpp
> #include <iostream>
> #include <stdexcept>
> using namespace std;
>
> template <typename T>
> class Queue {
> private:
>     T* data;
>     int head;
>     int tail;
>     int count;
>     int capacity;
>
> public:
>     Queue(int size) : head(0), tail(0), count(0), capacity(size) {
>         if (size <= 0) {
>             throw invalid_argument("Queue size must be positive");
>         }
>         data = new T[capacity];
>     }
>
>     ~Queue() {
>         delete[] data;
>     }
>
>     bool empty() const {
>         return count == 0;
>     }
>
>     bool full() const {
>         return count == capacity;
>     }
>
>     int size() const {
>         return count;
>     }
>
>     void enqueue(const T& value) {
>         if (full()) {
>             throw overflow_error("Queue is full");
>         }
>         data[tail] = value;
>         tail = (tail + 1) % capacity;
>         count++;
>     }
>
>     T dequeue() {
>         if (empty()) {
>             throw underflow_error("Queue is empty");
>         }
>         T value = data[head];
>         head = (head + 1) % capacity;
>         count--;
>         return value;
>     }
>
>     T front() const {
>         if (empty()) {
>             throw underflow_error("Queue is empty");
>         }
>         return data[head];
>     }
> };
> ```
>
> ---
>
> ## Example Usage
>
> ```cpp
> int main() {
>     Queue<int> q(5);
>
>     q.enqueue(10);
>     q.enqueue(20);
>     q.enqueue(30);
>
>     cout << q.dequeue() << endl; // 10
>     cout << q.front() << endl;   // 20
>
>     q.enqueue(40);
>     q.enqueue(50);
>     q.enqueue(60);
>
>     while (!q.empty()) {
>         cout << q.dequeue() << " ";
>     }
>     cout << endl;
>
>     return 0;
> }
> ```
>
> ---
>
> ## Why This Works
>
> At all times:
>
> - the front element is at index `head`
> - the next insertion position is `tail`
> - the number of valid elements is `count`
>
> Because indices are updated modulo `capacity`, the array is reused cyclically, so no resizing is needed.
>
> ---
>
> ## Complexity
>
> - `enqueue`: $O(1)$
> - `dequeue`: $O(1)$
> - `front`: $O(1)$
> - Space: $O(n)$ fixed memory
>
> ---
>
> ## Final Answer
>
> A queue without memory resizing is best implemented using a **fixed-size circular array**. This provides constant-time queue operations and avoids shifting elements or allocating new memory.
