> [!example] Question 927 · Optiver
> ## Software Engineer Interview

Given the edges of a tree, output the pre-order traversal of the tree.

[Source](https://www.thewallstreetquants.com/ebook#p=928)

> [!success]- Solution (Click to expand)
> A preorder traversal cannot be determined from the edges of a tree alone unless additional structure is specified.
>
> To produce a unique preorder traversal, one must know at least:
>
> - which node is the **root**, and
> - the **left-to-right order of children** for each node  
>   (or, for a binary tree, which child is **left** and which is **right**).
>
> This is because preorder traversal is defined as:
>
> $$
> \text{visit root} \;\to\; \text{traverse children from left to right in preorder}.
> $$
>
> If only an undirected edge list is given, many different rooted/ordered trees can correspond to the same set of edges, yielding different preorder outputs.
>
> ## What is needed
>
> Given:
>
> 1. an edge list,
> 2. a designated root $r$,
> 3. an ordering of children for each node,
>
> the preorder traversal is obtained by:
>
> 1. output the current node,
> 2. recursively output each child in the specified order.
>
> ## Example
>
> If the edges are
>
> $$
> (A,B),\ (A,C),\ (B,D),\ (B,E)
> $$
>
> with root $A$, and children ordered alphabetically, then the tree is:
>
> - $A$ has children $B, C$
> - $B$ has children $D, E$
>
> Hence the preorder traversal is:
>
> $$
> A,\ B,\ D,\ E,\ C
> $$
>
> ## Conclusion
>
> Please provide:
>
> - the list of edges,
> - the root node,
> - and, if necessary, the child order,
>
> and the preorder traversal can then be computed uniquely.
