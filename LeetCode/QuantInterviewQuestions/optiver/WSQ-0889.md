> [!example] Question 889 · Optiver
> ## Software Engineer Interview

Create a function in C++ to calculate the difference in days between two dates. Explain why your solution works.

[Source](https://www.thewallstreetquants.com/ebook#p=890)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A reliable way to compute the difference in days between two dates is:
>
> 1. Convert each date into the number of days elapsed from a fixed reference point.
> 2. Subtract the two values.
> 3. Take the absolute value if the result should always be nonnegative.
>
> This works because the mapping from a calendar date to a total day count is consistent: every date corresponds to exactly one integer day index.
>
> ---
>
> ## Key idea
>
> For a date with year $y$, month $m$, and day $d$:
>
> - First count all days in the years before $y$.
> - Then count all days in the months before $m$ of year $y$.
> - Then add $d$.
> - If the date is after February in a leap year, add one extra day.
>
> A year is a leap year if:
>
> $$
> (y \bmod 400 = 0) \;\text{or}\; (y \bmod 4 = 0 \text{ and } y \bmod 100 \ne 0)
> $$
>
> ---
>
> ## C++ implementation
>
> ```cpp
> #include <iostream>
> #include <cmath>
> using namespace std;
>
> struct Date {
>     int day, month, year;
> };
>
> bool isLeap(int year) {
>     return (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
> }
>
> int daysBeforeMonth(int month, int year) {
>     static int monthDays[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
>     
>     int days = 0;
>     for (int i = 0; i < month - 1; i++) {
>         days += monthDays[i];
>     }
>     
>     if (month > 2 && isLeap(year)) {
>         days += 1;
>     }
>     
>     return days;
> }
>
> long long daysFromStart(const Date& date) {
>     long long y = date.year - 1;
>     
>     long long totalDays = y * 365;
>     totalDays += y / 4;
>     totalDays -= y / 100;
>     totalDays += y / 400;
>     
>     totalDays += daysBeforeMonth(date.month, date.year);
>     totalDays += date.day;
>     
>     return totalDays;
> }
>
> long long differenceInDays(const Date& d1, const Date& d2) {
>     return llabs(daysFromStart(d1) - daysFromStart(d2));
> }
>
> int main() {
>     Date d1 = {10, 4, 2024};
>     Date d2 = {1, 5, 2024};
>
>     cout << "Difference in days: " << differenceInDays(d1, d2) << endl;
>     return 0;
> }
> ```
>
> ---
>
> ## Why this solution works
>
> ### 1. Counting complete years
>
> For all years before year $y$, the number of days is:
>
> $$
> 365 \cdot (y-1) + \left\lfloor \frac{y-1}{4} \right\rfloor - \left\lfloor \frac{y-1}{100} \right\rfloor + \left\lfloor \frac{y-1}{400} \right\rfloor
> $$
>
> This formula is correct because:
>
> - every year contributes $365$ days,
> - every $4$th year adds $1$ leap day,
> - every $100$th year removes that leap day,
> - every $400$th year adds it back.
>
> So it exactly matches the Gregorian calendar leap-year rule.
>
> ---
>
> ### 2. Counting complete months in the current year
>
> The function `daysBeforeMonth(month, year)` adds the lengths of all months before the given month.
>
> If the year is leap and the month is after February, one extra day is added:
>
> $$
> \text{extra} = 1 \quad \text{if } m > 2 \text{ and year is leap}
> $$
>
> Thus the month contribution is accurate.
>
> ---
>
> ### 3. Adding the day of the month
>
> Finally, adding $d$ places the date at its correct day number within the year.
>
> So `daysFromStart(date)` gives a unique total day count for that date.
>
> ---
>
> ### 4. Subtracting gives the day difference
>
> If two dates map to day counts $N_1$ and $N_2$, then the number of days between them is:
>
> $$
> |N_1 - N_2|
> $$
>
> This is valid because each increase of $1$ in the count represents exactly one calendar day.
>
> ---
>
> ## Example
>
> For $10/4/2024$ and $1/5/2024$:
>
> - From April $10$ to April $30$ is $20$ days,
> - plus $1$ more day to reach May $1$,
>
> so the difference is:
>
> $$
> 21
> $$
>
> The program produces that result.
>
> ---
>
> ## Time complexity
>
> - `daysBeforeMonth()` loops through at most $12$ months, so its cost is $O(1)$.
> - All other operations are constant time.
>
> Therefore, the total time complexity is:
>
> $$
> O(1)
> $$
>
> and the space complexity is also:
>
> $$
> O(1)
> $$
>
> ---
>
> ## Final answer
>
> The function `differenceInDays()` computes the difference by converting each date into a total number of days from a fixed origin and subtracting the two totals. This works because the conversion correctly accounts for:
>
> - normal years,
> - leap years,
> - month lengths,
> - the day within the month.
>
> So the method is correct, efficient, and runs in constant time.
