> [!example] Question 924 · Optiver
> ## Software Engineer Interview

Create a function in C++ to calculate the difference in days between two dates. Explain why your solution works.

[Source](https://www.thewallstreetquants.com/ebook#p=925)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A reliable way to compute the difference in days between two dates is to convert each date into a single integer: the number of days elapsed since a fixed reference point. Then the answer is simply the absolute difference of those two integers.
>
> This works because dates advance one day at a time, so if two dates correspond to day counts $N_1$ and $N_2$, then the number of days between them is
>
> $$
> |N_2 - N_1|.
> $$
>
> ---
>
> ## Idea
>
> To convert a date $(\text{year}, \text{month}, \text{day})$ into a day count, we add:
>
> 1. the total number of days in all complete years before the given year,
> 2. the total number of days in all complete months before the given month of that year,
> 3. the day of the month.
>
> The only complication is leap years.
>
> A year is a leap year if:
>
> - it is divisible by $400$, or
> - it is divisible by $4$ but not by $100$.
>
> So the predicate is:
>
> $$
> \text{leap}(y) =
> \bigl((y \bmod 400 = 0) \lor ((y \bmod 4 = 0) \land (y \bmod 100 \ne 0))\bigr).
> $$
>
> ---
>
> ## C++ Implementation
>
> ```cpp
> #include <iostream>
> #include <cstdlib>
> using namespace std;
>
> struct Date {
>     int year;
>     int month;
>     int day;
> };
>
> bool isLeapYear(int year) {
>     return (year % 400 == 0) || (year % 4 == 0 && year % 100 != 0);
> }
>
> int daysInMonth(int year, int month) {
>     static int monthDays[] = {31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
>     
>     if (month == 2 && isLeapYear(year)) {
>         return 29;
>     }
>     return monthDays[month - 1];
> }
>
> long long daysFromEpoch(const Date& d) {
>     long long days = 0;
>
>     // Add days for complete years before this year
>     for (int y = 1; y < d.year; ++y) {
>         days += isLeapYear(y) ? 366 : 365;
>     }
>
>     // Add days for complete months before this month
>     for (int m = 1; m < d.month; ++m) {
>         days += daysInMonth(d.year, m);
>     }
>
>     // Add days in current month
>     days += d.day;
>
>     return days;
> }
>
> long long differenceInDays(const Date& d1, const Date& d2) {
>     long long total1 = daysFromEpoch(d1);
>     long long total2 = daysFromEpoch(d2);
>     return llabs(total1 - total2);
> }
>
> int main() {
>     Date d1 = {2024, 3, 1};
>     Date d2 = {2024, 2, 25};
>
>     cout << "Difference in days: " << differenceInDays(d1, d2) << endl;
>     return 0;
> }
> ```
>
> ---
>
> ## Why the solution works
>
> ### 1. Each date is mapped to a unique day number
>
> The function `daysFromEpoch` counts how many days have passed from a fixed starting point, chosen here as $1/1/1$.
>
> For a date $(y, m, d)$, it computes:
>
> $$
> \text{daysFromEpoch}(y,m,d)
> =
> \sum_{k=1}^{y-1} \text{daysInYear}(k)
> +
> \sum_{j=1}^{m-1} \text{daysInMonth}(y,j)
> +
> d.
> $$
>
> This gives a unique total number of elapsed days for every valid date.
>
> ---
>
> ### 2. Leap years are handled correctly
>
> The function `isLeapYear` implements the Gregorian leap-year rule exactly:
>
> - years divisible by $4$ are usually leap years,
> - years divisible by $100$ are not leap years,
> - years divisible by $400$ are leap years.
>
> Thus:
>
> - $2000$ is a leap year,
> - $1900$ is not a leap year,
> - $2024$ is a leap year.
>
> Because February is assigned $29$ days in leap years and $28$ otherwise, the day count is correct across all months and years.
>
> ---
>
> ### 3. Subtracting day numbers gives the day difference
>
> Suppose two dates correspond to absolute day counts $N_1$ and $N_2$. Moving from one date to the other means advancing or going back exactly one day at a time. Therefore the number of days between them is the distance between these counts:
>
> $$
> |N_2 - N_1|.
> $$
>
> That is exactly what `differenceInDays` returns.
>
> ---
>
> ## Example
>
> Take the dates:
>
> - $2024$-$03$-$01$
> - $2024$-$02$-$25$
>
> Since $2024$ is a leap year, February has $29$ days. The dates are:
>
> - February $25$
> - February $26$
> - February $27$
> - February $28$
> - February $29$
> - March $1$
>
> So the difference is
>
> $$
> 5
> $$
>
> days, which matches the program output.
>
> ---
>
> ## Time Complexity
>
> In this version, `daysFromEpoch` loops through all previous years, so its time complexity is
>
> $$
> O(y),
> $$
>
> where $y$ is the year value.
>
> The space complexity is
>
> $$
> O(1).
> $$
>
> ---
>
> ## Possible improvement
>
> The year loop can be avoided by counting leap years mathematically:
>
> - ordinary days before year $y$: $365 \cdot (y-1)$
> - leap years before year $y$:
>
> $$
> \left\lfloor \frac{y-1}{4} \right\rfloor
> -
> \left\lfloor \frac{y-1}{100} \right\rfloor
> +
> \left\lfloor \frac{y-1}{400} \right\rfloor
> $$
>
> This reduces the computation to $O(1)$.
>
> ---
>
> ## Final Answer
>
> The function above correctly computes the difference in days between two dates by:
>
> 1. converting each date to a total day count from a fixed reference date,
> 2. correctly accounting for leap years,
> 3. returning the absolute difference of those counts.
>
> Thus the method is correct and straightforward to implement in C++.
