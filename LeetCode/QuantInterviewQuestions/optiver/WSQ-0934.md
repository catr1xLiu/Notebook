> [!example] Question 934 · Optiver
> ## Software Engineer Interview

Given a list of tuples (AB, BC, AD, BE, CF), construct a binary tree and determine if it is a valid binary tree. You must check for the following five types of errors: (1) input is in the correct format; (2) no duplicate nodes; (3) the root has only two children; (4) every node is present in the tree; and (5) there are no cycles in the binary tree.

[Source](https://www.thewallstreetquants.com/ebook#p=935)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Represent each tuple such as `AB` as a directed edge from parent `A` to child `B`.  
> A valid binary tree must satisfy all of the following:
>
> 1. **Input format is correct**.
> 2. **No duplicate edges**.
> 3. **No parent has more than $2$ children**.
> 4. **There is exactly one root, and every node belongs to the same tree**.
> 5. **There are no cycles**.
>
> ---
>
> ## Step 1: Parse and validate the input format
>
> Each tuple must have exactly two node labels, so each item must look like `(XY)` where $X$ is the parent and $Y$ is the child.
>
> For the sample input
>
> $$
> (AB, BC, AD, BE, CF)
> $$
>
> the edges are:
>
> - $A \to B$
> - $B \to C$
> - $A \to D$
> - $B \to E$
> - $C \to F$
>
> These are all in valid parent-child form.
>
> ---
>
> ## Step 2: Check for duplicate edges
>
> The edge set is
>
> $$
> \{(A,B), (B,C), (A,D), (B,E), (C,F)\}
> $$
>
> No edge appears more than once, so there are no duplicate tuples.
>
> ---
>
> ## Step 3: Check that no parent has more than two children
>
> Count children of each parent:
>
> - $A$ has children $\{B, D\}$, so $2$ children.
> - $B$ has children $\{C, E\}$, so $2$ children.
> - $C$ has child $\{F\}$, so $1$ child.
>
> No node has more than $2$ children, so this condition is satisfied.
>
> ---
>
> ## Step 4: Identify the root and verify all nodes are in one tree
>
> The set of all nodes is
>
> $$
> \{A, B, C, D, E, F\}
> $$
>
> Children are
>
> $$
> \{B, C, D, E, F\}
> $$
>
> A root is a node that never appears as a child. Thus the only root is
>
> $$
> A
> $$
>
> Since there is exactly one root, this is consistent with a tree.
>
> Now verify connectivity from $A$:
>
> - From $A$: reach $B, D$
> - From $B$: reach $C, E$
> - From $C$: reach $F$
>
> Thus every node $\{A,B,C,D,E,F\}$ is reachable from the root, so every node is in the tree.
>
> ---
>
> ## Step 5: Check for cycles
>
> Follow each directed path from the root:
>
> - $A \to B \to C \to F$
> - $A \to B \to E$
> - $A \to D$
>
> No path returns to a previously visited ancestor, so there is no cycle.
>
> ---
>
> ## Constructed binary tree
>
> The tree is
>
> ```text
>         A
>        / \
>       B   D
>      / \
>     C   E
>    /
>   F
> ```
>
> ---
>
> ## Conclusion
>
> All five validity conditions are satisfied:
>
> - input format is correct,
> - no duplicate edges,
> - no node has more than two children,
> - exactly one root exists and all nodes are connected,
> - no cycles are present.
>
> Therefore, the given tuples form a **valid binary tree**.
