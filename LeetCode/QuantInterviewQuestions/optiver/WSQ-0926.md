> ## Software Engineer Interview

Write an algorithm that replaces words in a paragraph with their corresponding synonyms from a thesaurus.

[Source](https://www.thewallstreetquants.com/ebook#p=927)

> [!success]- Solution (Click to expand)
> ## Algorithm to Replace Words in a Paragraph Using a Thesaurus
>
> ### Approach
>
> Given a paragraph and a thesaurus that maps words to their replacements, the task is to scan the paragraph word by word and substitute each word with its corresponding thesaurus entry whenever one exists. Words not found in the thesaurus are left unchanged.
>
> To preserve the paragraph structure, the algorithm should process tokens carefully, distinguishing words from punctuation and spaces.
>
> ### Algorithm
>
> Assume:
>
> - The input paragraph is a string $P$.
> - The thesaurus is a dictionary $T$ such that if a word $w$ has a replacement, then $T[w]$ gives that replacement.
>
> A simple algorithm is as follows:
>
> 1. Split the paragraph into tokens, where each token is either:
>    - a word,
>    - punctuation,
>    - or whitespace.
> 2. For each token:
>    - if it is a word and it appears in the thesaurus, replace it by $T[\text{token}]$;
>    - otherwise, keep it unchanged.
> 3. Concatenate all processed tokens to form the final paragraph.
>
> ### Pseudocode
>
> ```text
> Algorithm ReplaceWithThesaurus(P, T):
>     tokens ← Tokenize(P)   // separates words, spaces, punctuation
>     result ← empty list
>
>     for each token in tokens do
>         if IsWord(token) and token ∈ T then
>             append T[token] to result
>         else
>             append token to result
>         end if
>     end for
>
>     return Concatenate(result)
> ```
>
> ### Example
>
> Let the paragraph be:
>
> ```text
> "The quick brown fox jumps over the lazy dog."
> ```
>
> and let the thesaurus contain:
>
> ```text
> quick → fast
> brown → dark
> jumps → leaps
> lazy → idle
> ```
>
> Processing each word gives:
>
> - $\text{"quick"} \to \text{"fast"}$
> - $\text{"brown"} \to \text{"dark"}$
> - $\text{"jumps"} \to \text{"leaps"}$
> - $\text{"lazy"} \to \text{"idle"}$
>
> So the output is:
>
> ```text
> "The fast dark fox leaps over the idle dog."
> ```
>
> ### Time Complexity
>
> Let $n$ be the number of tokens in the paragraph.
>
> - Tokenization takes $O(n)$.
> - Each dictionary lookup takes $O(1)$ on average.
> - Thus, the total running time is $O(n)$.
>
> The space usage is also $O(n)$ for storing the output.
>
> ### Final Answer
>
> A correct algorithm is to tokenize the paragraph, replace each word $w$ by its thesaurus equivalent $T[w]$ whenever $w$ is present in the thesaurus, and then reassemble the tokens. This runs in linear time, $O(n)$, with respect to the size of the paragraph.
