> [!example] Question 923 · Optiver
> ## Software Engineer Interview

Implement a queue class without being able to resize memory.

[Source](https://www.thewallstreetquants.com/ebook#p=924)

> [!success]- Solution (Click to expand)
> ## Approach
>
> If memory cannot be resized after construction, the queue must use a **fixed-capacity buffer**.  
> The standard way to do this efficiently is a **circular queue** (or **ring buffer**):
>
> - Allocate an array of size $N$ once.
> - Maintain:
>   - `head`: index of the front element,
>   - `tail`: index where the next element will be inserted,
>   - `count`: number of elements currently stored.
> - Wrap indices using modulo arithmetic:
>   - `next = (index + 1) \bmod N`
>
> This gives:
>
> - `enqueue`: $O(1)$
> - `dequeue`: $O(1)$
> - `front`: $O(1)$
>
> The queue is:
>
> - **empty** when `count == 0`
> - **full** when `count == capacity`
>
> ## Implementation
>
> ```python
> class QueueFull(Exception):
>     pass
>
>
> class QueueEmpty(Exception):
>     pass
>
>
> class FixedQueue:
>     def __init__(self, capacity):
>         if capacity <= 0:
>             raise ValueError("capacity must be positive")
>         self._data = [None] * capacity
>         self._capacity = capacity
>         self._head = 0
>         self._tail = 0
>         self._count = 0
>
>     def enqueue(self, value):
>         if self.is_full():
>             raise QueueFull("queue is full")
>         self._data[self._tail] = value
>         self._tail = (self._tail + 1) % self._capacity
>         self._count += 1
>
>     def dequeue(self):
>         if self.is_empty():
>             raise QueueEmpty("queue is empty")
>         value = self._data[self._head]
>         self._data[self._head] = None
>         self._head = (self._head + 1) % self._capacity
>         self._count -= 1
>         return value
>
>     def front(self):
>         if self.is_empty():
>             raise QueueEmpty("queue is empty")
>         return self._data[self._head]
>
>     def is_empty(self):
>         return self._count == 0
>
>     def is_full(self):
>         return self._count == self._capacity
>
>     def size(self):
>         return self._count
>
>     def capacity(self):
>         return self._capacity
>
>     def __repr__(self):
>         items = []
>         for i in range(self._count):
>             idx = (self._head + i) % self._capacity
>             items.append(repr(self._data[idx]))
>         return f"FixedQueue([{', '.join(items)}], capacity={self._capacity})"
> ```
>
> ## Example
>
> ```python
> q = FixedQueue(3)
>
> q.enqueue(10)
> q.enqueue(20)
> q.enqueue(30)
>
> print(q)           # FixedQueue([10, 20, 30], capacity=3)
> print(q.dequeue()) # 10
>
> q.enqueue(40)
> print(q)           # FixedQueue([20, 30, 40], capacity=3)
> print(q.front())   # 20
> ```
>
> ## Why this works
>
> Suppose the capacity is $5$.
>
> - After several enqueue and dequeue operations, `head` and `tail` may reach the end of the array.
> - Instead of shifting elements, the queue wraps around to index $0$ using
>   $$
>   (\text{index} + 1) \bmod 5.
>   $$
>
> Thus the fixed array is reused without any resizing.
>
> ## Final Answer
>
> A queue without resizable memory should be implemented as a **fixed-size circular buffer**. This uses one preallocated array and maintains `head`, `tail`, and `count`, achieving $O(1)$ enqueue and dequeue while never reallocating memory.
