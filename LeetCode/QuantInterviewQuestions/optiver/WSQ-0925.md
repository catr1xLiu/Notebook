> [!example] Question 925 · Optiver
> ## Software Developer Interview

Given a sentence s and a list of word pairs, where each pair consists of strings a and b indicating that word a can be converted to word b (but not necessarily vice versa), determine the minimum length sentence you can translate the original sentence to. If there is more than one shortest sentence, return the lexicographically smallest one.

[Source](https://www.thewallstreetquants.com/ebook#p=926)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Treat each distinct word as a node in a directed graph.  
> A pair $(a,b)$ means there is a directed edge $a \to b$, since $a$ can be translated into $b$.
>
> For each word in the sentence, we must choose some word reachable from it.  
> The goal is:
>
> 1. minimize the total sentence length, and  
> 2. among all such minimum-length translations, choose the lexicographically smallest sentence.
>
> Because each word position is independent, the optimal translated sentence is obtained by replacing each original word with its own best reachable word, where “best” means:
>
> - shortest length first,
> - lexicographically smallest among equal lengths.
>
> So the problem reduces to:
>
> For every word $w$, find the best word reachable from $w$ in the directed graph.
>
> ---
>
> ## Graph structure
>
> If two words are in the same strongly connected component, then each can reach all others in that component, and any translation reachable from one of them through outgoing paths is also reachable from the others. Thus all words in one strongly connected component have the same optimal replacement.
>
> So:
>
> 1. build the directed graph,
> 2. compress it into its strongly connected components,
> 3. obtain a DAG of components,
> 4. compute, for each component, the best word reachable from that component.
>
> ---
>
> ## Ordering criterion
>
> For words $x$ and $y$, define
>
> - $x$ is better than $y$ if $|x| < |y|$, or
> - $|x| = |y|$ and $x$ is lexicographically smaller.
>
> Let this comparison be denoted by $\min_{\text{best}}$.
>
> For a component $C$, its best reachable word is
>
> $$
> \operatorname{best}(C)
> =
> \min_{\text{best}}
> \left(
> \{\text{words inside } C\}
> \cup
> \{\operatorname{best}(D) : C \to D\}
> \right).
> $$
>
> Since the component graph is a DAG, this can be computed by dynamic programming in reverse topological order.
>
> ---
>
> ## Algorithm
>
> ### 1. Build the graph
> Collect all words appearing either in the sentence or in a pair.  
> Assign each word an integer id and build adjacency lists.
>
> ### 2. Compute strongly connected components
> Use Tarjan’s algorithm or Kosaraju’s algorithm.
>
> Let $\operatorname{comp}(w)$ be the component containing word $w$.
>
> ### 3. Build the component DAG
> For each original edge $u \to v$, if $\operatorname{comp}(u) \neq \operatorname{comp}(v)$, add an edge between those components.
>
> ### 4. Initialize each component’s local best word
> For each component $C$, among all words inside $C$, choose
>
> $$
> \operatorname{localBest}(C)
> =
> \min_{\text{best}} \{\text{words in } C\}.
> $$
>
> ### 5. Dynamic programming on the DAG
> Process components in reverse topological order.  
> Set initially
>
> $$
> \operatorname{best}(C) = \operatorname{localBest}(C).
> $$
>
> Then for every outgoing edge $C \to D$,
>
> $$
> \operatorname{best}(C)
> =
> \min_{\text{best}}(\operatorname{best}(C), \operatorname{best}(D)).
> $$
>
> After this, $\operatorname{best}(C)$ is the optimal translation target for every word in $C$.
>
> ### 6. Translate the sentence
> For each word $w$ in the original sentence, replace it by
>
> $$
> \operatorname{best}(\operatorname{comp}(w)).
> $$
>
> This gives the minimum-length sentence.  
> Because each position uses the lexicographically smallest optimal replacement, the whole sentence is also lexicographically smallest among all minimum-length translations.
>
> ---
>
> ## Correctness
>
> We prove that the algorithm returns exactly the required sentence.
>
> ### Lemma 1
> All words in the same strongly connected component have the same set of reachable components.
>
> #### Proof
> If $u$ and $v$ are in the same strongly connected component, then $u \leadsto v$ and $v \leadsto u$.  
> If $u$ can reach a component $D$, then $v \leadsto u \leadsto D$, so $v$ can also reach $D$.  
> By symmetry, they have identical reachable components. ∎
>
> ### Lemma 2
> All words in the same strongly connected component have the same optimal translation target.
>
> #### Proof
> By Lemma 1, they can reach exactly the same components, hence exactly the same set of reachable words.  
> Therefore the best reachable word under the criterion “shortest length, then lexicographically smallest” is the same for all of them. ∎
>
> ### Lemma 3
> For any component $C$, the dynamic programming formula
>
> $$
> \operatorname{best}(C)
> =
> \min_{\text{best}}
> \left(
> \operatorname{localBest}(C),
> \{\operatorname{best}(D): C \to D\}
> \right)
> $$
>
> computes the best reachable word from $C$.
>
> #### Proof
> Any reachable word from $C$ is either:
>
> 1. inside $C$, in which case the best such word is $\operatorname{localBest}(C)$, or
> 2. in some component $D$ reachable by first taking an edge $C \to D$, in which case the best such word is among the best reachable words from those successors.
>
> Because the component graph is acyclic, processing in reverse topological order ensures all $\operatorname{best}(D)$ are already correct when computing $\operatorname{best}(C)$. Thus the formula yields exactly the best reachable word from $C$. ∎
>
> ### Lemma 4
> For each sentence position, replacing the original word by its component’s best word minimizes that word’s translated length; among such choices it is lexicographically smallest.
>
> #### Proof
> By Lemma 3, $\operatorname{best}(C)$ is the best reachable word from the component containing that word. Hence it is the shortest possible translation target, and among equally short targets it is lexicographically smallest. ∎
>
> ### Theorem
> The translated sentence produced by the algorithm has minimum total length; among all such minimum-length sentences, it is lexicographically smallest.
>
> #### Proof
> Sentence positions are independent: the choice at one position does not affect reachability at another.  
> Thus minimizing total length is achieved by minimizing each position individually, which is done by Lemma 4.
>
> Now consider all minimum-length translated sentences. At the first position where two such sentences differ, the lexicographically smaller sentence must use the lexicographically smallest optimal word at that position. Our algorithm does exactly this at every position, so the resulting sentence is lexicographically smallest among all minimum-length sentences. ∎
>
> ---
>
> ## Complexity
>
> Let
>
> - $V$ be the number of distinct words,
> - $E$ be the number of translation pairs.
>
> Then:
>
> - building the graph: $O(V + E)$,
> - computing SCCs: $O(V + E)$,
> - building the component DAG: $O(E)$,
> - DP on the DAG: $O(V + E)$ ignoring string-comparison cost.
>
> Thus the overall graph complexity is
>
> $$
> O(V + E).
> $$
>
> If string comparisons are counted explicitly, comparisons involve word lengths, but the algorithmic structure remains linear in the graph size.
>
> ---
>
> ## Final Answer
>
> Build the directed graph of translations, compress it into strongly connected components, and run dynamic programming on the resulting DAG.
>
> For each component, compute the best reachable word under the order:
>
> 1. shorter word is better,
> 2. if lengths tie, lexicographically smaller word is better.
>
> Then replace each word in the sentence by the best word of its component.
>
> This produces:
>
> - the minimum possible total sentence length, and
> - among all such shortest translations, the lexicographically smallest sentence.
