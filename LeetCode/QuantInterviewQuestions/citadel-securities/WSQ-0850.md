> [!example] Question 850 · Citadel Securities
> ## Trader Interview

Describe a program to determine whether a given integer is a prime number.

[Source](https://www.thewallstreetquants.com/ebook#p=851)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To determine whether an integer $n$ is prime, use the definition:
>
> - A prime number is an integer greater than $1$ with no positive divisors other than $1$ and itself.
>
> A direct program can test divisibility systematically.
>
> ### Algorithm
>
> 1. If $n \le 1$, then $n$ is **not prime**.
> 2. If $n = 2$, then $n$ is **prime**.
> 3. If $n$ is even, that is, if $n \bmod 2 = 0$, then $n$ is **not prime**.
> 4. For odd integers $d$ starting from $3$, test whether $d$ divides $n$.
>    - It is sufficient to test up to $\sqrt{n}$.
>    - If any such $d$ satisfies $n \bmod d = 0$, then $n$ is **not prime**.
> 5. If no divisor is found, then $n$ is **prime**.
>
> The reason testing up to $\sqrt{n}$ is enough is that if $n = ab$, then at least one of $a$ or $b$ must satisfy $a \le \sqrt{n}$ or $b \le \sqrt{n}$.
>
> ### Pseudocode
>
> ```text
> procedure isPrime(n)
>     if n <= 1 then
>         return false
>     if n = 2 then
>         return true
>     if n mod 2 = 0 then
>         return false
>
>     d := 3
>     while d*d <= n do
>         if n mod d = 0 then
>             return false
>         d := d + 2
>
>     return true
> ```
>
> ### Example
>
> To test $n = 29$:
>
> - $29 > 1$
> - $29 \ne 2$
> - $29 \bmod 2 \ne 0$
> - Test odd divisors up to $\sqrt{29} \approx 5.38$, so test $3$ and $5$:
>   - $29 \bmod 3 \ne 0$
>   - $29 \bmod 5 \ne 0$
>
> No divisor is found, so $29$ is prime.
>
> ### Final Answer
>
> A program to determine whether an integer is prime should:
>
> - reject all integers $n \le 1$,
> - accept $n = 2$,
> - reject even integers greater than $2$,
> - test odd divisors from $3$ through $\sqrt{n}$.
>
> If any divisor divides $n$ exactly, the number is not prime; otherwise, it is prime.
