> [!example] Question 848 · Citadel Securities
> ## Trader Interview

Write code to generate the Fibonacci sequence.

[Source](https://www.thewallstreetquants.com/ebook#p=849)

> [!success]- Solution (Click to expand)
> ```python
> def fibonacci(n):
>     if n < 0:
>         raise ValueError("n must be a non-negative integer")
>     if n == 0:
>         return 0
>     if n == 1:
>         return 1
>
>     a, b = 0, 1
>     for _ in range(2, n + 1):
>         a, b = b, a + b
>     return b
>
>
> # Example usage
> n = 10
> print(fibonacci(n))  # 55
> ```
