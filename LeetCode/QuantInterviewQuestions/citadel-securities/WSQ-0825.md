> [!example] Question 825 · Citadel Securities
> ## Quantitative Researcher Interview

Given a string, return all possible permutations of its characters as a list. You may use recursive backtracking or any relevant Python packages.

[Source](https://www.thewallstreetquants.com/ebook#p=826)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To return **all permutations of a given string** as a list, there are two standard approaches:
>
> 1. **Recursive backtracking**
> 2. **Using Python’s `itertools.permutations`**
>
> ---
>
> ## 1. Recursive backtracking
>
> ### Idea
> Build permutations by choosing each character in turn, then recursively permuting the remaining characters.
>
> If the string has length $n$, then there are $n!$ permutations in total.
>
> ### Implementation
>
> ```python
> def permutations(s):
>     if len(s) <= 1:
>         return [s]
>
>     result = []
>     for i in range(len(s)):
>         char = s[i]
>         rest = s[:i] + s[i+1:]
>         for p in permutations(rest):
>             result.append(char + p)
>     return result
> ```
>
> ### Example
>
> ```python
> print(permutations("abc"))
> ```
>
> Output:
>
> ```python
> ['abc', 'acb', 'bac', 'bca', 'cab', 'cba']
> ```
>
> ---
>
> ## 2. Using `itertools.permutations`
>
> Python already provides this functionality in the standard library.
>
> ### Implementation
>
> ```python
> from itertools import permutations
>
> def string_permutations(s):
>     return [''.join(p) for p in permutations(s)]
> ```
>
> ### Example
>
> ```python
> print(string_permutations("abc"))
> ```
>
> Output:
>
> ```python
> ['abc', 'acb', 'bac', 'bca', 'cab', 'cba']
> ```
>
> ---
>
> ## Note on duplicate characters
>
> If the input string contains repeated characters, these methods will produce repeated permutations. For example, for `"aab"`.
>
> To return only unique permutations:
>
> ```python
> from itertools import permutations
>
> def unique_permutations(s):
>     return list({''.join(p) for p in permutations(s)})
> ```
>
> ---
>
> ## Final Answer
>
> A concise Python solution using the standard library is:
>
> ```python
> from itertools import permutations
>
> def string_permutations(s):
>     return [''.join(p) for p in permutations(s)]
> ```
>
> If a recursive backtracking solution is required:
>
> ```python
> def permutations(s):
>     if len(s) <= 1:
>         return [s]
>
>     result = []
>     for i in range(len(s)):
>         for p in permutations(s[:i] + s[i+1:]):
>             result.append(s[i] + p)
>     return result
> ```
