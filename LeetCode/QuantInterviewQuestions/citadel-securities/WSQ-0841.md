> [!example] Question 841 · Citadel Securities
> ## Software Engineer Interview

Implement a thread pool for sending messages.

[Source](https://www.thewallstreetquants.com/ebook#p=842)

> [!success]- Solution (Click to expand)
> A thread pool for sending messages is a fixed-size group of worker threads that pull tasks — in this case, "send this message" jobs — from a shared queue and execute them concurrently. The core pieces are a task queue, a mutex protecting it, a condition variable to wake idle workers, a set of worker threads, and a shutdown mechanism that lets in-flight and already-queued work finish cleanly.
>
> ## Implementation
>
> ```cpp
> #include <condition_variable>
> #include <functional>
> #include <future>
> #include <memory>
> #include <mutex>
> #include <queue>
> #include <stdexcept>
> #include <thread>
> #include <type_traits>
> #include <vector>
>
> class ThreadPool {
> public:
>     explicit ThreadPool(size_t numThreads) : stopping_(false) {
>         workers_.reserve(numThreads);
>         for (size_t i = 0; i < numThreads; ++i) {
>             workers_.emplace_back([this] { workerLoop(); });
>         }
>     }
>
>     ThreadPool(const ThreadPool&) = delete;
>     ThreadPool& operator=(const ThreadPool&) = delete;
>
>     ~ThreadPool() {
>         shutdown();
>     }
>
>     // Submits a task and returns a future for its result (or exception).
>     template <class F, class... Args>
>     auto submit(F&& f, Args&&... args) -> std::future<std::invoke_result_t<F, Args...>> {
>         using ReturnType = std::invoke_result_t<F, Args...>;
>
>         auto task = std::make_shared<std::packaged_task<ReturnType()>>(
>             std::bind(std::forward<F>(f), std::forward<Args>(args)...));
>         std::future<ReturnType> result = task->get_future();
>
>         {
>             std::lock_guard<std::mutex> lock(queueMutex_);
>             if (stopping_) {
>                 throw std::runtime_error("submit called on a stopped ThreadPool");
>             }
>             tasks_.emplace([task] { (*task)(); });
>         }
>         condition_.notify_one();
>         return result;
>     }
>
>     // Stops accepting new work, lets queued work finish, then joins all threads.
>     void shutdown() {
>         {
>             std::lock_guard<std::mutex> lock(queueMutex_);
>             if (stopping_) return;
>             stopping_ = true;
>         }
>         condition_.notify_all();
>         for (std::thread& worker : workers_) {
>             if (worker.joinable()) worker.join();
>         }
>     }
>
> private:
>     void workerLoop() {
>         for (;;) {
>             std::function<void()> task;
>             {
>                 std::unique_lock<std::mutex> lock(queueMutex_);
>                 condition_.wait(lock, [this] {
>                     return stopping_ || !tasks_.empty();
>                 });
>                 if (tasks_.empty() && stopping_) {
>                     return;
>                 }
>                 task = std::move(tasks_.front());
>                 tasks_.pop();
>             }
>             task();
>         }
>     }
>
>     std::vector<std::thread> workers_;
>     std::queue<std::function<void()>> tasks_;
>     std::mutex queueMutex_;
>     std::condition_variable condition_;
>     bool stopping_;
> };
> ```
>
> ## Example: sending messages through the pool
>
> ```cpp
> #include <iostream>
> #include <string>
>
> struct Message {
>     std::string recipient;
>     std::string body;
> };
>
> bool sendMessage(const Message& msg) {
>     // Placeholder for an I/O-bound network call.
>     std::cout << "Sending to " << msg.recipient << ": " << msg.body << "\n";
>     return true;
> }
>
> int main() {
>     ThreadPool pool(4);
>
>     std::vector<Message> outbox = {
>         {"alice@example.com", "Hello Alice"},
>         {"bob@example.com", "Hello Bob"},
>         {"carol@example.com", "Hello Carol"},
>     };
>
>     std::vector<std::future<bool>> results;
>     for (const auto& msg : outbox) {
>         results.push_back(pool.submit(sendMessage, msg));
>     }
>
>     for (auto& fut : results) {
>         bool ok = fut.get();
>         std::cout << (ok ? "sent" : "failed") << "\n";
>     }
>
>     return 0;
> }
> ```
>
> ## Design notes
>
> - The condition variable is guarded by a predicate inside `wait`, namely `stopping_ || !tasks_.empty()`, so spurious wakeups simply re-check the condition and go back to sleep; no extra flag is needed.
> - The queue mutex is held only while touching `tasks_`; each task runs outside the lock, so a slow message send does not block other threads from submitting or dequeuing work.
> - `shutdown()` performs a drain: once `stopping_` is set, no new work is accepted, but workers keep processing whatever is already queued and only exit once the queue is empty.
> - Wrapping each job in a `std::packaged_task` and returning a `std::future` lets an exception thrown by `sendMessage` propagate to the caller through `future::get()`, instead of silently terminating a worker thread.
> - Work is processed in FIFO order through a single shared `std::queue`; if strict per-recipient ordering were required, a per-recipient queue or key-based dispatch would replace the single shared queue.
