> [!example] Question 875 · Citadel Securities
> ## Quantitative Researcher (Intern) Interview

Given a number, determine whether it can be represented as the sum of two or more consecutive integers.

[Source](https://www.thewallstreetquants.com/ebook#p=876)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A positive integer can be written as a sum of $2$ or more consecutive positive integers **if and only if** it is **not** a power of $2$.
>
> ### Why this is true
>
> Suppose a number $n$ is written as a sum of $k \ge 2$ consecutive positive integers:
>
> $$
> n = a + (a+1) + (a+2) + \cdots + (a+k-1)
> $$
>
> This is an arithmetic series, so
>
> $$
> n = \frac{k\bigl(2a + k - 1\bigr)}{2}
> $$
>
> Thus, $n$ has a factorization involving some odd component. In fact, numbers that are powers of $2$ do not have enough odd divisors to allow such a decomposition, while every other positive integer does.
>
> Equivalently:
>
> - If $n = 2^m$ for some integer $m \ge 0$, then $n$ **cannot** be expressed as a sum of $2$ or more consecutive positive integers.
> - Otherwise, $n$ **can** be expressed that way.
>
> ### Computational test
>
> A number is a power of $2$ exactly when its binary representation has a single $1$ bit, which can be tested by
>
> $$
> n \mathbin{\&} (n-1) = 0
> $$
>
> for $n > 0$.
>
> Therefore, the answer is:
>
> - return `False` if $n$ is a power of $2$,
> - otherwise return `True`.
>
> ### Final rule
>
> For a given positive integer $n$:
>
> $$
> \boxed{\text{Representable as a sum of } 2 \text{ or more consecutive numbers} \iff n \text{ is not a power of } 2}
> $$
>
> A compact implementation is:
>
> ```python
> def consecutive_numbers_sum_possible(n):
>     return n > 0 and (n & (n - 1)) != 0
> ```
