> [!example] Question 868 · Citadel Securities
> ## Quantitative Researcher Intern Interview

How can you implement a rolling mean and variance of a data stream in O(1) time per update?

[Source](https://www.thewallstreetquants.com/ebook#p=869)

> [!success]- Solution (Click to expand)
> To maintain the **rolling mean** and **rolling variance** of a stream over a fixed-size window of length $W$ in $O(1)$ time per update, keep only:
>
> - a circular buffer of the last $W$ values,
> - the running sum
>   $$S = \sum_{i=1}^{W} x_i,$$
> - the running sum of squares
>   $$Q = \sum_{i=1}^{W} x_i^2.$$
>
> Then both mean and variance can be updated in constant time when a new value arrives.
>
> ---
>
> ## 1. Data maintained
>
> For the current window $\{x_1,\dots,x_W\}$, store:
>
> - $S = \sum x_i$,
> - $Q = \sum x_i^2$.
>
> The rolling mean is
>
> $$
> \mu = \frac{S}{W}.
> $$
>
> The population variance is
>
> $$
> \sigma^2 = \frac{Q}{W} - \left(\frac{S}{W}\right)^2.
> $$
>
> If the sample variance is desired, use
>
> $$
> s^2 = \frac{Q - \frac{S^2}{W}}{W-1}.
> $$
>
> ---
>
> ## 2. Update when a new value arrives
>
> Suppose the oldest value leaving the window is $x_{\text{old}}$, and the new value entering is $x_{\text{new}}$.
>
> Update:
>
> $$
> S \leftarrow S - x_{\text{old}} + x_{\text{new}},
> $$
>
> $$
> Q \leftarrow Q - x_{\text{old}}^2 + x_{\text{new}}^2.
> $$
>
> Then recompute:
>
> $$
> \mu = \frac{S}{W},
> $$
>
> $$
> \sigma^2 = \frac{Q}{W} - \mu^2.
> $$
>
> Each update uses only a constant number of arithmetic operations, so the time per element is $O(1)$.
>
> ---
>
> ## 3. Initialization
>
> Before the window is full, let the current number of elements be $n \le W$. Then use
>
> $$
> \mu = \frac{S}{n},
> $$
>
> $$
> \sigma^2 = \frac{Q}{n} - \left(\frac{S}{n}\right)^2,
> $$
>
> or sample variance
>
> $$
> s^2 = \frac{Q - \frac{S^2}{n}}{n-1}, \qquad n > 1.
> $$
>
> Once $n = W$, begin removing the oldest element on each update.
>
> ---
>
> ## 4. Circular buffer implementation
>
> Use an array of length $W$ and an index pointing to the oldest element.
>
> ### Pseudocode
>
> ```text
> initialize buffer[0..W-1]
> S = 0
> Q = 0
> count = 0
> idx = 0
>
> function add(x):
>     if count < W:
>         buffer[idx] = x
>         S += x
>         Q += x*x
>         count += 1
>         idx = (idx + 1) mod W
>     else:
>         old = buffer[idx]
>         buffer[idx] = x
>         S += x - old
>         Q += x*x - old*old
>         idx = (idx + 1) mod W
>
> function mean():
>     return S / count
>
> function variance_population():
>     m = S / count
>     return Q / count - m*m
>
> function variance_sample():
>     if count < 2:
>         return undefined
>     return (Q - S*S / count) / (count - 1)
> ```
>
> ---
>
> ## 5. Numerical stability
>
> The formula
>
> $$
> \sigma^2 = \frac{Q}{W} - \left(\frac{S}{W}\right)^2
> $$
>
> is efficient, but it can suffer from cancellation error when the variance is very small relative to the magnitude of the data.
>
> For many practical applications this is acceptable. If greater numerical robustness is required, one may use a more stable rolling variant of Welford’s method, but that is more complicated because deletion of the oldest observation must also be handled.
>
> A common practical safeguard is:
>
> $$
> \sigma^2 = \max\!\left(0,\; \frac{Q}{W} - \left(\frac{S}{W}\right)^2\right).
> $$
>
> ---
>
> ## 6. Complexity
>
> - **Time per update:** $O(1)$
> - **Memory:** $O(W)$, due to storing the window in the circular buffer
>
> ---
>
> ## Final answer
>
> Maintain the running totals
>
> $$
> S = \sum x_i, \qquad Q = \sum x_i^2
> $$
>
> over the current window of size $W$, together with a circular buffer containing the last $W$ values. When a new value $x_{\text{new}}$ arrives and the oldest value $x_{\text{old}}$ leaves, update
>
> $$
> S \leftarrow S - x_{\text{old}} + x_{\text{new}},
> $$
>
> $$
> Q \leftarrow Q - x_{\text{old}}^2 + x_{\text{new}}^2.
> $$
>
> Then compute
>
> $$
> \mu = \frac{S}{W}, \qquad
> \sigma^2 = \frac{Q}{W} - \mu^2,
> $$
>
> or sample variance
>
> $$
> s^2 = \frac{Q - \frac{S^2}{W}}{W-1}.
> $$
>
> This gives rolling mean and variance in $O(1)$ time per update.
