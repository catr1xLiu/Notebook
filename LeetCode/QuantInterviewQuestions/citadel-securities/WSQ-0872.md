> [!example] Question 872 · Citadel Securities
> ## Software Engineer Intern Interview

Implement a ring buffer data structure. Write functions for both writing data to the buffer and reading data from it.

[Source](https://www.thewallstreetquants.com/ebook#p=873)

> [!success]- Solution (Click to expand)
> ## Ring Buffer Implementation
>
> A ring buffer (circular buffer) is a fixed-size queue that wraps around when it reaches the end of the underlying array. It supports efficient $O(1)$ writes and reads.
>
> ### Structure
>
> The buffer needs:
>
> - an array to store data,
> - a capacity,
> - a write position,
> - a read position,
> - a count of stored elements.
>
> ### C Implementation
>
> ```c
> #include <stdio.h>
> #include <stdlib.h>
> #include <stdbool.h>
>
> typedef struct {
>     int *data;
>     size_t capacity;
>     size_t head;   // write position
>     size_t tail;   // read position
>     size_t count;  // number of elements in buffer
> } RingBuffer;
> ```
>
> ### Initialization
>
> ```c
> bool ring_buffer_init(RingBuffer *rb, size_t capacity) {
>     rb->data = (int *)malloc(capacity * sizeof(int));
>     if (rb->data == NULL) {
>         return false;
>     }
>
>     rb->capacity = capacity;
>     rb->head = 0;
>     rb->tail = 0;
>     rb->count = 0;
>     return true;
> }
> ```
>
> ### Cleanup
>
> ```c
> void ring_buffer_free(RingBuffer *rb) {
>     free(rb->data);
>     rb->data = NULL;
>     rb->capacity = 0;
>     rb->head = 0;
>     rb->tail = 0;
>     rb->count = 0;
> }
> ```
>
> ### Write Function
>
> The write operation inserts one element if the buffer is not full.
>
> ```c
> bool ring_buffer_write(RingBuffer *rb, int value) {
>     if (rb->count == rb->capacity) {
>         return false; // buffer full
>     }
>
>     rb->data[rb->head] = value;
>     rb->head = (rb->head + 1) % rb->capacity;
>     rb->count++;
>     return true;
> }
> ```
>
> ### Read Function
>
> The read operation removes one element if the buffer is not empty.
>
> ```c
> bool ring_buffer_read(RingBuffer *rb, int *value) {
>     if (rb->count == 0) {
>         return false; // buffer empty
>     }
>
>     *value = rb->data[rb->tail];
>     rb->tail = (rb->tail + 1) % rb->capacity;
>     rb->count--;
>     return true;
> }
> ```
>
> ### Example Usage
>
> ```c
> int main(void) {
>     RingBuffer rb;
>     int value;
>
>     if (!ring_buffer_init(&rb, 5)) {
>         printf("Failed to initialize buffer\n");
>         return 1;
>     }
>
>     ring_buffer_write(&rb, 10);
>     ring_buffer_write(&rb, 20);
>     ring_buffer_write(&rb, 30);
>
>     while (ring_buffer_read(&rb, &value)) {
>         printf("%d\n", value);
>     }
>
>     ring_buffer_free(&rb);
>     return 0;
> }
> ```
>
> ## Explanation
>
> Let the buffer capacity be $N$.
>
> - Writing stores the element at index $\text{head}$, then updates
>   $$
>   \text{head} = (\text{head} + 1) \bmod N.
>   $$
> - Reading retrieves the element at index $\text{tail}$, then updates
>   $$
>   \text{tail} = (\text{tail} + 1) \bmod N.
>   $$
> - The variable $\text{count}$ distinguishes between the empty and full states:
>   - empty when $\text{count} = 0$,
>   - full when $\text{count} = N$.
>
> Thus both operations run in constant time.
>
> ## Final Answer
>
> A correct ring buffer implementation requires a fixed array, head/tail indices, and a count field. The key functions are:
>
> - `ring_buffer_write`: writes one element unless the buffer is full,
> - `ring_buffer_read`: reads one element unless the buffer is empty.
>
