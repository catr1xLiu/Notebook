> [!example] Question 854 · Citadel Securities
> ## Quantitative Trader Interview

Write Python code to determine if a given integer is a prime number.

[Source](https://www.thewallstreetquants.com/ebook#p=855)

> [!success]- Solution (Click to expand)
> ```python
> def is_prime(n: int) -> bool:
>     if n <= 1:
>         return False
>     if n <= 3:
>         return True
>     if n % 2 == 0 or n % 3 == 0:
>         return False
>
>     i = 5
>     while i * i <= n:
>         if n % i == 0 or n % (i + 2) == 0:
>             return False
>         i += 6
>
>     return True
>
>
> # Example usage
> num = int(input("Enter an integer: "))
> if is_prime(num):
>     print(f"{num} is prime")
> else:
>     print(f"{num} is not prime")
> ```
