> ## Software Engineer Interview

What is the difference between concurrent and multicore systems?

[Source](https://www.thewallstreetquants.com/ebook#p=840)

> [!success]- Solution (Click to expand)
> ## Difference Between Concurrent and Multi-Core Systems
>
> Although the terms are sometimes used together, **concurrent systems** and **multi-core systems** refer to different concepts.
>
> ### 1. Concurrent System
>
> A **concurrent system** is a system in which multiple tasks make progress during overlapping time periods.
>
> - Concurrency is mainly a **software or execution model** concept.
> - Tasks may appear to run at the same time, but on a single processor they often execute by **interleaving**:
>   $$
>   T_1 \rightarrow T_2 \rightarrow T_1 \rightarrow T_3 \rightarrow \cdots
>   $$
> - The processor switches rapidly among tasks, giving the impression of simultaneous execution.
>
> #### Key idea
> Concurrency is about **managing multiple activities at once**, not necessarily executing them literally at the same instant.
>
> #### Example
> A single-core operating system running:
> - a web browser,
> - a music player,
> - a file download
>
> can handle all of them concurrently by time-sharing the CPU.
>
> ---
>
> ### 2. Multi-Core System
>
> A **multi-core system** is a hardware system containing two or more processing cores in a single CPU.
>
> - Multi-core refers to **hardware architecture**.
> - Each core can execute instructions independently.
> - This allows true **parallel execution** of multiple tasks:
>   $$
>   \text{Core 1} \rightarrow T_1, \qquad \text{Core 2} \rightarrow T_2
>   $$
> - Multiple tasks can run at the same instant on different cores.
>
> #### Key idea
> Multi-core is about **physical processing units** that enable parallelism.
>
> #### Example
> In a quad-core processor, four separate cores may run four different threads simultaneously.
>
> ---
>
> ## Main Difference
>
> - **Aspect Nature** — Concurrent System: Software/execution concept; Multi-Core System: Hardware architecture
> - **Aspect Execution** — Concurrent System: Tasks may only be interleaved; Multi-Core System: Tasks can run truly in parallel
> - **Aspect Requirement** — Concurrent System: Can work on a single-core CPU; Multi-Core System: Requires multiple cores
> - **Aspect Goal** — Concurrent System: Handle multiple tasks efficiently; Multi-Core System: Increase computational throughput
>
> ---
>
> ## Relationship Between Them
>
> - A system can be **concurrent without being multi-core**.
> - A multi-core system usually supports **parallel execution**, and it often also runs concurrent programs.
> - Concurrency and parallelism are related, but not identical:
>   - **Concurrency**: dealing with many tasks at once
>   - **Parallelism**: doing many tasks at once
>
> ---
>
> ## Conclusion
>
> A **concurrent system** concerns how multiple tasks are organized and progressed, possibly on one processor through interleaving. A **multi-core system** concerns hardware with multiple CPU cores, enabling true simultaneous execution of tasks. Thus, concurrency is a **programming/execution concept**, while multi-core is a **hardware feature**.
