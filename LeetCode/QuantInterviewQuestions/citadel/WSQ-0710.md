> [!example] Question 710 · Citadel
> ## Quantitative Researcher Interview

What data structure is used to implement a dictionary in Python?

[Source](https://www.thewallstreetquants.com/ebook#p=711)

> [!success]- Solution (Click to expand)
> In Python, a **dictionary** is a **hash table**-based data structure.
>
> ## Definition
>
> A dictionary stores data as **key–value pairs**:
>
> $$
> \{ \text{key} : \text{value} \}
> $$
>
> Each key is mapped to a corresponding value, allowing fast lookup, insertion, and deletion.
>
> ## Underlying data structure
>
> Python dictionaries are implemented using a **hash table**, which works as follows:
>
> 1. A **hash function** computes a hash value for a key.
> 2. That hash value determines where the key–value pair should be stored.
> 3. This allows average-time access to values by key in:
>
> $$
> O(1)
> $$
>
> time.
>
> ## Main properties
>
> - **Mutable**: items can be added, changed, or removed.
> - **Keys must be hashable**: immutable types such as strings, numbers, and tuples can be used as keys.
> - **Values can be any type**.
> - In modern Python versions, dictionaries also **preserve insertion order**.
>
> ## Example
>
> ```python
> student = {
>     "name": "Alice",
>     "age": 20,
>     "grade": "A"
> }
> ```
>
> Here:
>
> - `"name"`, `"age"`, and `"grade"` are the **keys**
> - `"Alice"`, `20`, and `"A"` are the **values**
>
> ## Conclusion
>
> The Python dictionary data structure is a **hash table** that stores **key–value pairs** and provides average-case performance of:
>
> $$
> O(1)
> $$
>
> for lookup, insertion, and deletion.
