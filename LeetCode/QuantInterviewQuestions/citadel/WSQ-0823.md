> ## Random Forest: How It Works
>
> A **random forest** is an ensemble learning method that combines many **decision trees** to improve prediction accuracy and reduce overfitting.
>
> ## 1. Basic Idea
>
> A single decision tree can fit training data very well, but it is often **unstable**: small changes in the data can produce a very different tree. A random forest addresses this by building many trees and aggregating their predictions.
>
> The key principle is:
>
> - build many diverse trees,
> - let each tree make a prediction,
> - combine the predictions.
>
> This reduces variance and usually gives better generalization.
>
> ---
>
> ## 2. How the Trees Are Made
>
> Suppose the training set is
>
> $$
> \{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}.
> $$
>
> To construct a random forest with $B$ trees:
>
> ### Step 1: Bootstrap sampling
>
> For each tree $b = 1,2,\dots,B$:
>
> - draw a **bootstrap sample** of size $n$ from the training data,
> - sampling is done **with replacement**.
>
> Thus, some observations appear multiple times in a sample, while others may not appear at all.
>
> ### Step 2: Grow a decision tree
>
> Using that bootstrap sample, grow a decision tree. However, unlike an ordinary tree, at each split:
>
> - do **not** consider all input features,
> - instead, randomly select a subset of features of size $m$,
> - choose the best split only among those $m$ features.
>
> This random feature selection is what makes the trees less correlated.
>
> ### Step 3: Repeat
>
> Repeat Steps $1$ and $2$ to create $B$ different trees.
>
> ---
>
> ## 3. How Prediction Is Made
>
> After all trees are built, the forest predicts by combining them.
>
> ### For classification
>
> Each tree outputs a class label. The forest predicts the class receiving the **majority vote**:
>
> $$
> \hat{y} = \operatorname{mode}\{\hat{y}^{(1)}, \hat{y}^{(2)}, \dots, \hat{y}^{(B)}\}.
> $$
>
> ### For regression
>
> Each tree outputs a numerical value. The forest predicts the **average**:
>
> $$
> \hat{y} = \frac{1}{B}\sum_{b=1}^B \hat{y}^{(b)}.
> $$
>
> ---
>
> ## 4. Why It Works
>
> Random forests work well because they combine two ideas:
>
> ### Bagging
>
> Bagging, or **bootstrap aggregating**, reduces variance by averaging predictions from many trees trained on different bootstrap samples.
>
> If individual tree predictions have variance $\sigma^2$, averaging many weakly correlated trees reduces the overall variance.
>
> ### Random feature selection
>
> If all trees were built from the same strong predictors, they would look similar and their errors would be highly correlated. By forcing each split to consider only a random subset of features, the forest creates more diverse trees.
>
> The benefit of averaging is greatest when trees are both:
>
> - reasonably accurate,
> - weakly correlated.
>
> ---
>
> ## 5. Important Characteristics
>
> ### Trees are usually grown deep
>
> Random forest trees are typically grown with little or no pruning. Each tree may overfit its own bootstrap sample, but the ensemble average remains stable.
>
> ### Out-of-bag error
>
> Because each bootstrap sample leaves out some observations, those omitted observations are called **out-of-bag** observations. They can be used to estimate prediction error without a separate validation set.
>
> For a training point, predict it using only the trees for which that point was not included in the bootstrap sample. Aggregating these predictions gives the **out-of-bag error estimate**.
>
> ### Feature importance
>
> Random forests can estimate which variables are important. Common methods include:
>
> - measuring total impurity reduction contributed by a feature,
> - measuring the increase in prediction error when a feature is randomly permuted.
>
> ---
>
> ## 6. Main Hyperparameters
>
> Some important choices are:
>
> - $B$: number of trees,
> - $m$: number of features considered at each split,
> - maximum tree depth,
> - minimum samples required to split a node,
> - minimum samples in a leaf.
>
> Typical defaults are:
>
> - for classification: $m \approx \sqrt{p}$,
> - for regression: $m \approx p/3$,
>
> where $p$ is the number of input features.
>
> ---
>
> ## 7. Advantages
>
> Random forests have several strengths:
>
> - high predictive accuracy,
> - reduced overfitting compared with a single tree,
> - work well for both classification and regression,
> - can handle nonlinear relationships and interactions,
> - require relatively little preprocessing,
> - can estimate feature importance,
> - robust to noise and outliers.
>
> ---
>
> ## 8. Limitations
>
> They also have drawbacks:
>
> - less interpretable than a single decision tree,
> - can be computationally heavier for large datasets,
> - may perform poorly on very sparse high-dimensional problems compared with specialized methods,
> - feature importance measures can be biased in some settings.
>
> ---
>
> ## 9. Summary
>
> A random forest builds many decision trees using:
>
> 1. **bootstrap-resampled training sets**, and  
> 2. **random subsets of features at each split**.
>
> It then combines their predictions by:
>
> - **majority vote** for classification,
> - **averaging** for regression.
>
> This produces a model that is more accurate and more stable than a single decision tree because averaging many diverse trees reduces variance while preserving predictive power.
