> [!example] Question 782 · Citadel
> ## Software Engineer Interview

How do you reverse a linked list?

[Source](https://www.thewallstreetquants.com/ebook#p=783)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To reverse a singly linked list, iterate through the list and reverse each node’s pointer one by one.
>
> ### Approach
>
> Maintain three pointers:
>
> - $prev$: the previous node, initially $null$
> - $curr$: the current node, initially the head of the list
> - $next$: temporarily stores the next node so it is not lost
>
> At each step:
>
> 1. Save the next node: $next = curr.next$
> 2. Reverse the pointer: $curr.next = prev$
> 3. Move $prev$ forward: $prev = curr$
> 4. Move $curr$ forward: $curr = next$
>
> When the traversal ends, $prev$ points to the new head of the reversed list.
>
> ### Algorithm
>
> Given head of the list:
>
> $$
> \text{Initialize } prev = null,\ curr = head
> $$
>
> While $curr \neq null$:
>
> $$
> next = curr.next
> $$
>
> $$
> curr.next = prev
> $$
>
> $$
> prev = curr
> $$
>
> $$
> curr = next
> $$
>
> Return:
>
> $$
> prev
> $$
>
> ### Correctness
>
> At every iteration, the portion of the list before $curr$ has already been reversed, and $prev$ points to the head of that reversed portion. Reassigning $curr.next$ to $prev$ correctly adds $curr$ to the front of the reversed portion. Advancing $curr$ and $prev$ preserves this invariant until all nodes are processed. Therefore, when $curr = null$, $prev$ is the head of the fully reversed list.
>
> ### Complexity
>
> - Time: $O(n)$, where $n$ is the number of nodes
> - Space: $O(1)$
>
> ### Python Code
>
> ```python
> # Definition for singly-linked list.
> # class ListNode:
> #     def __init__(self, val=0, next=None):
> #         self.val = val
> #         self.next = next
>
> class Solution:
>     def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
>         prev = None
>         curr = head
>         
>         while curr:
>             nxt = curr.next
>             curr.next = prev
>             prev = curr
>             curr = nxt
>         
>         return prev
> ```
>
> ### Final Answer
>
> The linked list can be reversed iteratively by changing each node’s $next$ pointer to its previous node, using three pointers. This yields an $O(n)$ time and $O(1)$ space solution.
