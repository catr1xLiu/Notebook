> [!example] Question 807 · Citadel
> ## Summer Intern Interview

Write code to compute x raised to the power n (x^n) in O(log n) time.

[Source](https://www.thewallstreetquants.com/ebook#p=808)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To compute $x^n$ in $O(\log n)$ time, use **binary exponentiation** (also called **fast exponentiation** or **exponentiation by squaring**).
>
> ### Idea
>
> Observe:
>
> - If $n$ is even, then
>   $$
>   x^n = \left(x^{n/2}\right)^2
>   $$
> - If $n$ is odd, then
>   $$
>   x^n = x \cdot x^{n-1}
>   $$
>
> At each step, the exponent is reduced by about half, so the total number of multiplications is $O(\log n)$.
>
> ### Recursive code
>
> ```python
> def power(x, n):
>     if n == 0:
>         return 1
>     half = power(x, n // 2)
>     if n % 2 == 0:
>         return half * half
>     else:
>         return x * half * half
> ```
>
> ### Iterative code
>
> This version is often preferred because it avoids recursion.
>
> ```python
> def power(x, n):
>     result = 1
>     while n > 0:
>         if n % 2 == 1:
>             result *= x
>         x *= x
>         n //= 2
>     return result
> ```
>
> ### Why it is $O(\log n)$
>
> In each iteration, $n$ is divided by $2$:
> $$
> n \to \left\lfloor \frac{n}{2} \right\rfloor
> $$
> So the number of iterations is proportional to the number of bits in $n$, which is:
> $$
> O(\log n)
> $$
>
> ### Final answer
>
> A correct $O(\log n)$ method for computing $x^n$ is:
>
> ```python
> def power(x, n):
>     result = 1
>     while n > 0:
>         if n % 2 == 1:
>             result *= x
>         x *= x
>         n //= 2
>     return result
> ```
>
> This computes $x^n$ in $O(\log n)$ time and $O(1)$ extra space.
