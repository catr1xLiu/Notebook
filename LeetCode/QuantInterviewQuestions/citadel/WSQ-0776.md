> ## Implementing a `defaultdict` in Python with OOD
>
> A `defaultdict` behaves like a dictionary, except that when a missing key is accessed, it automatically creates a default value for that key using a factory function.
>
> The essential ideas are:
>
> 1. Store key-value pairs like a normal dictionary.
> 2. Store a `default_factory`, which is a callable such as `list`, `int`, or `set`.
> 3. When a missing key is accessed through `__getitem__`, create a value by calling the factory, store it, and return it.
>
> ## Object-Oriented Design
>
> A clean design is to subclass `dict`, because `defaultdict` is a specialized dictionary.
>
> ### Implementation
>
> ```python
> class DefaultDict(dict):
>     def __init__(self, default_factory=None, *args, **kwargs):
>         if default_factory is not None and not callable(default_factory):
>             raise TypeError("default_factory must be callable or None")
>         self.default_factory = default_factory
>         super().__init__(*args, **kwargs)
>
>     def __missing__(self, key):
>         if self.default_factory is None:
>             raise KeyError(key)
>         value = self.default_factory()
>         self[key] = value
>         return value
>
>     def __getitem__(self, key):
>         try:
>             return super().__getitem__(key)
>         except KeyError:
>             return self.__missing__(key)
>
>     def __repr__(self):
>         return f"{self.__class__.__name__}({self.default_factory}, {dict.__repr__(self)})"
> ```
>
> ## How it works
>
> ### Constructor
>
> ```python
> def __init__(self, default_factory=None, *args, **kwargs):
> ```
>
> - `default_factory` is the function used to generate default values.
> - It must be callable or `None`.
> - `*args` and `**kwargs` allow initialization like a normal dictionary.
>
> For example:
>
> ```python
> d = DefaultDict(list)
> d = DefaultDict(int, a=1, b=2)
> ```
>
> ### Handling missing keys
>
> The key method is:
>
> ```python
> def __missing__(self, key):
> ```
>
> If the key does not exist:
>
> - If no factory is provided, raise `KeyError`.
> - Otherwise, create a new value with:
>
> ```python
> value = self.default_factory()
> ```
>
> Then store it:
>
> ```python
> self[key] = value
> ```
>
> and return it.
>
> ### Access behavior
>
> When `d[key]` is used, `__getitem__` is called. If the key exists, return it normally. If it does not, invoke `__missing__(key)`.
>
> ## Example usage
>
> ### Example 1: Grouping values
>
> ```python
> d = DefaultDict(list)
> d["fruits"].append("apple")
> d["fruits"].append("banana")
> d["colors"].append("red")
>
> print(d)
> ```
>
> Output:
>
> ```python
> DefaultDict(<class 'list'>, {'fruits': ['apple', 'banana'], 'colors': ['red']})
> ```
>
> ### Example 2: Counting
>
> ```python
> d = DefaultDict(int)
> for ch in "aabbbc":
>     d[ch] += 1
>
> print(d)
> ```
>
> Output:
>
> ```python
> DefaultDict(<class 'int'>, {'a': 2, 'b': 3, 'c': 1})
> ```
>
> ### Example 3: No factory
>
> ```python
> d = DefaultDict()
> print(d["x"])
> ```
>
> This raises:
>
> ```python
> KeyError: 'x'
> ```
>
> ## Alternative design: composition instead of inheritance
>
> If one wants stricter encapsulation, one can wrap a dictionary instead of inheriting from it.
>
> ```python
> class DefaultDict:
>     def __init__(self, default_factory=None):
>         if default_factory is not None and not callable(default_factory):
>             raise TypeError("default_factory must be callable or None")
>         self.default_factory = default_factory
>         self._data = {}
>
>     def __getitem__(self, key):
>         if key not in self._data:
>             if self.default_factory is None:
>                 raise KeyError(key)
>             self._data[key] = self.default_factory()
>         return self._data[key]
>
>     def __setitem__(self, key, value):
>         self._data[key] = value
>
>     def __contains__(self, key):
>         return key in self._data
>
>     def __repr__(self):
>         return f"DefaultDict({self.default_factory}, {self._data})"
> ```
>
> This is simpler conceptually, but it does not automatically provide the full dictionary interface unless more methods are added.
>
> ## Final implementation
>
> ```python
> class DefaultDict(dict):
>     def __init__(self, default_factory=None, *args, **kwargs):
>         if default_factory is not None and not callable(default_factory):
>             raise TypeError("default_factory must be callable or None")
>         self.default_factory = default_factory
>         super().__init__(*args, **kwargs)
>
>     def __missing__(self, key):
>         if self.default_factory is None:
>             raise KeyError(key)
>         value = self.default_factory()
>         self[key] = value
>         return value
>
>     def __getitem__(self, key):
>         try:
>             return super().__getitem__(key)
>         except KeyError:
>             return self.__missing__(key)
>
>     def __repr__(self):
>         return f"{self.__class__.__name__}({self.default_factory}, {dict.__repr__(self)})"
> ```
>
> This captures the core behavior of Python’s built-in `collections.defaultdict` in an object-oriented way.
