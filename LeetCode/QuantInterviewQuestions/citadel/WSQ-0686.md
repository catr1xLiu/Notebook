> ## Implementing a `defaultdict` in Python Using Object-Oriented Design
>
> A `defaultdict` behaves like a regular dictionary, except that when a missing key is accessed, it automatically creates a default value using a supplied factory function.
>
> The essential idea is:
>
> - store key-value pairs in an internal dictionary,
> - store a `default_factory`,
> - when a missing key is requested, create and insert a default value.
>
> ## Design
>
> Define a class with:
>
> - an initializer accepting a factory such as `list`, `int`, or `set`,
> - standard dictionary-like methods,
> - special handling in `__getitem__` for missing keys.
>
> ## Implementation
>
> ```python
> class DefaultDict:
>     def __init__(self, default_factory=None, *args, **kwargs):
>         if default_factory is not None and not callable(default_factory):
>             raise TypeError("default_factory must be callable or None")
>         self.default_factory = default_factory
>         self._data = dict(*args, **kwargs)
>
>     def __getitem__(self, key):
>         if key in self._data:
>             return self._data[key]
>         return self.__missing__(key)
>
>     def __setitem__(self, key, value):
>         self._data[key] = value
>
>     def __delitem__(self, key):
>         del self._data[key]
>
>     def __contains__(self, key):
>         return key in self._data
>
>     def __len__(self):
>         return len(self._data)
>
>     def __iter__(self):
>         return iter(self._data)
>
>     def __repr__(self):
>         return f"{self.__class__.__name__}({self.default_factory}, {self._data})"
>
>     def __missing__(self, key):
>         if self.default_factory is None:
>             raise KeyError(key)
>         value = self.default_factory()
>         self._data[key] = value
>         return value
>
>     def get(self, key, default=None):
>         return self._data.get(key, default)
>
>     def items(self):
>         return self._data.items()
>
>     def keys(self):
>         return self._data.keys()
>
>     def values(self):
>         return self._data.values()
>
>     def copy(self):
>         return DefaultDict(self.default_factory, self._data.copy())
> ```
>
> ## How It Works
>
> Suppose the factory is `list`.
>
> ```python
> d = DefaultDict(list)
> d["a"].append(1)
> d["a"].append(2)
> print(d)
> ```
>
> ### Step-by-step behavior
>
> 1. `d["a"]` is requested.
> 2. The key `"a"` is not present.
> 3. `__missing__("a")` is called.
> 4. `list()` creates `[]`.
> 5. The pair `"a": []` is inserted.
> 6. The list is returned, and `.append(1)` modifies it.
>
> The result is:
>
> ```python
> DefaultDict(<class 'list'>, {'a': [1, 2]})
> ```
>
> ## Another Example
>
> Using `int` as the default factory is useful for counting.
>
> ```python
> d = DefaultDict(int)
> for ch in "banana":
>     d[ch] += 1
>
> print(d)
> ```
>
> Since `int()` returns `0`, each missing key starts at `0`, producing counts such as:
>
> ```python
> DefaultDict(<class 'int'>, {'b': 1, 'a': 3, 'n': 2})
> ```
>
> ## Important Detail
>
> The `get()` method does **not** create a default value. It behaves like the normal dictionary method:
>
> ```python
> d = DefaultDict(list)
> print(d.get("x"))   # None
> print("x" in d)     # False
> ```
>
> But:
>
> ```python
> d["x"]
> print("x" in d)     # True
> ```
>

> ## Conclusion
>
> A `defaultdict` can be implemented by combining:
>
> - encapsulation of an internal dictionary,
> - a stored factory function,
> - missing-key handling in `__getitem__` through `__missing__`.
>
> This yields a clean object-oriented design that closely matches the behavior of Python’s built-in `collections.defaultdict`.
