> [!example] Question 744 · Citadel
> ## Quantitative Analyst Interview

How can you detect a loop in a linked list?

[Source](https://www.thewallstreetquants.com/ebook#p=745)

> [!success]- Solution (Click to expand)
> To detect a loop in a linked list, the standard method is **Floyd’s cycle-finding algorithm**, also called the **tortoise and hare** method.
>
> ## Idea
>
> Use two pointers:
>
> - a **slow** pointer that moves one node at a time,
> - a **fast** pointer that moves two nodes at a time.
>
> ### Why it works
>
> - If there is **no loop**, the fast pointer will eventually reach `null`.
> - If there **is** a loop, the fast pointer will eventually “lap” the slow pointer, so they will meet at some node inside the cycle.
>
> ## Algorithm
>
> 1. Initialize both pointers at the head.
> 2. Repeatedly move:
>    - slow by $1$ step,
>    - fast by $2$ steps.
> 3. If `fast == null` or `fast.next == null`, there is no loop.
> 4. If `slow == fast`, a loop exists.
>
> ## Pseudocode
>
> ```text
> function hasLoop(head):
>     slow = head
>     fast = head
>
>     while fast != null and fast.next != null:
>         slow = slow.next
>         fast = fast.next.next
>
>         if slow == fast:
>             return true
>
>     return false
> ```
>
> ## Finding the starting node of the loop
>
> If the problem also asks for the node where the loop begins:
>
> 1. First detect the meeting point using the method above.
> 2. Reset one pointer to the head.
> 3. Move both pointers one step at a time.
> 4. The node where they meet is the start of the loop.
>
> ### Pseudocode
>
> ```text
> function findLoopStart(head):
>     slow = head
>     fast = head
>
>     while fast != null and fast.next != null:
>         slow = slow.next
>         fast = fast.next.next
>
>         if slow == fast:
>             break
>
>     if fast == null or fast.next == null:
>         return null
>
>     slow = head
>     while slow != fast:
>         slow = slow.next
>         fast = fast.next
>
>     return slow
> ```
>
> ## Time and space complexity
>
> - **Time:** $O(n)$
> - **Space:** $O(1)$
>
> ## Final answer
>
> A loop in a linked list can be found using **two pointers moving at different speeds**. If the pointers ever meet, the list contains a loop; if the fast pointer reaches `null`, it does not. This method runs in $O(n)$ time and uses $O(1)$ extra space.
