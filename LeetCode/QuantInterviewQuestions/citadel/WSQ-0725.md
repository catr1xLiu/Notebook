> [!example] Question 725 · Citadel
> ## Quantitative Researcher Interview

Given an array of numbers: 1, 5, 3, 2, 4, 2, 3, 1, 2, 3, 2, 4, return another array where duplicate numbers are grouped in consecutive positions, maintaining the order of their first appearance. For example, the result should be: 1, 1, 5, 3, 3, 3, 2, 2, 2, 2, 4, 4.

[Source](https://www.thewallstreetquants.com/ebook#p=726)

> [!success]- Solution (Click to expand)
> To place equal numbers in consecutive positions while preserving the order in which distinct values first appear, proceed as follows:
>
> 1. Scan the array from left to right.
> 2. Record the first time each distinct number appears.
> 3. Count how many times each number occurs.
> 4. Output each distinct number, in first-appearance order, repeated according to its count.
>
> For the array
> $$
> [1,5,3,2,4,2,3,1,2,3,2,4],
> $$
> the first appearances occur in the order
> $$
> 1,5,3,2,4.
> $$
> Their frequencies are:
> - $1$ appears $2$ times,
> - $5$ appears $1$ time,
> - $3$ appears $3$ times,
> - $2$ appears $4$ times,
> - $4$ appears $2$ times.
>
> Therefore the reordered array is
> $$
> [1,1,5,3,3,3,2,2,2,2,4,4].
> $$
>
> A direct algorithm is:
>
> ```text
> order = empty list
> count = empty map
>
> for x in array:
>     if x not in count:
>         append x to order
>         count[x] = 0
>     count[x] += 1
>
> result = empty list
> for x in order:
>     append x to result, count[x] times
> ```
>
> Thus the required result is
> $$
> [1,1,5,3,3,3,2,2,2,2,4,4].
> $$
