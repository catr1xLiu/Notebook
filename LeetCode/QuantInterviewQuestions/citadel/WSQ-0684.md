> ## Developer Interview

Given a binary tree, write a function to determine if it is a valid binary search tree.

[Source](https://www.thewallstreetquants.com/ebook#p=685)

> [!success]- Solution (Click to expand)
> ## Binary Search Tree Validation
>
> ### Approach
>
> A binary tree is a valid binary search tree if, for every node:
>
> - all values in its left subtree are strictly less than the node's value, and
> - all values in its right subtree are strictly greater than the node's value.
>
> Checking only the immediate children is not sufficient; every node must satisfy constraints inherited from all its ancestors. The standard method is to perform a depth-first traversal while maintaining an allowable range for each node.
>
> ### Algorithm
>
> For each node, keep two bounds:
>
> - a lower bound $L$,
> - an upper bound $U$.
>
> A node with value $x$ is valid only if
>
> $$
> L < x < U.
> $$
>
> Then:
>
> - recurse on the left child with range $(L, x)$,
> - recurse on the right child with range $(x, U)$.
>
> If every node satisfies its range, the tree is a valid BST.
>
> ### Pseudocode
>
> ```text
> isValidBST(root):
>     return validate(root, -∞, +∞)
>
> validate(node, low, high):
>     if node is null:
>         return true
>     
>     if node.val <= low or node.val >= high:
>         return false
>     
>     return validate(node.left, low, node.val) 
>            and validate(node.right, node.val, high)
> ```
>
> ### Correctness
>
> This works because the range passed to each node encodes all ancestor constraints:
>
> - if a node lies in a left subtree, it must be less than that ancestor,
> - if it lies in a right subtree, it must be greater than that ancestor.
>
> Thus the algorithm enforces the full BST property, not merely local parent-child comparisons.
>
> ### Complexity
>
> If the tree has $n$ nodes:
>
> - Time complexity: $O(n)$, since each node is visited once.
> - Space complexity: $O(h)$, where $h$ is the tree height, due to the recursion stack.
>
> In the worst case, $h = n$; for a balanced tree, $h = O(\log n)$.
>
> ### Final Answer
>
> To validate a binary search tree, perform a depth-first traversal while carrying valid lower and upper bounds. A tree is valid exactly when every node's value lies strictly between its inherited bounds.
