> [!example] Question 682 · Citadel
> ## Software Engineer Interview

Given a sorted array of integers and a target integer, can you find two numbers in the array such that their sum equals the target?

[Source](https://www.thewallstreetquants.com/ebook#p=683)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Because the array is sorted, the most efficient approach is the **two-pointer method**.
>
> ### Idea
>
> Let one pointer start at the beginning of the array and another at the end:
>
> - Let $i = 0$
> - Let $j = n - 1$
>
> At each step, compute
>
> $$
> s = \text{arr}[i] + \text{arr}[j]
> $$
>
> Then:
>
> - If $s = \text{target}$, the pair has been found.
> - If $s < \text{target}$, increase $i$ to make the sum larger.
> - If $s > \text{target}$, decrease $j$ to make the sum smaller.
>
> This works because the array is sorted.
>
> ---
>
> ### Algorithm
>
> Given a sorted array $\text{arr}$ of length $n$:
>
> 1. Set $i = 0$ and $j = n - 1$.
> 2. While $i < j$:
>    - Compute $\text{arr}[i] + \text{arr}[j]$.
>    - If it equals $\text{target}$, return the pair.
>    - If it is less than $\text{target}$, increment $i$.
>    - If it is greater than $\text{target}$, decrement $j$.
> 3. If the loop ends, no such pair exists.
>
> ---
>
> ### Pseudocode
>
> ```text
> function findPair(arr, target):
>     i = 0
>     j = length(arr) - 1
>
>     while i < j:
>         s = arr[i] + arr[j]
>
>         if s == target:
>             return (arr[i], arr[j])
>         else if s < target:
>             i = i + 1
>         else:
>             j = j - 1
>
>     return null
> ```
>
> ---
>
> ### Example
>
> Let the array be
>
> $$
> [1, 2, 4, 7, 11, 15]
> $$
>
> and let the target be
>
> $$
> 15
> $$
>
> Start with:
>
> - $i = 0$, value $1$
> - $j = 5$, value $15$
>
> Then:
>
> $$
> 1 + 15 = 16 > 15
> $$
>
> So decrease $j$.
>
> Now:
>
> $$
> 1 + 11 = 12 < 15
> $$
>
> So increase $i$.
>
> Now:
>
> $$
> 2 + 11 = 13 < 15
> $$
>
> Increase $i$.
>
> Now:
>
> $$
> 4 + 11 = 15
> $$
>
> Thus the required pair is
>
> $$
> (4, 11)
> $$
>
> ---
>
> ### Complexity
>
> - Time complexity: $$O(n)$$
> - Space complexity: $$O(1)$$
>
> ---
>
> ## Final Answer
>
> Yes. In a sorted array, two numbers summing to a target can be found efficiently using two pointers:
>
> - one at the start,
> - one at the end,
>
> and moving them inward based on whether the current sum is less than or greater than the target. This finds a valid pair in $$O(n)$$ time and $$O(1)$$ extra space.
