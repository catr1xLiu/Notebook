> [!example] Question 712 · Citadel
> ## Quantitative Researcher Interview

Write a program to find the square root of a number.

[Source](https://www.thewallstreetquants.com/ebook#p=713)

> [!success]- Solution (Click to expand)
> ```python
> # Program to find the square root of a number
>
> num = float(input("Enter a number: "))
>
> if num < 0:
>     print("Square root is not defined for negative numbers in real numbers.")
> else:
>     sqrt_num = num ** 0.5
>     print("Square root =", sqrt_num)
> ```
>
> For example, if the input is $25$, the output is:
>
> ```python
> Square root = 5.0
> ```
