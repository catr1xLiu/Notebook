> [!example] Question 809 · Citadel
> ## Quantitative Developer Interview

Given a vector of edges (e.g., A-B, A-C, C-D), write a function to determine if the resulting graph is a tree. If it is a tree, return its root.

[Source](https://www.thewallstreetquants.com/ebook#p=810)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Treat the input as an undirected graph whose vertices are the distinct labels appearing in the edge list.
>
> A graph is a tree if and only if it is:
>
> 1. **Connected**, and
> 2. **Acyclic**
>
> For an undirected graph with $n$ vertices and $m$ edges, this is equivalent to checking:
>
> - $m = n - 1$, and
> - the graph is connected
>
> If the graph is a tree, then there is **no unique root** unless one is specified. Any vertex may be chosen as a root. Thus, after verifying that the graph is a tree, one may return any vertex, for example the first one encountered.
>
> ### Approach
>
> Given edges such as $(A,B), (A,C), (C,D)$:
>
> 1. Build an adjacency list.
> 2. Count vertices $n$ and edges $m$.
> 3. If $m \ne n-1$, it is not a tree.
> 4. Run DFS or BFS from any vertex.
> 5. If all vertices are visited, the graph is connected; combined with $m=n-1$, it is a tree.
> 6. Return any visited start vertex as the root.
>
> ### Python implementation
>
> ```python
> def determine_tree_and_root(edges):
>     if not edges:
>         return False, None
>
>     # Build adjacency list
>     graph = {}
>     for u, v in edges:
>         if u == v:
>             return False, None  # self-loop => not a tree
>         graph.setdefault(u, []).append(v)
>         graph.setdefault(v, []).append(u)
>
>     vertices = list(graph.keys())
>     n = len(vertices)
>     m = len(edges)
>
>     # Necessary condition for a tree
>     if m != n - 1:
>         return False, None
>
>     # Check connectivity with DFS
>     root = vertices[0]
>     visited = set()
>     stack = [root]
>
>     while stack:
>         node = stack.pop()
>         if node in visited:
>             continue
>         visited.add(node)
>         for nei in graph[node]:
>             if nei not in visited:
>                 stack.append(nei)
>
>     if len(visited) != n:
>         return False, None
>
>     return True, root
> ```
>
> ### Example
>
> For the edges
>
> ```python
> edges = [('A', 'B'), ('A', 'C'), ('C', 'D')]
> ```
>
> the graph has:
>
> - $n = 4$ vertices: $\{A,B,C,D\}$
> - $m = 3$ edges
>
> Since $m = n - 1 = 3$ and the graph is connected, it is a tree. The function may return:
>
> ```python
> (True, 'A')
> ```
>
> although returning `'B'`, `'C'`, or `'D'` as the root would also be valid.
>
> ## Final Answer
>
> Use the fact that an undirected graph is a tree exactly when it has $n-1$ edges and is connected. If so, return any node as the root, since a tree does not have a unique root unless one is specified.
