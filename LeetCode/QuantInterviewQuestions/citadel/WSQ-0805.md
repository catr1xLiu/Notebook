How do you implement a hash map in C\#?

> # Implementing a Hash Map in C\#
>
> In C#, the built-in hash map is `Dictionary<TKey, TValue>`. If the goal is to *use* a hash map, `Dictionary` is the standard choice. If the goal is to *implement one manually*, the usual approach is to use:
>
> - an array of buckets,
> - a hash function,
> - collision handling, typically by **chaining**.
>
> ## 1. Using the built-in hash map
>
> A simple example:
>
> ```csharp
> using System;
> using System.Collections.Generic;
>
> class Program
> {
>     static void Main()
>     {
>         Dictionary<string, int> map = new Dictionary<string, int>();
>
>         map["apple"] = 10;
>         map["banana"] = 20;
>
>         Console.WriteLine(map["apple"]); // 10
>
>         if (map.ContainsKey("banana"))
>         {
>             Console.WriteLine(map["banana"]); // 20
>         }
>
>         map.Remove("apple");
>     }
> }
> ```
>
> This is the practical answer in most applications.
>

> # 2. Implementing a simple hash map from scratch
>
> ## Idea
>
> A hash map stores key-value pairs and supports operations such as:
>
> - `Put(key, value)`
> - `Get(key)`
> - `Remove(key)`
>
> The implementation below uses **separate chaining**:
>
> - The table is an array.
> - Each position in the array is a bucket.
> - Each bucket stores a linked list of entries.
> - If two keys hash to the same bucket, both are placed in that list.
>
> ---
>
> ## 3. Implementation
>
> ```csharp
> using System;
> using System.Collections.Generic;
>
> public class MyHashMap<TKey, TValue>
> {
>     private class Entry
>     {
>         public TKey Key;
>         public TValue Value;
>         public Entry Next;
>
>         public Entry(TKey key, TValue value)
>         {
>             Key = key;
>             Value = value;
>             Next = null;
>         }
>     }
>
>     private Entry[] buckets;
>     private int count;
>     private const double LoadFactorThreshold = 0.75;
>
>     public MyHashMap(int capacity = 16)
>     {
>         buckets = new Entry[capacity];
>         count = 0;
>     }
>
>     private int GetBucketIndex(TKey key, int length)
>     {
>         if (key == null)
>             throw new ArgumentNullException(nameof(key));
>
>         int hash = key.GetHashCode() & 0x7fffffff;
>         return hash % length;
>     }
>
>     public void Put(TKey key, TValue value)
>     {
>         if ((double)(count + 1) / buckets.Length > LoadFactorThreshold)
>         {
>             Resize();
>         }
>
>         int index = GetBucketIndex(key, buckets.Length);
>         Entry current = buckets[index];
>
>         while (current != null)
>         {
>             if (EqualityComparer<TKey>.Default.Equals(current.Key, key))
>             {
>                 current.Value = value;
>                 return;
>             }
>             current = current.Next;
>         }
>
>         Entry newEntry = new Entry(key, value);
>         newEntry.Next = buckets[index];
>         buckets[index] = newEntry;
>         count++;
>     }
>
>     public TValue Get(TKey key)
>     {
>         int index = GetBucketIndex(key, buckets.Length);
>         Entry current = buckets[index];
>
>         while (current != null)
>         {
>             if (EqualityComparer<TKey>.Default.Equals(current.Key, key))
>             {
>                 return current.Value;
>             }
>             current = current.Next;
>         }
>
>         throw new KeyNotFoundException("Key not found.");
>     }
>
>     public bool TryGet(TKey key, out TValue value)
>     {
>         int index = GetBucketIndex(key, buckets.Length);
>         Entry current = buckets[index];
>
>         while (current != null)
>         {
>             if (EqualityComparer<TKey>.Default.Equals(current.Key, key))
>             {
>                 value = current.Value;
>                 return true;
>             }
>             current = current.Next;
>         }
>
>         value = default!;
>         return false;
>     }
>
>     public bool Remove(TKey key)
>     {
>         int index = GetBucketIndex(key, buckets.Length);
>         Entry current = buckets[index];
>         Entry previous = null;
>
>         while (current != null)
>         {
>             if (EqualityComparer<TKey>.Default.Equals(current.Key, key))
>             {
>                 if (previous == null)
>                 {
>                     buckets[index] = current.Next;
>                 }
>                 else
>                 {
>                     previous.Next = current.Next;
>                 }
>
>                 count--;
>                 return true;
>             }
>
>             previous = current;
>             current = current.Next;
>         }
>
>         return false;
>     }
>
>     public bool ContainsKey(TKey key)
>     {
>         return TryGet(key, out _);
>     }
>
>     public int Count => count;
>
>     private void Resize()
>     {
>         Entry[] oldBuckets = buckets;
>         buckets = new Entry[oldBuckets.Length * 2];
>         count = 0;
>
>         foreach (Entry head in oldBuckets)
>         {
>             Entry current = head;
>             while (current != null)
>             {
>                 Put(current.Key, current.Value);
>                 current = current.Next;
>             }
>         }
>     }
> }
> ```
>

> ## 4. Example usage
>
> ```csharp
> using System;
>
> class Program
> {
>     static void Main()
>     {
>         MyHashMap<string, int> map = new MyHashMap<string, int>();
>
>         map.Put("one", 1);
>         map.Put("two", 2);
>         map.Put("three", 3);
>
>         Console.WriteLine(map.Get("two")); // 2
>
>         map.Put("two", 22);
>         Console.WriteLine(map.Get("two")); // 22
>
>         Console.WriteLine(map.ContainsKey("three")); // True
>
>         map.Remove("one");
>         Console.WriteLine(map.Count); // 2
>     }
> }
> ```

> # 5. How it works
>
> ## Hashing
>
> For a key, the method
>
> ```csharp
> key.GetHashCode()
> ```
>
> produces an integer hash code. The bucket index is computed as:
>
> ```csharp
> int index = (key.GetHashCode() & 0x7fffffff) % buckets.Length;
> ```
>
> The bitwise operation ensures a non-negative value.
>
> ## Collision handling
>
> Two different keys may produce the same bucket index. This is called a collision. In this implementation, collisions are handled by linked lists inside each bucket.
>
> ## Resizing
>
> When the load factor exceeds $0.75$, the array size is doubled and all entries are rehashed into the new bucket array.
>
> ---
>
> # 6. Time complexity
>
> Under typical assumptions:
>
> - `Put`: average $O(1)$
> - `Get`: average $O(1)$
> - `Remove`: average $O(1)$
>
> In the worst case, if many keys collide into one bucket:
>
> - `Put`: $O(n)$
> - `Get`: $O(n)$
> - `Remove`: $O(n)$
>
> ---
>
> # 7. Notes
>
> - `Dictionary<TKey, TValue>` is highly optimized and should generally be preferred.
> - A custom implementation is useful for learning or for specialized behavior.
> - Good performance depends on a good distribution of hash codes from `GetHashCode()`.
>
> # Final answer
>
> To implement a hash map in C\#, the standard practical choice is `Dictionary<TKey, TValue>`. If implementing one manually, use an array of buckets plus collision handling via chaining, as shown in the `MyHashMap<TKey, TValue>` example above. This supports insertion, lookup, update, and removal with average-case time complexity $O(1)$.
