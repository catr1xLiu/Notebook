> [!example] Question 770 · Citadel
> ## Software Engineer Interview

Implement a queue using a stack.

[Source](https://www.thewallstreetquants.com/ebook#p=771)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To implement a queue using a stack, use the fact that a queue is **FIFO** (first-in, first-out), while a stack is **LIFO** (last-in, first-out). The standard way is to use **two stacks**:
>
> - $S_{\text{in}}$ for enqueue operations
> - $S_{\text{out}}$ for dequeue operations
>
> ### Idea
>
> - **Enqueue**: push the new element onto $S_{\text{in}}$.
> - **Dequeue**:
>   - If $S_{\text{out}}$ is nonempty, pop from it.
>   - Otherwise, move all elements from $S_{\text{in}}$ to $S_{\text{out}}$ by repeated pop/push. This reverses the order, so the oldest element becomes the top of $S_{\text{out}}$.
>   - Then pop from $S_{\text{out}}$.
>
> This preserves queue order.
>
> ## Implementation
>
> ```python
> class MyQueue:
>     def __init__(self):
>         self.s_in = []
>         self.s_out = []
>
>     def enqueue(self, x):
>         self.s_in.append(x)
>
>     def dequeue(self):
>         if self.empty():
>             raise IndexError("dequeue from empty queue")
>
>         if not self.s_out:
>             while self.s_in:
>                 self.s_out.append(self.s_in.pop())
>
>         return self.s_out.pop()
>
>     def front(self):
>         if self.empty():
>             raise IndexError("front from empty queue")
>
>         if not self.s_out:
>             while self.s_in:
>                 self.s_out.append(self.s_in.pop())
>
>         return self.s_out[-1]
>
>     def empty(self):
>         return len(self.s_in) == 0 and len(self.s_out) == 0
> ```
>
> ## Example
>
> Perform the operations:
>
> - $\text{enqueue}(1)$
> - $\text{enqueue}(2)$
> - $\text{enqueue}(3)$
> - $\text{dequeue}()$
>
> After the three enqueue operations:
>
> - $S_{\text{in}} = [1,2,3]$
> - $S_{\text{out}} = []$
>
> When $\text{dequeue}()$ is called, transfer all elements:
>
> - move $3$, then $2$, then $1$ into $S_{\text{out}}$
>
> Now:
>
> - $S_{\text{in}} = []$
> - $S_{\text{out}} = [3,2,1]$
>
> Popping from $S_{\text{out}}$ returns $1$, which is the correct front of the queue.
>
> ## Complexity
>
> - $\text{enqueue}$: $O(1)$
> - $\text{dequeue}$: amortized $O(1)$
> - $\text{front}$: amortized $O(1)$
> - Space: $O(n)$
>
> The amortized bound holds because each element is moved at most once from $S_{\text{in}}$ to $S_{\text{out}}$, and popped at most once.
>
> ## Final Answer
>
> A queue can be implemented using two stacks:
>
> - push new elements into one stack,
> - pop elements from the other,
> - and when the output stack is empty, transfer all elements from the input stack to the output stack.
>
> This gives correct queue behavior with amortized $O(1)$ time per operation.
