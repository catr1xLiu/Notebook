> [!example] Question 737 · Citadel
> ## Quantitative Analyst Interview

How would you run a Monte Carlo simulation in Python to predict the probability of obtaining 4 out of 6 coins as heads, without using for loops?

[Source](https://www.thewallstreetquants.com/ebook#p=738)

> [!success]- Solution (Click to expand)
> To estimate the probability of getting exactly $4$ heads in $6$ coin tosses by Monte Carlo simulation **without using explicit `for` loops**, use **NumPy vectorization**.
>
> ## Approach
>
> Each simulation consists of $6$ independent fair coin flips. Represent:
>
> - head as $1$
> - tail as $0$
>
> Then:
>
> 1. Generate many trials at once in a $N \times 6$ array.
> 2. Sum each row to count the number of heads in each trial.
> 3. Check how many trials have exactly $4$ heads.
> 4. Take the mean of that boolean condition to estimate the probability.
>
> ## Python code
>
> ```python
> import numpy as np
>
> # number of Monte Carlo trials
> N = 1_000_000
>
> # simulate N trials of 6 fair coin flips
> # each entry is 0 or 1 with equal probability
> flips = np.random.randint(0, 2, size=(N, 6))
>
> # count heads in each trial
> heads_per_trial = flips.sum(axis=1)
>
> # estimate probability of exactly 4 heads
> prob_estimate = np.mean(heads_per_trial == 4)
>
> print(prob_estimate)
> ```
>
> ## Why this works
>
> - `np.random.randint(0, 2, size=(N, 6))` creates all coin flips at once.
> - `sum(axis=1)` gives the number of heads in each of the $N$ trials.
> - `heads_per_trial == 4` produces a boolean array:
>   - `True` if a trial has exactly $4$ heads
>   - `False` otherwise
> - `np.mean(...)` converts `True` to $1$ and `False` to $0$, giving the proportion of successful trials.
>
> ## Exact probability
>
> The theoretical probability is
>
> $$
> P(X = 4) = \binom{6}{4}\left(\frac{1}{2}\right)^6
> $$
>
> Since $\binom{6}{4} = 15$,
>
> $$
> P(X = 4) = \frac{15}{64} = 0.234375
> $$
>
> So the simulation output should be close to
>
> $$
> 0.234375
> $$
>
> ## Alternative using a binomial generator
>
> Since the number of heads in $6$ fair tosses follows $X \sim \text{Binomial}(6, 0.5)$, an even shorter simulation is:
>
> ```python
> import numpy as np
>
> N = 1_000_000
> heads = np.random.binomial(n=6, p=0.5, size=N)
> prob_estimate = np.mean(heads == 4)
>
> print(prob_estimate)
> ```
>
> This also avoids `for` loops and is typically more efficient.
>
> ## Final answer
>
> A loop-free Monte Carlo simulation in Python can be done by generating all trials at once with NumPy and computing
>
> $$
> \hat{P}(X=4)=\frac{1}{N}\sum_{i=1}^N \mathbf{1}\{X_i=4\}.
> $$
>
> A vectorized implementation is:
>
> ```python
> import numpy as np
>
> N = 1_000_000
> flips = np.random.randint(0, 2, size=(N, 6))
> prob_estimate = np.mean(flips.sum(axis=1) == 4)
> print(prob_estimate)
> ```
>
> This should produce an estimate close to the exact probability
>
> $$
> \frac{15}{64} = 0.234375.
> $$
