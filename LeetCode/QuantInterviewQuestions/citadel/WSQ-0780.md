> ## Software Engineer Interview

Implement a function to compute the nth Fibonacci number using memoization.

[Source](https://www.thewallstreetquants.com/ebook#p=781)

> [!success]- Solution (Click to expand)
> ## Fibonacci Number Using Memoization
>
> To compute the $n$th Fibonacci number efficiently, use **memoization**, which stores previously computed values so they are not recomputed.
>
> The Fibonacci sequence is defined by
>
> $$
> F(0) = 0, \qquad F(1) = 1
> $$
>
> and for $n \ge 2$,
>
> $$
> F(n) = F(n-1) + F(n-2)
> $$
>
> ### Idea of Memoization
>
> A direct recursive implementation repeatedly solves the same subproblems.  
> For example, computing $F(5)$ requires $F(4)$ and $F(3)$, and computing $F(4)$ again requires $F(3)$ and $F(2)$. Thus $F(3)$ is computed multiple times.
>
> Memoization avoids this by storing each computed value in a table:
>
> - If $F(n)$ has already been computed, return it immediately.
> - Otherwise compute it once, store it, and reuse it later.
>
> ### Algorithm
>
> 1. Create a dictionary or array $memo$.
> 2. Store the base cases:
>    $$
>    memo[0] = 0, \qquad memo[1] = 1
>    $$
> 3. Define a recursive function:
>    - If $n$ is in $memo$, return $memo[n]$.
>    - Otherwise compute
>      $$
>      memo[n] = fib(n-1) + fib(n-2)
>      $$
>      and return it.
>
> ### Python Implementation
>
> ```python
> def fib(n, memo={}):
>     if n in memo:
>         return memo[n]
>     if n == 0:
>         return 0
>     if n == 1:
>         return 1
>
>     memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
>     return memo[n]
>
> # Example
> print(fib(10))   # 55
> ```
>
> ### Improved Version
>
> It is safer not to use a mutable default argument. A better implementation is:
>
> ```python
> def fib(n, memo=None):
>     if memo is None:
>         memo = {}
>
>     if n in memo:
>         return memo[n]
>     if n == 0:
>         return 0
>     if n == 1:
>         return 1
>
>     memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
>     return memo[n]
>
> print(fib(10))   # 55
> ```
>
> ### Example Trace
>
> To compute $F(5)$:
>
> $$
> F(5) = F(4) + F(3)
> $$
>
> $$
> F(4) = F(3) + F(2)
> $$
>
> $$
> F(3) = F(2) + F(1)
> $$
>
> $$
> F(2) = F(1) + F(0) = 1
> $$
>
> Then memoized values are reused:
>
> - $F(2) = 1$
> - $F(3) = 2$
> - $F(4) = 3$
> - $F(5) = 5$
>
> ### Time and Space Complexity
>
> With memoization:
>
> - **Time complexity:** $O(n)$, because each value from $0$ to $n$ is computed at most once.
> - **Space complexity:** $O(n)$, for the memo table and recursion stack.
>
> ### Final Answer
>
> Memoization computes Fibonacci numbers efficiently by storing previously computed values. The recurrence is
>
> $$
> F(0) = 0,\qquad F(1) = 1,\qquad F(n) = F(n-1) + F(n-2)
> $$
>
> and the memoized implementation runs in $O(n)$ time and $O(n)$ space.
