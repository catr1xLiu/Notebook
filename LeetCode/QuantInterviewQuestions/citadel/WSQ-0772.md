> [!example] Question 772 · Citadel
> ## Software Developer Interview

Given a sentence containing three types of brackets—parentheses (), square brackets \[\], and curly braces \{\}—determine if the brackets are properly matched and ordered.

[Source](https://www.thewallstreetquants.com/ebook#p=773)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To determine whether a sentence has the correct order of opening and closing brackets for the three bracket types
>
> - $()$
> - $[]$
> - $\{\}$
>
> the standard method is to use a **stack**.
>
> ### Idea
>
> Scan the sentence from left to right.
>
> - When an **opening bracket** is found, push it onto the stack.
> - When a **closing bracket** is found, check the top of the stack:
>   - if the stack is empty, the order is wrong;
>   - otherwise, the top must be the matching opening bracket.
> - After processing the whole sentence:
>   - if the stack is empty, the bracket order is correct;
>   - otherwise, it is incorrect.
>
> This works because brackets must close in the reverse order in which they are opened.
>
> ---
>
> ## Algorithm
>
> Let the stack initially be empty.
>
> For each character $c$ in the sentence:
>
> 1. If $c \in \{(,[,\{\}$, push $c$ onto the stack.
> 2. If $c \in \{),],\}\}$:
>    - if the stack is empty, return **incorrect**;
>    - pop the top element $t$;
>    - check whether $t$ matches $c$:
>      - $( \leftrightarrow )$
>      - $[ \leftrightarrow ]$
>      - $\{ \leftrightarrow \}$
>    - if not matched, return **incorrect**.
> 3. Ignore all other characters.
>
> After the scan, if the stack is empty, return **correct**; otherwise return **incorrect**.
>
> ---
>
> ## Pseudocode
>
> ```text
> function isBalanced(sentence):
>     stack = empty stack
>
>     for each character c in sentence:
>         if c is '(' or '[' or '{':
>             push c onto stack
>
>         else if c is ')' or ']' or '}':
>             if stack is empty:
>                 return false
>
>             t = pop from stack
>
>             if (c == ')' and t != '(') or
>                (c == ']' and t != '[') or
>                (c == '}' and t != '{'):
>                 return false
>
>     return stack is empty
> ```
>
> ---
>
> ## Example
>
> For the sentence
>
> $$
> \texttt{"a[ b(c)\{d\} ]"}
> $$
>
> the bracket processing is:
>
> - $[$ pushed
> - $( $ pushed
> - $)$ matches $( $
> - $\{$ pushed
> - $\}$ matches $\{$
> - $]$ matches $[$
>
> The stack is empty at the end, so the order is **correct**.
>
> For
>
> $$
> \texttt{"([)]"}
> $$
>
> the processing gives:
>
> - $( $ pushed
> - $[$ pushed
> - $)$ appears, but the top is $[$, not $( $
>
> So the order is **incorrect**.
>
> ---
>
> ## Complexity
>
> Let $n$ be the length of the sentence.
>
> - **Time complexity:** $O(n)$
> - **Space complexity:** $O(n)$ in the worst case
>
> ---
>
> ## Final Answer
>
> A sentence has the right order of brackets if, when scanned left to right, every closing bracket matches the most recent unmatched opening bracket of the same type, and no unmatched opening brackets remain at the end. This can be checked using a stack in $O(n)$ time.
