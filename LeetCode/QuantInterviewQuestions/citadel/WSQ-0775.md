> ## Implementing a Hashtable with Collision Handling by Probing
>
> A hashtable stores key-value pairs in an array and uses a hash function to map each key to an array index. Since different keys may map to the same index, collisions must be resolved. With **probing**, collisions are handled by searching for another available slot in the table.
>
> ### 1. Idea of Open Addressing with Probing
>
> Let the table size be $m$, and let the hash function be $h(k)$.  
> If the slot $h(k)$ is occupied, probe other slots according to a rule until either:
>
> - the key is found,
> - an empty slot is found, or
> - the whole table has been checked.
>
> A common probing strategy is **linear probing**:
>
> $$
> \text{index}_i = (h(k) + i) \bmod m, \qquad i = 0,1,2,\dots
> $$
>
> This checks consecutive positions.
>
> ### 2. Required Operations
>
> A hashtable should support:
>
> - **insert**$(k,v)$
> - **get**$(k)$
> - **delete**$(k)$
>
> To make deletion work correctly in open addressing, one cannot simply mark a deleted slot as empty, because that would break future searches. Instead, use a special marker, often called **deleted**.
>

>
> ## Python Implementation
>
> ```python
> class _DeletedEntry:
>     pass
>
>
> DELETED = _DeletedEntry()
>
>
> class HashTable:
>     def __init__(self, capacity=8):
>         self.capacity = capacity
>         self.size = 0
>         self.table = [None] * capacity
>
>     def _hash(self, key):
>         return hash(key) % self.capacity
>
>     def _probe(self, key):
>         start = self._hash(key)
>         first_deleted = None
>
>         for i in range(self.capacity):
>             idx = (start + i) % self.capacity
>             entry = self.table[idx]
>
>             if entry is None:
>                 return first_deleted if first_deleted is not None else idx
>
>             if entry is DELETED:
>                 if first_deleted is None:
>                     first_deleted = idx
>                 continue
>
>             k, _ = entry
>             if k == key:
>                 return idx
>
>         return first_deleted if first_deleted is not None else -1
>
>     def _needs_resize(self):
>         return self.size / self.capacity > 0.7
>
>     def _resize(self):
>         old_table = self.table
>         self.capacity *= 2
>         self.table = [None] * self.capacity
>         old_size = self.size
>         self.size = 0
>
>         for entry in old_table:
>             if entry is not None and entry is not DELETED:
>                 key, value = entry
>                 self.insert(key, value)
>
>         self.size = old_size
>
>     def insert(self, key, value):
>         if self._needs_resize():
>             self._resize()
>
>         idx = self._probe(key)
>         if idx == -1:
>             raise Exception("Hashtable is full")
>
>         if self.table[idx] is None or self.table[idx] is DELETED:
>             self.size += 1
>
>         self.table[idx] = (key, value)
>
>     def get(self, key):
>         start = self._hash(key)
>
>         for i in range(self.capacity):
>             idx = (start + i) % self.capacity
>             entry = self.table[idx]
>
>             if entry is None:
>                 break
>
>             if entry is DELETED:
>                 continue
>
>             k, v = entry
>             if k == key:
>                 return v
>
>         raise KeyError(key)
>
>     def delete(self, key):
>         start = self._hash(key)
>
>         for i in range(self.capacity):
>             idx = (start + i) % self.capacity
>             entry = self.table[idx]
>
>             if entry is None:
>                 break
>
>             if entry is DELETED:
>                 continue
>
>             k, _ = entry
>             if k == key:
>                 self.table[idx] = DELETED
>                 self.size -= 1
>                 return
>
>         raise KeyError(key)
>
>     def __contains__(self, key):
>         try:
>             self.get(key)
>             return True
>         except KeyError:
>             return False
>
>     def __len__(self):
>         return self.size
>
>     def __repr__(self):
>         items = []
>         for entry in self.table:
>             if entry is not None and entry is not DELETED:
>                 items.append(f"{entry[0]}: {entry[1]}")
>         return "{" + ", ".join(items) + "}"
> ```
>

> ## 3. How Collision Handling Works
>
> Suppose the table size is $8$, and both keys $10$ and $18$ hash to index $2$:
>
> $$
> h(10) = 2, \qquad h(18) = 2
> $$
>
> - Insert $10$: place it at index $2$.
> - Insert $18$: index $2$ is occupied, so probe:
>   - check index $3$,
>   - if empty, place $18$ there.
>
> Thus collisions are resolved without using linked lists.
>

> ## 4. Example Usage
>
> ```python
> ht = HashTable()
>
> ht.insert("apple", 5)
> ht.insert("banana", 8)
> ht.insert("orange", 12)
>
> print(ht.get("apple"))    # 5
> print("banana" in ht)     # True
>
> ht.delete("banana")
> print("banana" in ht)     # False
>
> ht.insert("grape", 20)
> print(ht)
> ```

> ## 5. Time Complexity
>
> Under a low load factor, the expected time for operations is:
>
> - **insert**: $O(1)$ average
> - **get**: $O(1)$ average
> - **delete**: $O(1)$ average
>
> In the worst case, probing may scan the entire table:
>
> $$
> O(m)
> $$
>
> where $m$ is the table capacity.
>

> ## 6. Remarks
>
> Linear probing is simple and cache-friendly, but it suffers from **primary clustering**. Other probing methods include:
>
> - **quadratic probing**:
>   $$
>   (h(k) + i^2) \bmod m
>   $$
> - **double hashing**:
>   $$
>   (h_1(k) + i \cdot h_2(k)) \bmod m
>   $$
>
> These can reduce clustering.
>
> ## Final Answer
>
> A hashtable with collision handling by probing can be implemented using **open addressing** and **linear probing**, as shown above. The key points are:
>
> - compute the initial slot with a hash function,
> - on collision, probe subsequent slots,
> - use a special **deleted** marker for removals,
> - resize the table when the load factor becomes too large.
>
> The provided Python implementation correctly supports insertion, lookup, deletion, and collision resolution by probing.
