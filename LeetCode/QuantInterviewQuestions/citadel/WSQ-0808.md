> ## $k$-Nearest Neighbour Algorithm
>
> The $k$-nearest neighbour ($k$-NN) algorithm is a supervised learning method used for **classification** and **regression**. It predicts the output for a new input by looking at the $k$ training examples closest to it.
>
> ---
>
> ## Algorithm Idea
>
> Given:
>
> - a training set $\{(x_1, y_1), (x_2, y_2), \dots, (x_n, y_n)\}$
> - a query point $x$
> - a chosen integer $k$
>
> the algorithm proceeds as follows:
>
> 1. Compute the distance from $x$ to every training point $x_i$.
> 2. Sort the training points by increasing distance.
> 3. Select the $k$ closest points.
> 4. Predict:
>    - **Classification:** the majority class among the $k$ neighbours.
>    - **Regression:** the average of the $k$ neighbours' target values.
>
> A common distance is the Euclidean distance:
>
> $$
> d(x, x_i) = \sqrt{\sum_{j=1}^{m} (x_j - x_{ij})^2}
> $$
>
> where $m$ is the number of features.
>
> ---
>
> ## Python Implementation
>
> ```python
> from collections import Counter
> import math
>
> class KNearestNeighbour:
>     def __init__(self, k=3, task='classification'):
>         self.k = k
>         self.task = task
>         self.X_train = []
>         self.y_train = []
>
>     def fit(self, X, y):
>         self.X_train = X
>         self.y_train = y
>
>     def _euclidean_distance(self, a, b):
>         return math.sqrt(sum((x - y) ** 2 for x, y in zip(a, b)))
>
>     def _predict_one(self, x):
>         distances = []
>         for x_train, y_train in zip(self.X_train, self.y_train):
>             dist = self._euclidean_distance(x, x_train)
>             distances.append((dist, y_train))
>
>         distances.sort(key=lambda t: t[0])
>         k_neighbours = [label for _, label in distances[:self.k]]
>
>         if self.task == 'classification':
>             return Counter(k_neighbours).most_common(1)[0][0]
>         elif self.task == 'regression':
>             return sum(k_neighbours) / len(k_neighbours)
>         else:
>             raise ValueError("task must be 'classification' or 'regression'")
>
>     def predict(self, X):
>         return [self._predict_one(x) for x in X]
> ```
>

>
> ## Example: Classification
>
> ```python
> X_train = [
>     [1, 2],
>     [2, 3],
>     [3, 3],
>     [6, 5],
>     [7, 7],
>     [8, 6]
> ]
>
> y_train = ['A', 'A', 'A', 'B', 'B', 'B']
>
> knn = KNearestNeighbour(k=3, task='classification')
> knn.fit(X_train, y_train)
>
> X_test = [[5, 5], [2, 2]]
> predictions = knn.predict(X_test)
>
> print(predictions)
> ```

> ```python

> ```

> ## Remarks
>
> - The algorithm is simple and requires no explicit training phase beyond storing the data.
> - Its prediction cost can be high because distances to all training points must be computed.
> - Feature scaling is important, since distance-based methods are sensitive to differences in units.
> - Choosing $k$ too small can make the model noisy; choosing $k$ too large can oversmooth predictions.
>
