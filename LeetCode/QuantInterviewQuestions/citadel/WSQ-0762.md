> [!example] Question 762 · Citadel
> ## Software Engineering Intern Interview

Reverse a linked list in place.

[Source](https://www.thewallstreetquants.com/ebook#p=763)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To reverse a singly linked list *in place*, the links between nodes must be redirected so that each node points to its predecessor instead of its successor.
>
> ### Idea
>
> Maintain three pointers:
>
> - $prev$: the previous node, initially $null$
> - $curr$: the current node being processed, initially the head
> - $next$: temporarily stores the next node so the rest of the list is not lost
>
> At each step:
>
> 1. Save $curr.next$ in $next$
> 2. Reverse the pointer by setting $curr.next = prev$
> 3. Advance $prev$ to $curr$
> 4. Advance $curr$ to $next$
>
> When the traversal ends, $prev$ points to the new head of the reversed list.
>
> ---
>
> ### Algorithm
>
> Given the head pointer $head$:
>
> $$
> prev \leftarrow null
> $$
>
> $$
> curr \leftarrow head
> $$
>
> While $curr \neq null$:
>
> 1. $next \leftarrow curr.next$
> 2. $curr.next \leftarrow prev$
> 3. $prev \leftarrow curr$
> 4. $curr \leftarrow next$
>
> Return $prev$.
>
> ---
>
> ### Correctness
>
> At the start of each iteration:
>
> - $prev$ is the head of the already reversed prefix
> - $curr$ is the head of the remaining unreversed suffix
>
> The operation $curr.next \leftarrow prev$ moves the first node of the unreversed suffix to the front of the reversed prefix. Thus, after each iteration, the reversed prefix grows by one node and the unreversed suffix shrinks by one node.
>
> When $curr = null$, the unreversed suffix is empty, so the entire list has been reversed. Therefore, $prev$ is the head of the reversed list.
>
> ---
>
> ### Code
>
> ```python
> def reverse_list(head):
>     prev = None
>     curr = head
>
>     while curr is not None:
>         nxt = curr.next
>         curr.next = prev
>         prev = curr
>         curr = nxt
>
>     return prev
> ```
>
> ---
>
> ### Complexity
>
> The list is traversed once, so the time complexity is
>
> $$
> O(n)
> $$
>
> where $n$ is the number of nodes.
>
> Only a constant amount of extra space is used, so the space complexity is
>
> $$
> O(1)
> $$
>
> ---
>
> ### Final Answer
>
> Reverse the linked list in place by iterating through the nodes and redirecting each node’s $next$ pointer to the previous node. The new head is the last non-null node processed, stored in $prev$.
