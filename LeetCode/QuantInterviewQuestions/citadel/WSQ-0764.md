> [!example] Question 764 · Citadel
> ## Software Engineer Interview

Given an array representing user events, find the length of the longest contiguous subarray where the most frequent user in that subarray has the same number of events as the least frequent user in the entire event log. Write an efficient function to solve this problem.

[Source](https://www.thewallstreetquants.com/ebook#p=765)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Let the event log be an array $A$ of length $n$, where each entry is a user ID.
>
> We seek the maximum length of a contiguous subarray $A[l \dots r]$ such that:
>
> - if $f_x(l,r)$ denotes the frequency of user $x$ inside $A[l \dots r]$,
> - and if
>   $$
>   m = \min_{u} \bigl(\text{total frequency of user } u \text{ in the entire array}\bigr),
>   $$
>   then the subarray must satisfy
>   $$
>   \max_x f_x(l,r) = m.
>   $$
>
> Thus, in the chosen subarray:
>
> - no user may appear more than $m$ times, and
> - at least one user must appear exactly $m$ times.
>
> The goal is to compute the maximum possible subarray length efficiently.
>
> ---
>
> ## Key observation
>
> A subarray is valid exactly when its maximum frequency is $m$.
>
> This suggests a sliding-window approach:
>
> - maintain frequencies of users inside the current window,
> - ensure that no frequency exceeds $m$,
> - whenever some user frequency becomes $m$, the window is valid.
>
> So the problem reduces to finding the longest window in which every user count is at most $m$, and at least one user count is exactly $m$.
>
> ---
>
> ## Step 1: Compute the global minimum frequency
>
> First count the total occurrences of each user in the whole array.
>
> If the total count of user $u$ is $T_u$, then
> $$
> m = \min_u T_u.
> $$
>
> This value is fixed for the entire problem.
>
> ---
>
> ## Step 2: Sliding window
>
> Use two pointers:
>
> - $l$ = left boundary,
> - $r$ = right boundary.
>
> Maintain:
>
> - a frequency map $\text{cnt}$ for the current window,
> - the current maximum frequency in the window.
>
> As we extend $r$:
>
> 1. include $A[r]$ in the window,
> 2. if some frequency exceeds $m$, move $l$ right until all frequencies are again at most $m$.
>
> Now the window satisfies
> $$
> \max_x f_x(l,r) \le m.
> $$
>
> If in addition some user appears exactly $m$ times, then
> $$
> \max_x f_x(l,r) = m,
> $$
> so the window is valid, and we update the answer.
>
> ---
>
> ## Why this works
>
> ### Lemma 1
> If a window contains some user with frequency greater than $m$, then it is invalid.
>
> **Proof.**
> The condition requires
> $$
> \max_x f_x(l,r) = m.
> $$
> If any frequency is greater than $m$, then
> $$
> \max_x f_x(l,r) > m,
> $$
> so the condition fails. ∎
>
> ### Lemma 2
> If every user frequency in the window is at most $m$, and some user frequency is exactly $m$, then the window is valid.
>
> **Proof.**
> Since all frequencies are at most $m$,
> $$
> \max_x f_x(l,r) \le m.
> $$
> If some user appears exactly $m$ times, then
> $$
> \max_x f_x(l,r) \ge m.
> $$
> Hence
> $$
> \max_x f_x(l,r) = m.
> $$
> So the window is valid. ∎
>
> ### Lemma 3
> The sliding-window process examines all maximal valid windows.
>
> **Proof.**
> The right pointer only moves forward. Whenever adding a new element causes some count to exceed $m$, the left pointer advances until the constraint “all counts $\le m$” is restored. Therefore, for each fixed right endpoint, the algorithm maintains the longest feasible window ending there. Any longer window ending at that point would violate the frequency bound. Thus every candidate for the optimum is considered. ∎
>
> From these lemmas, the algorithm is correct.
>
> ---
>
> ## Efficient implementation detail
>
> To test whether the current window has some user with frequency exactly $m$, we can maintain a counter:
>
> - $\text{eqM}$ = number of distinct users whose current window frequency equals $m$.
>
> When a user’s count changes:
>
> - if it becomes $m$, increment $\text{eqM}$,
> - if it was $m$ and changes away from $m$, decrement $\text{eqM}$.
>
> Then the window is valid exactly when
> $$
> \text{eqM} > 0.
> $$
>
> ---
>
> ## Algorithm
>
> 1. Count total frequencies of all users in the full array.
> 2. Compute
>    $$
>    m = \min_u T_u.
>    $$
> 3. Initialize:
>    - $l = 0$,
>    - answer $= 0$,
>    - empty window frequency map,
>    - $\text{eqM} = 0$.
> 4. For each $r$ from $0$ to $n-1$:
>    - add $A[r]$ to the window,
>    - update $\text{eqM}$ accordingly,
>    - while the count of $A[r]$ is greater than $m$, shrink from the left and update frequencies and $\text{eqM}$,
>    - if $\text{eqM} > 0$, update
>      $$
>      \text{answer} = \max(\text{answer}, r-l+1).
>      $$
> 5. Return $\text{answer}$.
>
> ---
>
> ## Complexity
>
> Let $n$ be the number of events.
>
> - Computing global frequencies: $O(n)$
> - Sliding window: each pointer moves at most $n$ times, so $O(n)$
>
> Therefore the total time complexity is
> $$
> O(n),
> $$
> and the space complexity is
> $$
> O(k),
> $$
> where $k$ is the number of distinct users.
>
> ---
>
> ## Final answer
>
> The maximum length of a consistent contiguous event log can be found in linear time by:
>
> - computing the minimum total frequency $m$ of any user in the entire log,
> - using a sliding window that maintains all window frequencies $\le m$,
> - and recording the longest window in which some user appears exactly $m$ times.
>
> This yields an $O(n)$ time and $O(k)$ space solution.
