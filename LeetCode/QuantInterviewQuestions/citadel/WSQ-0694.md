> ## Quantitative Researcher Interview

Explain the difference between Lasso and Ridge regression.

[Source](https://www.thewallstreetquants.com/ebook#p=695)

> [!success]- Solution (Click to expand)
> ## Difference Between Lasso and Ridge
>
> Lasso and Ridge are both regularization methods used in regression to prevent overfitting by adding a penalty term to the loss function. Their key difference lies in the type of penalty they impose.
>
> ### 1. Ridge Regression
>
> Ridge regression adds an $L_2$ penalty, that is, the sum of squared coefficients.
>
> Its objective function is
>
> $$
> \min_{\beta_0,\beta} \left\{ \sum_{i=1}^n \left(y_i - \beta_0 - x_i^\top \beta\right)^2 + \lambda \sum_{j=1}^p \beta_j^2 \right\}.
> $$
>
> #### Effect:
> - It shrinks the coefficients toward $0$.
> - Typically, it does **not** make coefficients exactly zero.
> - Thus, Ridge keeps all predictors in the model.
>
> #### Use:
> - Appropriate when many predictors contribute a little.
> - Works well when predictors are highly correlated.
>
> ---
>
> ### 2. Lasso Regression
>
> Lasso adds an $L_1$ penalty, that is, the sum of the absolute values of the coefficients.
>
> Its objective function is
>
> $$
> \min_{\beta_0,\beta} \left\{ \sum_{i=1}^n \left(y_i - \beta_0 - x_i^\top \beta\right)^2 + \lambda \sum_{j=1}^p |\beta_j| \right\}.
> $$
>
> #### Effect:
> - It shrinks coefficients toward $0$.
> - Some coefficients can become exactly $0$.
> - Thus, Lasso performs **variable selection** as well as shrinkage.
>
> #### Use:
> - Appropriate when only a subset of predictors is truly important.
> - Produces a simpler, more interpretable model.
>
> ---
>
> ## Geometric Interpretation
>
> - Ridge uses a circular or spherical constraint region because it penalizes $\sum \beta_j^2$.
> - Lasso uses a diamond-shaped constraint region because it penalizes $\sum |\beta_j|$.
>
> The corners of the Lasso constraint make it more likely that the solution occurs at an axis, causing some coefficients to be exactly zero.
>
> ---
>
> ## Main Practical Differences
>
> - **Method Ridge** — Penalty: $L_2$; Coefficients set exactly to $0$?: No; Variable selection?: No
> - **Method Lasso** — Penalty: $L_1$; Coefficients set exactly to $0$?: Yes; Variable selection?: Yes
>
> ---
>
> ## Summary
>
> - **Ridge**: uses an $L_2$ penalty, shrinks all coefficients, but usually keeps every variable.
> - **Lasso**: uses an $L_1$ penalty, shrinks coefficients and can eliminate some entirely.
>
> Thus, the essential difference is that **Lasso can produce sparse models, whereas Ridge generally cannot**.
