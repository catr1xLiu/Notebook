> [!example] Question 734 · Citadel
> ## Quantitative Researcher Interview

You have two strings, each of which takes exactly one hour to burn completely when lit at one end. The rate of burning is non-uniform and differs between the strings. Using only these two strings and a way to light them, how can you measure 45 minutes?

[Source](https://www.thewallstreetquants.com/ebook#p=735)

> [!success]- Solution (Click to expand)
> Light both ends of the first string and one end of the second string at the same time.
>
> - Since the first string is burning from both ends, it will be completely burned in $30$ minutes, regardless of how unevenly it burns.
> - At that moment, the second string has been burning from one end for $30$ minutes, so it has $30$ minutes of burn-time remaining if lit from one end.
> - Immediately light the other end of the second string. Now the remaining part burns from both ends, so it finishes in $15$ minutes.
>
> Thus the total elapsed time is
>
> $$
> 30 + 15 = 45 \text{ minutes}.
> $$
>
> So, the method measures exactly $\boxed{45 \text{ minutes}}$.
