> [!example] Question 716 · Citadel
> ## Quantitative Researcher Interview

Create a class that implements a singly linked list data structure.

[Source](https://www.thewallstreetquants.com/ebook#p=717)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A linked list is a linear data structure in which each element stores its value and a reference to the next element. To create a linked list class, one typically defines:
>
> 1. A `Node` class to represent each element.
> 2. A `LinkedList` class to manage the sequence of nodes.
>
> Since a linked list does not use indices like an array, common operations such as insertion and deletion are performed by updating references.
>
> ### Implementation
>
> ```python
> class Node:
>     def __init__(self, data):
>         self.data = data
>         self.next = None
>
>
> class LinkedList:
>     def __init__(self):
>         self.head = None
>
>     def append(self, data):
>         new_node = Node(data)
>
>         if self.head is None:
>             self.head = new_node
>             return
>
>         current = self.head
>         while current.next is not None:
>             current = current.next
>         current.next = new_node
>
>     def prepend(self, data):
>         new_node = Node(data)
>         new_node.next = self.head
>         self.head = new_node
>
>     def delete(self, data):
>         if self.head is None:
>             return
>
>         if self.head.data == data:
>             self.head = self.head.next
>             return
>
>         current = self.head
>         while current.next is not None and current.next.data != data:
>             current = current.next
>
>         if current.next is not None:
>             current.next = current.next.next
>
>     def search(self, data):
>         current = self.head
>         while current is not None:
>             if current.data == data:
>                 return True
>             current = current.next
>         return False
>
>     def display(self):
>         elements = []
>         current = self.head
>         while current is not None:
>             elements.append(str(current.data))
>             current = current.next
>         return " -> ".join(elements) if elements else "Empty"
> ```
>
> ### Example Usage
>
> ```python
> ll = LinkedList()
> ll.append(10)
> ll.append(20)
> ll.prepend(5)
>
> print(ll.display())   # 5 -> 10 -> 20
> print(ll.search(10))  # True
>
> ll.delete(10)
> print(ll.display())   # 5 -> 20
> ```
>
> ### Explanation of Methods
>
> - `append(data)`: Inserts a new node at the end of the list.
> - `prepend(data)`: Inserts a new node at the beginning of the list.
> - `delete(data)`: Removes the first node containing the given value.
> - `search(data)`: Returns `True` if the value is found, otherwise `False`.
> - `display()`: Returns a string representation of the list.
>
> ### Final Answer
>
> The linked list class is implemented above using a `Node` class and a `LinkedList` class, supporting insertion at both ends, deletion, search, and display.
