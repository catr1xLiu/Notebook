> ## Software Engineer Interview

Implement a function to compute the nth Fibonacci number using memoization.

[Source](https://www.thewallstreetquants.com/ebook#p=691)

> ## Fibonacci Number Using Memoization
>
> To compute the $n$th Fibonacci number efficiently, use **memoization**, which stores previously computed values so they are not recomputed.
>
> The Fibonacci sequence is defined by
>
> $$
> F(0) = 0,\qquad F(1) = 1
> $$
>
> and for $n \ge 2$,
>
> $$
> F(n) = F(n-1) + F(n-2).
> $$
>
> A direct recursive implementation recomputes the same subproblems many times, leading to exponential time. Memoization avoids this by saving each computed value.
>
> ### Memoized Algorithm
>
> Use a dictionary or array $memo$ such that $memo[n]$ stores $F(n)$ once it has been computed.
>
> #### Recursive Idea
>
> 1. If $n = 0$ or $n = 1$, return the base value.
> 2. If $F(n)$ is already in $memo$, return it.
> 3. Otherwise compute
>    $$
>    F(n) = F(n-1) + F(n-2),
>    $$
>    store it in $memo$, and return it.
>
> ### Python Implementation
>
> ```python
> def fibonacci(n, memo={}):
>     if n in memo:
>         return memo[n]
>     if n == 0:
>         return 0
>     if n == 1:
>         return 1
>
>     memo[n] = fibonacci(n - 1, memo) + fibonacci(n - 2, memo)
>     return memo[n]
> ```
>
> ### Example
>
> To compute $F(6)$:
>
> $$
> F(6) = F(5) + F(4)
> $$
>
> $$
> F(5) = F(4) + F(3), \qquad F(4) = F(3) + F(2)
> $$
>
> With memoization, once $F(4)$, $F(3)$, and $F(2)$ are computed, they are reused instead of recalculated.
>
> Thus,
>
> $$
> F(0)=0,\quad F(1)=1,\quad F(2)=1,\quad F(3)=2,\quad F(4)=3,\quad F(5)=5,\quad F(6)=8.
> $$
>
> So the result is
>
> $$
> F(6)=8.
> $$
>
> ### Time and Space Complexity
>
> - **Time complexity:** $O(n)$, since each Fibonacci value from $0$ to $n$ is computed at most once.
> - **Space complexity:** $O(n)$, due to the memo table and recursion stack.
>
> ### Final Answer
>
> Memoization computes the Fibonacci number efficiently by storing previously calculated results, reducing the running time from exponential to linear:
>
> $$
> \boxed{\text{Time} = O(n), \qquad \text{Space} = O(n)}
> $$
>
> and the recurrence used is
>
> $$
> F(n)=F(n-1)+F(n-2), \quad F(0)=0,\quad F(1)=1.
> $$
