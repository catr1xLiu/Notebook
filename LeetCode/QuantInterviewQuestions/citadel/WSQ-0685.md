> ## Hashtable with Collision Handling by Probing
>
> A hashtable stores key-value pairs in an array and uses a hash function to map each key to an index. When two keys map to the same index, a **collision** occurs. One standard way to resolve collisions is **probing**, also called **open addressing**.
>
> This implementation uses **linear probing**:
> - Compute the initial index by hashing the key.
> - If the slot is occupied by another key, check the next slot.
> - Continue until an empty slot or the target key is found.
>
> ---
>
> ## Approach
>
> We maintain an array of entries. Each slot can be in one of three states:
>
> - `EMPTY`: never used
> - `OCCUPIED`: currently stores a key-value pair
> - `DELETED`: previously occupied, now removed
>
> The `DELETED` marker is necessary so that probing chains are not broken after deletions.
>
> Operations:
>
> 1. **Insert**
>    - Hash the key to get a starting index.
>    - Probe until:
>      - the key is found, then update its value, or
>      - an empty/deleted slot is found, then insert there.
>
> 2. **Search**
>    - Hash the key and probe until:
>      - the key is found, or
>      - an `EMPTY` slot is reached, which means the key does not exist.
>
> 3. **Delete**
>    - Search for the key.
>    - If found, mark the slot as `DELETED`.
>
> To keep operations efficient, resize the table when the load factor becomes too large.
>
> ---
>
> ## Python Implementation
>
> ```python
> class _EmptySlot:
>     pass
>
>
> class _DeletedSlot:
>     pass
>
>
> EMPTY = _EmptySlot()
> DELETED = _DeletedSlot()
>
>
> class HashTable:
>     def __init__(self, capacity=8):
>         self.capacity = max(8, capacity)
>         self.size = 0
>         self.table = [EMPTY] * self.capacity
>
>     def _hash(self, key):
>         return hash(key) % self.capacity
>
>     def _probe(self, key):
>         index = self._hash(key)
>         first_deleted = None
>
>         for i in range(self.capacity):
>             j = (index + i) % self.capacity
>             slot = self.table[j]
>
>             if slot is EMPTY:
>                 return first_deleted if first_deleted is not None else j
>
>             if slot is DELETED:
>                 if first_deleted is None:
>                     first_deleted = j
>                 continue
>
>             k, _ = slot
>             if k == key:
>                 return j
>
>         raise RuntimeError("Hashtable is full")
>
>     def _find_index(self, key):
>         index = self._hash(key)
>
>         for i in range(self.capacity):
>             j = (index + i) % self.capacity
>             slot = self.table[j]
>
>             if slot is EMPTY:
>                 return None
>
>             if slot is DELETED:
>                 continue
>
>             k, _ = slot
>             if k == key:
>                 return j
>
>         return None
>
>     def _resize(self):
>         old_table = self.table
>         self.capacity *= 2
>         self.table = [EMPTY] * self.capacity
>         old_size = self.size
>         self.size = 0
>
>         for slot in old_table:
>             if slot is not EMPTY and slot is not DELETED:
>                 k, v = slot
>                 self.put(k, v)
>
>         self.size = old_size
>
>     def put(self, key, value):
>         if (self.size + 1) / self.capacity > 0.7:
>             self._resize()
>
>         index = self._probe(key)
>         slot = self.table[index]
>
>         if slot is EMPTY or slot is DELETED:
>             self.table[index] = (key, value)
>             self.size += 1
>         else:
>             self.table[index] = (key, value)
>
>     def get(self, key):
>         index = self._find_index(key)
>         if index is None:
>             raise KeyError(key)
>         return self.table[index][1]
>
>     def remove(self, key):
>         index = self._find_index(key)
>         if index is None:
>             raise KeyError(key)
>         self.table[index] = DELETED
>         self.size -= 1
>
>     def contains(self, key):
>         return self._find_index(key) is not None
>
>     def __len__(self):
>         return self.size
>
>     def __repr__(self):
>         items = []
>         for slot in self.table:
>             if slot is not EMPTY and slot is not DELETED:
>                 items.append(f"{slot[0]}: {slot[1]}")
>         return "{" + ", ".join(items) + "}"
> ```
>

> ## Example
>
> ```python
> ht = HashTable()
>
> ht.put("apple", 10)
> ht.put("banana", 20)
> ht.put("orange", 30)
>
> print(ht.get("banana"))     # 20
> print(ht.contains("apple")) # True
>
> ht.put("banana", 25)
> print(ht.get("banana"))     # 25
>
> ht.remove("apple")
> print(ht.contains("apple")) # False
>
> print(ht)
> ```
>

> ## How Probing Handles Collisions
>
> Suppose two keys hash to the same index $h$.
>
> - First key is stored at index $h$.
> - Second key also maps to $h$, but since that slot is occupied, linear probing tries:
>   $$
>   h, \; (h+1) \bmod m, \; (h+2) \bmod m, \dots
>   $$
>   where $m$ is the table size.
>
> Thus, the collision is resolved by finding the next available position.
>
> ---
>
> ## Time Complexity
>
> Under a reasonable load factor:
>
> - **Insert:** average $O(1)$
> - **Search:** average $O(1)$
> - **Delete:** average $O(1)$
>
> In the worst case, probing may scan many slots, giving:
>
> - **Worst case:** $O(n)$
>
> ---
>
> ## Final Answer
>
> A hashtable with collision handling using probing can be implemented with **open addressing** and **linear probing**, as shown above. It supports insertion, lookup, update, and deletion efficiently while resolving collisions by checking subsequent array positions until the appropriate slot is found.
