> [!example] Question 693 · Citadel
> ## Software Developer Interview

Given an 8x8 chessboard, write code to calculate the number of ways to go from the top left corner to the bottom right corner, where you can move down, up, left, or right at each step.

[Source](https://www.thewallstreetquants.com/ebook#p=694)

> [!success]- Solution (Click to expand)
> ## Solution
>
> If moves in all four directions are allowed, the answer depends on one crucial detail:
>
> - If revisiting squares is allowed, then the number of ways is **infinite**, because you can loop arbitrarily many times before reaching the destination.
> - Therefore, the meaningful version of the problem is to count **simple paths**: paths from the top-left corner to the bottom-right corner that do **not** visit any square more than once.
>
> This can be solved by depth-first search with backtracking.
>
> ### Idea
>
> Model the $8 \times 8$ chessboard as a grid. Starting at $(0,0)$, recursively try moving:
>
> - down: $(r+1,c)$
> - up: $(r-1,c)$
> - right: $(r,c+1)$
> - left: $(r,c-1)$
>
> A move is valid only if:
>
> 1. it stays inside the board, and
> 2. the square has not been visited already.
>
> When the search reaches $(7,7)$, one valid path has been found.
>
> ---
>
> ## Python code
>
> ```python
> def count_paths_8x8():
>     n = 8
>     target = (n - 1, n - 1)
>     visited = [[False] * n for _ in range(n)]
>
>     directions = [(1, 0), (-1, 0), (0, 1), (0, -1)]
>
>     def dfs(r, c):
>         if (r, c) == target:
>             return 1
>
>         visited[r][c] = True
>         total = 0
>
>         for dr, dc in directions:
>             nr, nc = r + dr, c + dc
>             if 0 <= nr < n and 0 <= nc < n and not visited[nr][nc]:
>                 total += dfs(nr, nc)
>
>         visited[r][c] = False
>         return total
>
>     return dfs(0, 0)
>
>
> print(count_paths_8x8())
> ```
>
> ---
>
> ## Explanation
>
> Let $f(r,c)$ denote the number of simple paths from square $(r,c)$ to $(7,7)$, given the current set of visited squares.
>
> The recursive procedure works as follows:
>
> 1. If $(r,c) = (7,7)$, return $1$.
> 2. Mark $(r,c)$ as visited.
> 3. For each of the four directions, move to an unvisited neighboring square inside the board.
> 4. Sum the number of paths returned by those recursive calls.
> 5. Unmark $(r,c)$ before returning, so that other recursive branches can use it.
>
> This is a standard **backtracking** algorithm.
>
> ---
>
> ## Important note on complexity
>
> The number of simple paths on an $8 \times 8$ grid is enormous, so this brute-force search can take a very long time. The algorithm is correct, but not efficient for large boards.
>
> If the problem allows revisiting squares, then no finite count exists:
>
> $$
> \text{Number of paths} = \infty
> $$
>
> because one may move back and forth repeatedly before eventually going to the destination.
>
> ---
>
> ## Final answer
>
> A correct way to compute the number of paths is to use DFS with backtracking as shown above. If revisits are allowed, the number of ways is infinite; if revisits are forbidden, the provided code counts all valid simple paths from the top-left corner to the bottom-right corner.
