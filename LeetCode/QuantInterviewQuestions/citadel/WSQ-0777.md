> [!example] Question 777 · Citadel
> ## Software Engineer Interview

Given a matrix and the coordinates of the top-left and bottom-right corners, calculate the sum of the elements within the specified submatrix in (1) linear time and (2) constant time. You are allowed to preprocess the matrix.

[Source](https://www.thewallstreetquants.com/ebook#p=778)

> [!success]- Solution (Click to expand)
> ## Approach
>
> To answer many submatrix-sum queries efficiently, preprocess the matrix into a **2D prefix-sum array**. Then:
>
> 1. A query can be answered in **linear time** in one dimension by summing row prefixes.
> 2. A query can be answered in **constant time** using full 2D inclusion-exclusion.
>
> Let the matrix be $A$ with $m$ rows and $n$ columns, indexed from $0$.
>
> Suppose the query asks for the sum of the submatrix with:
>
> - top-left corner $(r_1, c_1)$
> - bottom-right corner $(r_2, c_2)$
>
> where $0 \le r_1 \le r_2 < m$ and $0 \le c_1 \le c_2 < n$.
>
> ---
>
> ## 1. Linear-time query
>
> ### Preprocessing
>
> Compute **row-wise prefix sums**:
>
> $$
> R[i][j] = \sum_{k=0}^{j} A[i][k]
> $$
>
> for each row $i$ and column $j$.
>
> This preprocessing takes:
>
> $$
> O(mn)
> $$
>
> time and $O(mn)$ space.
>
> ### Query formula
>
> For each row $i$ from $r_1$ to $r_2$, the sum of columns $c_1$ through $c_2$ is:
>
> $$
> \text{rowSum}(i) =
> \begin{cases}
> R[i][c_2], & c_1 = 0 \\
> R[i][c_2] - R[i][c_1 - 1], & c_1 > 0
> \end{cases}
> $$
>
> Therefore the submatrix sum is:
>
> $$
> \sum_{i=r_1}^{r_2} \text{rowSum}(i)
> $$
>
> This takes:
>
> $$
> O(r_2 - r_1 + 1)
> $$
>
> time, which is linear in the number of rows of the query rectangle.
>
> ### Pseudocode
>
> ```text
> preprocessRowPrefix(A):
>     let R be an m x n array
>     for i = 0 to m - 1:
>         R[i][0] = A[i][0]
>         for j = 1 to n - 1:
>             R[i][j] = R[i][j - 1] + A[i][j]
>     return R
>
> queryLinear(R, r1, c1, r2, c2):
>     sum = 0
>     for i = r1 to r2:
>         if c1 == 0:
>             sum += R[i][c2]
>         else:
>             sum += R[i][c2] - R[i][c1 - 1]
>     return sum
> ```
>
> ---
>
> ## 2. Constant-time query
>
> ### Preprocessing
>
> Compute the **2D prefix-sum array** $P$, where:
>
> $$
> P[i][j] = \sum_{x=0}^{i} \sum_{y=0}^{j} A[x][y]
> $$
>
> This can be built using:
>
> $$
> P[i][j] = A[i][j] + \begin{cases} P[i-1][j], & i > 0 \\ 0, & i = 0 \end{cases} + \begin{cases} P[i][j-1], & j > 0 \\ 0, & j = 0 \end{cases} - \begin{cases} P[i-1][j-1], & i > 0 \text{ and } j > 0 \\ 0, & \text{otherwise} \end{cases}
> $$
>
> This preprocessing also takes:
>
> $$
> O(mn)
> $$
>
> time and $O(mn)$ space.
>
> ### Query formula
>
> Let $S(r_1,c_1,r_2,c_2)$ denote the required submatrix sum. Using inclusion-exclusion:
>
> $$
> S = P[r_2][c_2] - \begin{cases} P[r_1-1][c_2], & r_1 > 0 \\ 0, & r_1 = 0 \end{cases} - \begin{cases} P[r_2][c_1-1], & c_1 > 0 \\ 0, & c_1 = 0 \end{cases} + \begin{cases} P[r_1-1][c_1-1], & r_1 > 0 \text{ and } c_1 > 0 \\ 0, & \text{otherwise} \end{cases}
> $$
>
> This query uses only a constant number of array accesses, so it runs in:
>
> $$
> O(1)
> $$
>
> time.
>
> ### Pseudocode
>
> ```text
> preprocess2DPrefix(A):
>     let P be an m x n array
>     for i = 0 to m - 1:
>         for j = 0 to n - 1:
>             P[i][j] = A[i][j]
>             if i > 0:
>                 P[i][j] += P[i - 1][j]
>             if j > 0:
>                 P[i][j] += P[i][j - 1]
>             if i > 0 and j > 0:
>                 P[i][j] -= P[i - 1][j - 1]
>     return P
>
> queryConstant(P, r1, c1, r2, c2):
>     sum = P[r2][c2]
>     if r1 > 0:
>         sum -= P[r1 - 1][c2]
>     if c1 > 0:
>         sum -= P[r2][c1 - 1]
>     if r1 > 0 and c1 > 0:
>         sum += P[r1 - 1][c1 - 1]
>     return sum
> ```
>
> ---
>
> ## Final Answer
>
> - **Linear-time query:** preprocess **row prefix sums** in $O(mn)$ time, then answer each query in  
>   $$
>   O(r_2 - r_1 + 1)
>   $$
>   by summing row intervals.
>
> - **Constant-time query:** preprocess a **2D prefix-sum array** in $O(mn)$ time, then answer each query in  
>   $$
>   O(1)
>   $$
>   using inclusion-exclusion:
>
> $$
> S = P[r_2][c_2] - P[r_1-1][c_2] - P[r_2][c_1-1] + P[r_1-1][c_1-1]
> $$
>
> with any out-of-bounds term treated as $0$.
