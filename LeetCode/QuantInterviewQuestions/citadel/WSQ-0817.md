> ## 1. Find points inside a triangle
>
> ### Approach
>
> Given a triangle with vertices $A(x_1,y_1)$, $B(x_2,y_2)$, and $C(x_3,y_3)$, and a point $P(x,y)$, determine whether $P$ lies inside the triangle.
>
> A standard method is to compare areas:
>
> - Compute the area of triangle $ABC$.
> - Compute the areas of triangles $PAB$, $PBC$, and $PCA$.
> - If
>   $$
>   [ABC] = [PAB] + [PBC] + [PCA],
>   $$
>   then $P$ lies inside or on the boundary of the triangle.
>
> ### Formula for area
>
> The area of a triangle with vertices $(x_a,y_a)$, $(x_b,y_b)$, and $(x_c,y_c)$ is
>
> $$
> \text{Area}=\frac{1}{2}\left|x_a(y_b-y_c)+x_b(y_c-y_a)+x_c(y_a-y_b)\right|.
> $$
>
> ### Step-by-step algorithm
>
> For each point $P(x,y)$:
>
> 1. Compute
>    $$
>    A = [ABC].
>    $$
> 2. Compute
>    $$
>    A_1 = [PBC], \quad A_2 = [APC], \quad A_3 = [ABP].
>    $$
> 3. Check whether
>    $$
>    A = A_1 + A_2 + A_3.
>    $$
>    - If true, the point is inside or on the triangle.
>    - Otherwise, it is outside.
>
> ### Example implementation idea
>
> ```python
> def area(x1, y1, x2, y2, x3, y3):
>     return abs(x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2)) / 2
>
> def is_inside_triangle(A, B, C, P):
>     x1, y1 = A
>     x2, y2 = B
>     x3, y3 = C
>     x, y = P
>
>     A_total = area(x1, y1, x2, y2, x3, y3)
>     A1 = area(x, y, x2, y2, x3, y3)
>     A2 = area(x1, y1, x, y, x3, y3)
>     A3 = area(x1, y1, x2, y2, x, y)
>
>     return A_total == A1 + A2 + A3
> ```
>
> ### Conclusion
>
> A point is inside a triangle iff the sum of the areas of the three subtriangles formed with that point equals the area of the original triangle.

> ## 2. Find the number of pairs in a list whose sum is $60$
>
> ### Approach
>
> Given a list of times (integers), count the number of unordered pairs $(i,j)$ with $i<j$ such that
>
> $$
> t_i + t_j = 60.
> $$
>
> A direct $O(n^2)$ check is possible, but a more efficient method uses a frequency table.
>
> ### Frequency-based method
>
> For each number $t$ in the list:
>
> - Its complement is
>   $$
>   60 - t.
>   $$
> - If the complement has already appeared, then each occurrence of the complement forms a valid pair with $t$.
>
> ### Step-by-step algorithm
>
> Initialize:
>
> - a dictionary `count` to store frequencies of previously seen values,
> - a variable `pairs = 0`.
>
> For each time $t$ in the list:
>
> 1. Compute
>    $$
>    c = 60 - t.
>    $$
> 2. Add the number of previously seen complements:
>    $$
>    \text{pairs} \mathrel{+}= \text{count}[c].
>    $$
> 3. Record the current value:
>    $$
>    \text{count}[t] \mathrel{+}= 1.
>    $$
>
> ### Example
>
> For the list
>
> $$
> [10, 20, 50, 40, 30, 30]
> $$
>
> valid pairs are:
>
> - $(10,50)$
> - $(20,40)$
> - $(30,30)$
>
> So the answer is $3$.
>
> ### Example implementation
>
> ```python
> from collections import defaultdict
>
> def count_pairs_sum_60(times):
>     count = defaultdict(int)
>     pairs = 0
>
>     for t in times:
>         pairs += count[60 - t]
>         count[t] += 1
>
>     return pairs
> ```
>
> ### Complexity
>
> - Time: $O(n)$
> - Space: $O(n)$ in the worst case
>
> ### Conclusion
>
> To count pairs summing to $60$, scan the list once, and for each value add the number of previously seen values equal to its complement $60-t$. This gives an $O(n)$ solution.
