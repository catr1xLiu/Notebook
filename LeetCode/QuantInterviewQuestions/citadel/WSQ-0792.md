> [!example] Question 792 · Citadel
> ## Quant Research Intern Interview

If you have a dataset with many features, what methods can you use to reduce its dimensionality?

[Source](https://www.thewallstreetquants.com/ebook#p=793)

> [!success]- Solution (Click to expand)
> Dimension reduction methods fall into two broad categories: **feature selection** and **feature extraction**.
>
> ## 1. Feature Selection
> These methods keep a subset of the original features.
>
> ### Filter methods
> They rank features using statistical criteria independent of a predictive model, such as:
> - variance thresholding,
> - correlation filtering,
> - mutual information,
> - chi-square tests,
> - ANOVA $F$-tests.
>
> ### Wrapper methods
> They evaluate subsets of features using a learning algorithm, such as:
> - forward selection,
> - backward elimination,
> - recursive feature elimination.
>
> ### Embedded methods
> They perform feature selection during model training, such as:
> - Lasso regression using an $L_1$ penalty,
> - tree-based models using feature importance,
> - elastic net regularization.
>
> ## 2. Feature Extraction
> These methods transform the original features into a smaller set of new variables.
>
> ### Linear methods
> - **Principal Component Analysis (PCA):** projects data onto directions of maximum variance.
> - **Linear Discriminant Analysis (LDA):** finds projections that best separate classes.
> - **Factor Analysis:** explains observed variables through a smaller number of latent factors.
> - **Singular Value Decomposition (SVD):** often used for matrix-based dimensionality reduction.
>
> ### Nonlinear methods
> - **Kernel PCA:** nonlinear extension of PCA.
> - **t-SNE:** useful mainly for visualization in low dimensions.
> - **UMAP:** preserves local and some global structure, often for visualization.
> - **Isomap**, **Locally Linear Embedding (LLE):** manifold learning methods.
> - **Autoencoders:** neural networks that learn compact representations.
>
> ## 3. Practical preprocessing steps
> Before applying dimension reduction, one may also:
> - remove redundant features,
> - combine highly correlated variables,
> - use domain knowledge to eliminate irrelevant variables,
> - standardize features, especially before methods like PCA.
>
> ## Conclusion
> Common ways to reduce dimension include:
> - **selecting fewer original features** via filter, wrapper, or embedded methods, and
> - **creating fewer derived features** via methods such as PCA, LDA, SVD, manifold learning, or autoencoders.
>
> The best choice depends on whether interpretability, predictive performance, or visualization is the main goal.
