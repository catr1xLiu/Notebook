What are virtual functions in C++? How are they used?

[Source](https://www.thewallstreetquants.com/ebook#p=723)

> [!success]- Solution (Click to expand)
> ## Virtual functions in C++
>
> A **virtual function** is a member function in a base class that is declared with the keyword `virtual` so that, when it is overridden in a derived class, the function call is resolved **at runtime** based on the actual object type rather than the pointer or reference type.
>
> This is the mechanism that enables **runtime polymorphism** in C++.
>
> ---
>
> ## Why virtual functions are needed
>
> Suppose a base-class pointer points to a derived-class object. Without virtual functions, calling a member function through the base pointer uses the base-class version. With virtual functions, C++ calls the derived-class version if it exists.
>
> ### Without virtual function
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> class Base {
> public:
>     void show() {
>         cout << "Base class show()" << endl;
>     }
> };
>
> class Derived : public Base {
> public:
>     void show() {
>         cout << "Derived class show()" << endl;
>     }
> };
>
> int main() {
>     Base* ptr;
>     Derived d;
>     ptr = &d;
>
>     ptr->show();   // Calls Base::show()
> }
> ```
>
> Output:
>
> ```cpp
> Base class show()
> ```
>
> Since `show()` is not virtual, the call is decided at compile time.
>
> ---
>
> ## Using a virtual function
>
> Declare the function as `virtual` in the base class.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> class Base {
> public:
>     virtual void show() {
>         cout << "Base class show()" << endl;
>     }
> };
>
> class Derived : public Base {
> public:
>     void show() override {
>         cout << "Derived class show()" << endl;
>     }
> };
>
> int main() {
>     Base* ptr;
>     Derived d;
>     ptr = &d;
>
>     ptr->show();   // Calls Derived::show()
> }
> ```
>
> Output:
>
> ```cpp
> Derived class show()
> ```
>
> Here, the function call is resolved at runtime, so the derived version is invoked.
>
> ---
>
> ## How it works
>
> When a class contains virtual functions, the compiler typically creates a **virtual table** (often called a **vtable**). Each object of that class generally contains a hidden pointer to this table. At runtime, the program uses this table to determine which function implementation to call.
>
> Conceptually:
>
> - Base class declares a virtual function.
> - Derived class overrides it.
> - A base-class pointer or reference refers to a derived object.
> - Calling the function uses the derived implementation.
>
> ---
>
> ## Syntax
>
> ```cpp
> class Base {
> public:
>     virtual void func();
> };
> ```
>
> A derived class can override it as follows:
>
> ```cpp
> class Derived : public Base {
> public:
>     void func() override;
> };
> ```
>
> The `override` keyword is optional but strongly recommended because it lets the compiler check that the function is actually overriding a virtual function from the base class.
>
> ---
>
> ## Virtual functions with references
>
> Virtual behavior works with both pointers and references.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> class Animal {
> public:
>     virtual void sound() {
>         cout << "Animal makes a sound" << endl;
>     }
> };
>
> class Dog : public Animal {
> public:
>     void sound() override {
>         cout << "Dog barks" << endl;
>     }
> };
>
> int main() {
>     Dog d;
>     Animal& ref = d;
>     ref.sound();   // Calls Dog::sound()
> }
> ```
>
> ---
>
> ## Pure virtual functions and abstract classes
>
> A virtual function can be made **pure virtual** by assigning it `= 0`.
>
> ```cpp
> class Shape {
> public:
>     virtual void draw() = 0;
> };
> ```
>
> Such a class is called an **abstract class**, and objects of it cannot be created.
>
> A derived class must provide an implementation:
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> class Shape {
> public:
>     virtual void draw() = 0;
> };
>
> class Circle : public Shape {
> public:
>     void draw() override {
>         cout << "Drawing Circle" << endl;
>     }
> };
>
> int main() {
>     Circle c;
>     c.draw();
> }
> ```
>
> ---
>
> ## Virtual destructor
>
> If a class is intended to be used polymorphically, its destructor should usually be virtual. Otherwise, deleting a derived object through a base pointer can cause incomplete destruction.
>
> ```cpp
> #include <iostream>
> using namespace std;
>
> class Base {
> public:
>     virtual ~Base() {
>         cout << "Base destructor" << endl;
>     }
> };
>
> class Derived : public Base {
> public:
>     ~Derived() {
>         cout << "Derived destructor" << endl;
>     }
> };
>
> int main() {
>     Base* ptr = new Derived();
>     delete ptr;
> }
> ```
>
> Output:
>
> ```cpp
> Derived destructor
> Base destructor
> ```
>
> Without a virtual destructor, only the base destructor might run, which is incorrect.
>
> ---
>
> ## Important points
>
> 1. A virtual function must be a member of a class.
> 2. It should usually be called through a base-class pointer or reference.
> 3. Constructors cannot be virtual.
> 4. Destructors can and often should be virtual.
> 5. Virtual dispatch happens at runtime.
> 6. The `override` keyword helps avoid mistakes.
> 7. If a function in the base class is pure virtual, the class becomes abstract.
>
> ---
>
> ## Summary
>
> A virtual function in C++ is used to achieve **runtime polymorphism**. It allows a program to call the correct overridden function in a derived class through a base-class pointer or reference.
>
> ### Basic pattern
>
> ```cpp
> class Base {
> public:
>     virtual void func() {
>     }
> };
>
> class Derived : public Base {
> public:
>     void func() override {
>     }
> };
> ```
>
> Then:
>
> ```cpp
> Base* p = new Derived();
> p->func();   // Calls Derived::func()
> ```
>
> Thus, virtual functions allow C++ programs to behave according to the actual object type at runtime.
