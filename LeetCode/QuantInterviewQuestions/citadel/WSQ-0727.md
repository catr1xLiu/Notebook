> [!example] Question 727 · Citadel
> ## Quantitative Researcher Interview

Write a program to output all the prime numbers smaller than a given integer N.

[Source](https://www.thewallstreetquants.com/ebook#p=728)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To output all prime numbers smaller than a given integer $N$, test each integer from $2$ to $N-1$ for primality.
>
> A number $x \ge 2$ is prime if it has no divisor other than $1$ and itself.  
> To check whether $x$ is prime efficiently, it is enough to test divisors from $2$ up to $\sqrt{x}$, because if $x$ has a divisor larger than $\sqrt{x}$, then it must also have a corresponding divisor smaller than $\sqrt{x}$.
>
> ### Algorithm
> 1. Read the integer $N$.
> 2. For each integer $i$ from $2$ to $N-1$:
>    - Assume $i$ is prime.
>    - Check whether any integer $j$ from $2$ to $\lfloor \sqrt{i} \rfloor$ divides $i$.
>    - If such a divisor exists, then $i$ is not prime.
>    - Otherwise, output $i$.
>
> ### Program in C
> ```c
> #include <stdio.h>
>
> int main() {
>     int N;
>     scanf("%d", &N);
>
>     for (int i = 2; i < N; i++) {
>         int isPrime = 1;
>         for (int j = 2; j * j <= i; j++) {
>             if (i % j == 0) {
>                 isPrime = 0;
>                 break;
>             }
>         }
>         if (isPrime) {
>             printf("%d ", i);
>         }
>     }
>
>     return 0;
> }
> ```
>
> ### Example
> If the input is
> ```c
> 20
> ```
>
> the output is
> ```c
> 2 3 5 7 11 13 17 19
> ```
>
> ### Final Answer
> The above program prints all prime numbers smaller than $N$.
