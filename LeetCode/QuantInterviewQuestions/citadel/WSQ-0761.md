> [!example] Question 761 · Citadel
> ## Software Engineering Intern Interview

Return a minimum-length list of perfect squares whose sum equals a given value k.

[Source](https://www.thewallstreetquants.com/ebook#p=762)

> [!success]- Solution (Click to expand)
> ## Solution
>
> This is the classic **minimum number of perfect squares** problem: given an integer $k$, find a list of perfect squares whose sum is $k$, with the list having minimum possible length.
>
> ### Approach
>
> Use dynamic programming.
>
> Let $dp[i]$ denote the minimum number of squares needed to sum to $i$.  
> To reconstruct the actual list, store which square was chosen last for each $i$.
>
> For each value $i$ from $1$ to $k$, try every perfect square $j^2 \le i$:
>
> $$
> dp[i] = \min_{1 \le j^2 \le i} \left( dp[i - j^2] + 1 \right).
> $$
>
> Also store the corresponding $j^2$ so the solution can be rebuilt.
>
> ### Algorithm
>
> 1. Initialize:
>    - $dp[0] = 0$
>    - $dp[i] = \infty$ for $i > 0$
> 2. For each $i$ from $1$ to $k$:
>    - For each square $s = j^2 \le i$:
>      - If $dp[i-s] + 1 < dp[i]$, update $dp[i]$
>      - Record $s$ as the last square used for $i$
> 3. Reconstruct the answer by repeatedly subtracting the recorded square from the current value.
>
> ### Python implementation
>
> ```python
> def min_square_list(k: int):
>     dp = [0] + [float('inf')] * k
>     prev = [0] * (k + 1)
>
>     for i in range(1, k + 1):
>         j = 1
>         while j * j <= i:
>             s = j * j
>             if dp[i - s] + 1 < dp[i]:
>                 dp[i] = dp[i - s] + 1
>                 prev[i] = s
>             j += 1
>
>     result = []
>     while k > 0:
>         result.append(prev[k])
>         k -= prev[k]
>
>     return result
> ```
>
> ### Example
>
> If $k = 12$, the algorithm returns
>
> $$
> [4, 4, 4]
> $$
>
> since
>
> $$
> 4 + 4 + 4 = 12
> $$
>
> and no list of fewer than $3$ squares sums to $12$.
>
> If $k = 13$, it returns
>
> $$
> [9, 4]
> $$
>
> since
>
> $$
> 9 + 4 = 13.
> $$
>
> ### Complexity
>
> For each $i \le k$, we try all squares up to $\sqrt{i}$, so the time complexity is
>
> $$
> O(k\sqrt{k})
> $$
>
> and the space complexity is
>
> $$
> O(k).
> $$
>
> ### Final Answer
>
> A minimum-length list of squares summing to $k$ can be found with dynamic programming by computing
>
> $$
> dp[i] = \min_{j^2 \le i} \left(dp[i-j^2] + 1\right),
> $$
>
> and then reconstructing the chosen squares. The implementation above returns such a list.
