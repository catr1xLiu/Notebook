> [!example] Question 680 · Citadel
> ## Software Engineer Interview

Given a CSV file as input, write a program to convert it to columnar data format.

[Source](https://www.thewallstreetquants.com/ebook#p=681)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To convert a CSV file into **columnar data**, read the file row by row and reorganize the values so that each column name maps to the list of values in that column.
>
> ### Approach
>
> A CSV file is typically stored in **row-oriented** form:
>
> $$
> \text{row}_1 = [v_{11}, v_{12}, \dots, v_{1m}]
> $$
>
> $$
> \text{row}_2 = [v_{21}, v_{22}, \dots, v_{2m}]
> $$
>
> To convert this into **columnar** form, construct:
>
> $$
> \text{column}_j = [v_{1j}, v_{2j}, \dots, v_{nj}]
> $$
>
> for each column $j$.
>
> ---
>
> ## Example
>
> Suppose the CSV file contains:
>
> ```csv
> name,age,city
> Alice,30,Paris
> Bob,25,London
> Charlie,35,Berlin
> ```
>
> The corresponding columnar representation is:
>
> ```json
> {
>   "name": ["Alice", "Bob", "Charlie"],
>   "age": ["30", "25", "35"],
>   "city": ["Paris", "London", "Berlin"]
> }
> ```
>
> ---
>
> ## Python Implementation
>
> ```python
> import csv
>
> def csv_to_columnar(file_path):
>     columnar_data = {}
>
>     with open(file_path, newline='', encoding='utf-8') as csvfile:
>         reader = csv.DictReader(csvfile)
>
>         # Initialize lists for each column
>         for field in reader.fieldnames:
>             columnar_data[field] = []
>
>         # Populate column-wise data
>         for row in reader:
>             for field in reader.fieldnames:
>                 columnar_data[field].append(row[field])
>
>     return columnar_data
> ```
>
> ---
>
> ## How it works
>
> ### 1. Read the header
> The header provides the column names:
>
> $$
> [\text{name}, \text{age}, \text{city}]
> $$
>
> These become the keys in the output dictionary.
>
> ### 2. Initialize storage
> For each column, create an empty list:
>
> ```python
> {
>     "name": [],
>     "age": [],
>     "city": []
> }
> ```
>
> ### 3. Process each row
> For each row, append each value to its corresponding column list.
>
> For example, after reading:
>
> ```csv
> Alice,30,Paris
> ```
>
> the structure becomes:
>
> ```python
> {
>     "name": ["Alice"],
>     "age": ["30"],
>     "city": ["Paris"]
> }
> ```
>
> Continuing this for all rows yields the full columnar result.
>
> ---
>
> ## Usage
>
> ```python
> result = csv_to_columnar("input.csv")
> print(result)
> ```
>
> ---
>
> ## Final Answer
>
> A CSV file can be converted to columnar data by reading the header as column names and then collecting each field’s values into a list keyed by its column name. A correct implementation is:
>
> ```python
> import csv
>
> def csv_to_columnar(file_path):
>     columnar_data = {}
>
>     with open(file_path, newline='', encoding='utf-8') as csvfile:
>         reader = csv.DictReader(csvfile)
>
>         for field in reader.fieldnames:
>             columnar_data[field] = []
>
>         for row in reader:
>             for field in reader.fieldnames:
>                 columnar_data[field].append(row[field])
>
>     return columnar_data
> ```
>
> This produces a dictionary-like columnar structure in which each column stores all of its values together.
