> [!example] Question 681 · Citadel
> ## Software Developer Interview

Given a sentence containing three types of brackets (e.g., (), \{\}, \[\]), determine if the brackets are properly balanced and in the correct order.

[Source](https://www.thewallstreetquants.com/ebook#p=682)

> [!success]- Solution (Click to expand)
> ## Solution
>
> To determine whether a sentence has the correct order of brackets when using the three types
>
> $$
> (), \quad [], \quad \{\},
> $$
>
> the standard method is to use a **stack**.
>
> ### Idea
>
> Scan the sentence from left to right:
>
> - If the current character is an opening bracket, push it onto the stack.
> - If the current character is a closing bracket:
>   - If the stack is empty, the order is incorrect.
>   - Otherwise, check whether the top of the stack is the matching opening bracket.
>     - If it matches, pop it.
>     - If it does not match, the order is incorrect.
> - Ignore all non-bracket characters.
>
> At the end:
>
> - If the stack is empty, the brackets are in the correct order.
> - Otherwise, some opening brackets were never closed, so the order is incorrect.
>
> ---
>
> ## Algorithm
>
> Let the stack initially be empty.
>
> For each character $c$ in the sentence:
>
> 1. If $c \in \{(, [, \{\}$, push $c$ onto the stack.
> 2. If $c \in \{), ], \}\}$:
>    - If the stack is empty, return **incorrect**.
>    - Let $t$ be the top element of the stack.
>    - Check:
>      - if $c = )$, then $t$ must be $( $
>      - if $c = ]$, then $t$ must be $[ $
>      - if $c = \}$, then $t$ must be $\{ $
>    - If the match fails, return **incorrect**.
>    - Otherwise pop the stack.
>
> After processing the entire sentence:
>
> - If the stack is empty, return **correct**.
> - Otherwise return **incorrect**.
>
> ---
>
> ## Example
>
> Consider the sentence
>
> $$
> \texttt{"a(b[c]\{d\})"}
> $$
>
> Processing brackets only:
>
> $$
> ( \rightarrow [ \rightarrow ] \rightarrow \{ \rightarrow \} \rightarrow )
> $$
>
> Stack behavior:
>
> - Read $( $: push
> - Read $[ $: push
> - Read $]$: matches $[ $, pop
> - Read $\{$: push
> - Read $\}$: matches $\{$, pop
> - Read $)$: matches $( $, pop
>
> The stack is empty at the end, so the order is **correct**.
>
> Now consider
>
> $$
> \texttt{"([)]"}
> $$
>
> - Read $( $: push
> - Read $[ $: push
> - Read $)$: expected top $( $, but top is $[ $
>
> So the order is **incorrect**.
>
> ---
>
> ## Correctness
>
> This works because a stack enforces the **last-opened, first-closed** rule required for properly nested brackets. Every closing bracket must match the most recent unmatched opening bracket.
>
> ---
>
> ## Complexity
>
> If the sentence has length $n$:
>
> - Time complexity: $O(n)$
> - Space complexity: $O(n)$ in the worst case
>
> ---
>
> ## Final Answer
>
> A sentence has the right order of brackets if, when scanned left to right, every closing bracket matches the most recent unmatched opening bracket of the same type, and no opening brackets remain unmatched at the end. This can be checked in $O(n)$ time using a stack.
