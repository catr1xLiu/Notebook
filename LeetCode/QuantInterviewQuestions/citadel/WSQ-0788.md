How do you reverse a string using Python?

[Source](https://www.thewallstreetquants.com/ebook#p=789)

> [!success]- Solution (Click to expand)
> To reverse a string in Python, the simplest method is to use slicing:
>
> ```python
> s = "hello"
> reversed_s = s[::-1]
> print(reversed_s)
> ```
>
> Output:
>
> ```python
> olleh
> ```
>
> ### Explanation
> The slice syntax
>
> $$
> s[::-1]
> $$
>
> means:
> - start from the end,
> - go to the beginning,
> - step by $-1$.
>
> ### Alternative method
> You can also use `reversed()` together with `join()`:
>
> ```python
> s = "hello"
> reversed_s = ''.join(reversed(s))
> print(reversed_s)
> ```
>
> This produces the same result:
>
> ```python
> olleh
> ```
>
> ### Final answer
> Use:
>
> ```python
> s[::-1]
> ```
>
> to reverse a string in Python.
