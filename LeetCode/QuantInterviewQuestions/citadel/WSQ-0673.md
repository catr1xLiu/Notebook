> [!example] Question 673 · Citadel
> ## Software Engineer Interview

Given an array representing a sequence of user events (where each element is a user ID), find the length of the longest contiguous subarray where the most frequent user's frequency within the subarray equals the minimum frequency of any user in the entire event log. Implement an efficient function to return this maximum length.

[Source](https://www.thewallstreetquants.com/ebook#p=674)

> [!success]- Solution (Click to expand)
> ### Solution
>
> Let the event log be an array $a[0], a[1], \dots, a[n-1]$, where each value represents a user ID.
>
> We seek the longest contiguous subarray such that:
>
> - the **maximum frequency** of any user inside that subarray
> - is equal to the **minimum frequency** of any user in the entire array.
>
> ---
>
> ### Step 1: Compute the global minimum frequency
>
> Let $f(x)$ be the total number of occurrences of user $x$ in the whole array.
>
> Compute the frequency of every user, then define
>
> $$
> m = \min_x f(x).
> $$
>
> This value $m$ is fixed for the whole problem.
>
> ---
>
> ### Step 2: Reformulate the condition for a valid subarray
>
> For a subarray to satisfy the condition, the most frequent user inside it must appear exactly $m$ times.
>
> That means:
>
> - no user may appear more than $m$ times in the subarray,
> - and at least one user must appear exactly $m$ times.
>
> So the problem becomes:
>
> Find the longest subarray in which every user appears at most $m$ times, and some user appears exactly $m$ times.
>
> ---
>
> ### Step 3: Use a sliding window
>
> This condition is well suited to the two-pointer (sliding window) technique.
>
> Maintain a window $[L, R]$ and a frequency map for users inside the window.
>
> Also maintain:
>
> - the current frequency of each user in the window,
> - the current maximum frequency in the window.
>
> Expand $R$ step by step.  
> If some user's frequency becomes greater than $m$, move $L$ right until all frequencies are again at most $m$.
>
> Whenever the maximum frequency in the window is exactly $m$, the window is valid, and we update the answer.
>
> ---
>
> ### Step 4: Why this works
>
> The sliding window always maintains the invariant:
>
> $$
> \text{for all users } x,\quad \text{freq}_{[L,R]}(x) \le m.
> $$
>
> Thus the window is always the longest possible ending at $R$ that does not violate the frequency bound.
>
> If additionally
>
> $$
> \max_x \text{freq}_{[L,R]}(x) = m,
> $$
>
> then the subarray satisfies the required condition. Since every index enters and leaves the window at most once, the algorithm is efficient.
>
> ---
>
> ### Step 5: Algorithm
>
> 1. Count global frequencies of all users.
> 2. Compute
>
>    $$
>    m = \min_x f(x).
>    $$
>
> 3. Initialize:
>    - $L = 0$,
>    - empty window frequency map,
>    - answer $= 0$.
> 4. For each $R$ from $0$ to $n-1$:
>    - add $a[R]$ to the window,
>    - while some frequency exceeds $m$, move $L$ right and decrease counts,
>    - if the maximum frequency in the window is $m$, update the answer.
>
> ---
>
> ### Step 6: Complexity
>
> - Computing global frequencies: $O(n)$
> - Sliding window traversal: $O(n)$
> - Hash-map operations: $O(1)$ on average
>
> Hence total time complexity is
>
> $$
> O(n),
> $$
>
> and the space complexity is
>
> $$
> O(k),
> $$
>
> where $k$ is the number of distinct users.
>
> ---
>
> ### Reference implementation
>
> ```python
> from collections import Counter, defaultdict
>
> def longest_consistent_logs(events):
>     total = Counter(events)
>     m = min(total.values())
>
>     window = defaultdict(int)
>     left = 0
>     ans = 0
>
>     # number of users having each frequency inside the current window
>     freq_count = defaultdict(int)
>     current_max = 0
>
>     for right, user in enumerate(events):
>         old = window[user]
>         if old > 0:
>             freq_count[old] -= 1
>
>         window[user] += 1
>         new = window[user]
>         freq_count[new] += 1
>         current_max = max(current_max, new)
>
>         while current_max > m:
>             u = events[left]
>             old = window[u]
>             freq_count[old] -= 1
>
>             window[u] -= 1
>             if window[u] > 0:
>                 freq_count[window[u]] += 1
>
>             left += 1
>
>             while current_max > 0 and freq_count[current_max] == 0:
>                 current_max -= 1
>
>         if current_max == m:
>             ans = max(ans, right - left + 1)
>
>     return ans
> ```
>
> ---
>
> ### Final answer
>
> The longest valid contiguous subarray can be found by:
>
> 1. computing the minimum global user frequency $m$,
> 2. using a sliding window to maintain the longest subarray where no user appears more than $m$ times,
> 3. recording windows whose maximum frequency is exactly $m$.
>
> This yields an $O(n)$ time solution with $O(k)$ extra space.
