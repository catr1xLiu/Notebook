> [!example] Question 1081 · IMC
> ## Software Developer Interview

What is a hashmap?

[Source](https://www.thewallstreetquants.com/ebook#p=1082)

> [!success]- Solution (Click to expand)
> A **hash map** is a data structure that stores **key–value pairs** and allows fast lookup, insertion, and deletion by using a **hash function**.
>
> ## Basic idea
>
> Given a key, the hash map computes a number called a **hash**:
>
> $$
> h = \text{hash}(\text{key})
> $$
>
> This hash is then used to decide where the key–value pair should be stored in an internal array.
>
> For example, if storing
>
> $$
> (\text{"apple"}, 5), \quad (\text{"banana"}, 8)
> $$
>
> the hash map can quickly find the value associated with $\text{"apple"}$ by hashing the key $\text{"apple"}$ and going to the corresponding location.
>
> ## Why it is useful
>
> A hash map is designed so that, on average,
>
> - lookup is $O(1)$
> - insertion is $O(1)$
> - deletion is $O(1)$
>
> This makes it very efficient for tasks such as:
>
> - counting frequencies
> - caching results
> - implementing dictionaries or symbol tables
> - indexing data by unique identifiers
>
> ## Collision handling
>
> Different keys can sometimes produce the same hash index. This is called a **collision**.
>
> If
>
> $$
> \text{hash}(k_1) = \text{hash}(k_2)
> $$
>
> for two different keys $k_1 \ne k_2$, the hash map must handle this. Common methods are:
>
> ### 1. Chaining
> Each array position stores a list of entries that hash to that index.
>
> ### 2. Open addressing
> If a spot is occupied, the hash map probes other locations according to a rule.
>
> ## Example
>
> Suppose the table has size $10$, and the index is computed by
>
> $$
> \text{index} = \text{hash}(\text{key}) \bmod 10
> $$
>
> If
>
> $$
> \text{hash}(\text{"cat"}) = 42
> $$
>
> then
>
> $$
> 42 \bmod 10 = 2
> $$
>
> so the pair for $\text{"cat"}$ is stored at index $2$.
>
> ## Summary
>
> A hash map is a structure that maps keys to values using hashing, giving very fast average-time access. It is one of the most common and important data structures in programming.
