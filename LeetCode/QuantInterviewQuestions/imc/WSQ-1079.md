> [!example] Question 1079 · IMC
> ## Software Developer Interview

In a 2D array of integers, adjacent positions (vertically or horizontally) are considered part of the same 'country' if they contain the same integer. Given a 2D array of integers, compute the number of distinct countries in the array.

[Source](https://www.thewallstreetquants.com/ebook#p=1080)

> [!success]- Solution (Click to expand)
> ## Solution
>
> Treat the array as a grid graph:
>
> - Each cell is a node.
> - Two cells are connected if they are adjacent vertically or horizontally and contain the same integer.
>
> Then each **country** is exactly one connected component of equal-valued cells.  
> So the problem reduces to counting connected components in the grid.
>
> ### Approach
>
> Scan every cell in the array.  
> Whenever an unvisited cell is found, it starts a new country. From that cell, perform a graph traversal—either **Depth-First Search** or **Breadth-First Search**—to mark all cells in the same country as visited.
>
> Each such traversal counts as one distinct country.
>
> ### Algorithm
>
> Let the grid have $R$ rows and $C$ columns.
>
> 1. Create a boolean array `visited` of size $R \times C$, initially all false.
> 2. Initialize `count = 0`.
> 3. For each cell $(r, c)$:
>    - If it has not been visited:
>      - Increment `count`.
>      - Run DFS/BFS from $(r, c)$, visiting all cells reachable through up/down/left/right moves that have the same value as `grid[r][c]`.
> 4. Return `count`.
>
> ### DFS description
>
> From a starting cell $(r, c)$ with value $v$:
>
> - Mark $(r, c)$ as visited.
> - For each of the four neighbors:
>   - $(r-1, c)$, $(r+1, c)$, $(r, c-1)$, $(r, c+1)$
> - If the neighbor is inside the grid, unvisited, and its value is also $v$, continue DFS from that neighbor.
>
> ### Correctness
>
> Each traversal starts from one unvisited cell and visits exactly all cells in its connected component of equal values:
>
> - It never crosses into a different integer value.
> - It explores all possible vertical/horizontal same-valued neighbors.
>
> Thus:
>
> - Every country is counted once, when its first unvisited cell is encountered.
> - No country is counted more than once, because all its cells are marked visited during that traversal.
>
> Therefore, the algorithm returns exactly the number of distinct countries.
>
> ### Complexity
>
> Each cell is visited once, and each adjacency is checked a constant number of times.
>
> - Time: $O(RC)$
> - Space: $O(RC)$ for the visited array, plus recursion/queue space in the worst case
>
> ### Reference implementation
>
> ```python
> def count_countries(grid):
>     if not grid or not grid[0]:
>         return 0
>
>     rows, cols = len(grid), len(grid[0])
>     visited = [[False] * cols for _ in range(rows)]
>
>     def dfs(r, c, value):
>         if r < 0 or r >= rows or c < 0 or c >= cols:
>             return
>         if visited[r][c] or grid[r][c] != value:
>             return
>
>         visited[r][c] = True
>
>         dfs(r - 1, c, value)
>         dfs(r + 1, c, value)
>         dfs(r, c - 1, value)
>         dfs(r, c + 1, value)
>
>     count = 0
>
>     for r in range(rows):
>         for c in range(cols):
>             if not visited[r][c]:
>                 count += 1
>                 dfs(r, c, grid[r][c])
>
>     return count
> ```
>
> ### Final answer
>
> Use a flood-fill traversal such as DFS or BFS to count connected components of equal-valued cells under $4$-directional adjacency. The number of such connected components is the number of distinct countries, and it can be computed in $O(RC)$ time.
