> [!example] Question 1103 · IMC
> ## Software Developer Intern Interview

Write a function that takes an integer array as input and returns a boolean indicating whether the array contains any duplicate values.

[Source](https://www.thewallstreetquants.com/ebook#p=1104)

> [!success]- Solution (Click to expand)
> ```python
> def contains_duplicate(nums):
>     seen = set()
>     for x in nums:
>         if x in seen:
>             return True
>         seen.add(x)
>     return False
> ```
>
> To determine whether an integer array contains duplicates, scan through the array while storing previously seen values in a set.
>
> - If an element is already in the set, then a duplicate exists, so return `True`.
> - If the scan finishes without finding any repeated element, return `False`.
>
> This runs in:
>
> - Time: $O(n)$
> - Space: $O(n)$
>
> An even shorter equivalent version is:
>
> ```python
> def contains_duplicate(nums):
>     return len(nums) != len(set(nums))
> ```
