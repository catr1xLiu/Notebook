What is a race condition?

[Source](https://www.thewallstreetquants.com/ebook#p=1092)

> [!success]- Solution (Click to expand)
> A **race condition** is a bug that happens when multiple threads or processes access and modify shared data at the same time, and the program’s result depends on the unpredictable order or timing of those operations.
>
> For example, if two threads both do $x = x + 1$ on the same variable simultaneously, one update can be lost.
>
> Race conditions are typically prevented using synchronization mechanisms such as **locks**, **mutexes**, **semaphores**, or **atomic operations**.
