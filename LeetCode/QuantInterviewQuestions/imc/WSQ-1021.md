> ## 1. Longest possible valid password in a given string
>
> A password is valid if:
>
> - it consists only of alphanumeric characters,
> - it contains an even number of letters,
> - it contains an odd number of digits.
>
> Given a string of space-separated tokens, the task is to find the length of the longest valid password.
>
> ### Approach
>
> Split the string into words and test each word:
>
> - if any character is not alphanumeric, discard it;
> - count letters and digits;
> - if the number of letters is even and the number of digits is odd, it is valid.
>
> Track the maximum length among all valid words.
>
> ### Python implementation
>
> ```python
> def longest_password(S):
>     best = -1
>     
>     for word in S.split():
>         if not word.isalnum():
>             continue
>         
>         letters = sum(c.isalpha() for c in word)
>         digits = sum(c.isdigit() for c in word)
>         
>         if letters % 2 == 0 and digits % 2 == 1:
>             best = max(best, len(word))
>     
>     return best
> ```
>
> ### Example
>
> For
>
> ```python
> S = "test 5 a0A pass007 ?xy1"
> ```
>
> Check each token:
>
> - `"test"`: $4$ letters, $0$ digits $\rightarrow$ digits not odd;
> - `"5"`: $0$ letters, $1$ digit $\rightarrow$ valid, length $1$;
> - `"a0A"`: $2$ letters, $1$ digit $\rightarrow$ valid, length $3$;
> - `"pass007"`: $4$ letters, $3$ digits $\rightarrow$ valid, length $7$;
> - `"?xy1"`: not alphanumeric $\rightarrow$ invalid.
>
> Hence the answer is $7$.

> ## 2. Total number of stops an elevator takes to serve $X$ people
>
> Assume:
>
> - the elevator starts at floor $0$,
> - each person wants to go to one destination floor,
> - the elevator can carry at most $X$ people per trip if capacity is the limiting parameter,
> - each trip goes up to deliver passengers and then returns to floor $0$,
> - a stop is counted whenever the elevator halts at a floor, including return to floor $0$.
>
> A common formulation gives:
>
> - an array $A$ of passenger weights,
> - an array $B$ of destination floors,
> - capacity constraints:
>   - at most $X$ people,
>   - total weight at most $Y$.
>
> The goal is to partition passengers, in order, into trips satisfying both constraints. For each trip, the number of stops equals:
>
> $$
> \text{number of distinct destination floors in that trip} + 1
> $$
>
> where the extra $1$ is for returning to floor $0$.
>
> ### Greedy approach
>
> Process passengers in order:
>
> - add as many people as possible to the current trip without violating:
>   - passenger count limit,
>   - total weight limit;
> - count the distinct destination floors for that trip;
> - add $1$ for the return to ground floor;
> - repeat with the remaining passengers.
>
> ### Python implementation
>
> ```python
> def elevator_stops(A, B, M, X, Y):
>     n = len(A)
>     i = 0
>     total_stops = 0
>     
>     while i < n:
>         weight = 0
>         count = 0
>         floors = set()
>         
>         while i < n and count < X and weight + A[i] <= Y:
>             weight += A[i]
>             count += 1
>             floors.add(B[i])
>             i += 1
>         
>         total_stops += len(floors) + 1
>     
>     return total_stops
> ```
>
> ### Example
>
> Let
>
> ```python
> A = [60, 80, 40]
> B = [2, 3, 5]
> M = 5
> X = 2
> Y = 200
> ```
>
> - First trip: persons $1$ and $2$,
>   destination floors $\{2, 3\}$, so stops $= 2 + 1 = 3$.
> - Second trip: person $3$,
>   destination floors $\{5\}$, so stops $= 1 + 1 = 2$.
>
> Total stops:
>
> $$
> 3 + 2 = 5
> $$
>
> Hence the answer is $5$.

> ## 3. Number of unique countries in a $2$D matrix
>
> Suppose the matrix contains country labels, and we want the number of distinct labels appearing in it.
>
> ### Approach
>
> Traverse all entries and insert them into a set. Since a set stores only unique values, the final set size is the number of unique countries.
>
> ### Python implementation
>
> ```python
> def unique_countries(matrix):
>     seen = set()
>     
>     for row in matrix:
>         for country in row:
>             seen.add(country)
>     
>     return len(seen)
> ```
>
> ### Example
>
> For
>
> ```python
> matrix = [
>     ["US", "IN", "US"],
>     ["FR", "IN", "DE"],
>     ["DE", "BR", "FR"]
> ]
> ```
>
> The distinct countries are
>
> $$
> \{\text{US}, \text{IN}, \text{FR}, \text{DE}, \text{BR}\}
> $$
>
> So the number of unique countries is
>
> $$
> 5
> $$
>

> ## Final answers
>
> 1. The longest valid password can be found by checking each token for alphanumeric content, then verifying:
>    - even number of letters,
>    - odd number of digits,
>    and returning the maximum valid length, or $-1$ if none exists.
>
> 2. The total number of elevator stops is computed trip by trip as:
>
> $$
> \sum (\text{distinct destination floors in trip} + 1)
> $$
>
> using a greedy grouping under the passenger-count and weight constraints.
>
> 3. The number of unique countries in a $2$D matrix is the size of the set of all matrix entries:
>
> $$
> \left| \{ \text{all entries in the matrix} \} \right|
> $$
