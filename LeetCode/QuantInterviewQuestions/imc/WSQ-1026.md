> [!example] Question 1026 · IMC
> ## Software Developer Interview

Given a binary tree, return all nodes whose values are greater than those of all their ancestors (i.e., nodes that are visible from the root).

[Source](https://www.thewallstreetquants.com/ebook#p=1027)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A node is **visible** if its value is strictly greater than the value of every node on the path from the root to its parent.  
> Thus, while traversing the tree, it suffices to keep track of the **maximum value seen so far** among the ancestors.
>
> ### Approach
>
> Perform a depth-first traversal of the tree.
>
> For each node:
>
> - If its value is greater than the current maximum along the path, then it is visible.
> - Update the path maximum to
>   $$\max(\text{current\_max}, \text{node.val})$$
>   before exploring its children.
>
> This ensures each node is checked exactly once.
>
> ### Algorithm
>
> Let $\text{dfs}(node, maxSoFar)$ denote the recursive procedure.
>
> 1. If $node$ is null, return.
> 2. If $node.val > maxSoFar$, add $node$ to the answer.
> 3. Recurse on the left child with updated maximum.
> 4. Recurse on the right child with updated maximum.
>
> Initialize the traversal at the root with $maxSoFar = -\infty$.
>
> ### Correctness
>
> We prove that the algorithm returns exactly the visible nodes.
>
> Consider any node $u$.
>
> - During the traversal, $maxSoFar$ passed to $u$ equals the maximum value among all ancestors of $u$.
> - Therefore, $u$ is added to the answer exactly when
>   $$u.val > maxSoFar,$$
>   which is precisely the definition of being visible.
>
> Since every node is visited once and tested against the maximum of its ancestors, the algorithm returns all and only the visible nodes.
>
> ### Complexity
>
> Let $n$ be the number of nodes.
>
> - Time complexity: $$O(n)$$
> - Space complexity:
>   - $$O(h)$$ recursive stack, where $h$ is the height of the tree
>   - worst case $$O(n)$$ for a skewed tree
>
> ### Reference Implementation
>
> ```python
> def visible_nodes(root):
>     result = []
>
>     def dfs(node, max_so_far):
>         if not node:
>             return
>
>         if node.val > max_so_far:
>             result.append(node)
>
>         new_max = max(max_so_far, node.val)
>         dfs(node.left, new_max)
>         dfs(node.right, new_max)
>
>     dfs(root, float('-inf'))
>     return result
> ```
>
> ### Final Answer
>
> Traverse the tree with depth-first search while carrying the maximum ancestor value seen so far; a node is visible exactly when its value is greater than that maximum. This yields an $$O(n)$$ solution.
