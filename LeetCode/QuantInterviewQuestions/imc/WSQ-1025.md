> [!example] Question 1025 · IMC
> ## Software Developer Interview

People are waiting for an elevator in a hotel that has floors numbered 0 to M. The elevator has a limit of X people and a weight limit of Y. There are N people standing in a queue at the ground floor. You are given two arrays: A\[N\], where each element is the weight of a person, and B\[N\], where each element is the floor each person wants to go to. The elevator goes up, stopping at each requested floor, then returns to the ground floor. Write a solution to determine how many times the elevator will stop.

> [!success]- Solution (Click to expand)
> ## Solution
>
> The elevator loads passengers strictly in queue order, taking as many consecutive people from the front of the queue as it can fit on each trip, subject to both constraints:
>
> - at most $X$ people,
> - total weight at most $Y$.
>
> For each trip:
>
> 1. take the longest prefix of the remaining queue that satisfies both limits,
> 2. count how many **distinct destination floors** appear among those passengers,
> 3. add one more stop for the return to floor $0$.
>
> The total number of elevator stops is the sum of these values over all trips, and simulating this loading process directly gives the answer.
>
> ## Algorithm
>
> Let $i$ be the index of the first person not yet served.
>
> While $i < N$:
>
> - start a new trip,
> - set passenger count $=0$, total weight $=0$, and set of visited floors $=\varnothing$,
> - while $i<N$ and passenger count $<X$ and total weight $+A[i]\le Y$: load person $i$ by adding $A[i]$ to total weight, adding $B[i]$ to the set of floors, and incrementing both passenger count and $i$,
> - after loading, this trip contributes $|\text{floors}|+1$ stops, since the elevator stops once at each distinct requested floor and once more when it returns to floor $0$.
>
> Accumulate the contribution over all trips.
>
> ## Complexity
>
> Let $N$ be the number of people.
>
> - Each person is processed exactly once.
> - Inserting a destination floor into a hash set is $O(1)$ on average.
>
> Therefore:
>
> - Time complexity: $O(N)$ average
> - Space complexity: $O(\min(X,M))$ for the set of floors held during one trip
>
> ## Pseudocode
>
> ```text
> function elevatorStops(A, B, X, Y):
>     n = length(A)
>     i = 0
>     totalStops = 0
>
>     while i < n:
>         count = 0
>         weight = 0
>         floors = empty set
>
>         while i < n and count < X and weight + A[i] <= Y:
>             weight = weight + A[i]
>             floors.add(B[i])
>             count = count + 1
>             i = i + 1
>
>         totalStops = totalStops + size(floors) + 1
>
>     return totalStops
> ```
>
> ## Example
>
> Let
>
> $$
> A = [60, 80, 40, 40], \qquad B = [2, 3, 5, 3], \qquad X = 2,\quad Y = 200.
> $$
>
> ### Trip 1
>
> Take the first two people: weights $60+80=140\le 200$, floors $\{2,3\}$. Stops: $2+1=3$.
>
> ### Trip 2
>
> Take the next two people: weights $40+40=80\le 200$, floors $\{5,3\}$. Stops: $2+1=3$.
>
> Total stops: $3+3=6$.
>
> ## Final answer
>
> The number of elevator stops is obtained by simulating the loading process, repeatedly taking the longest prefix of the remaining queue satisfying
>
> $$
> \text{people} \le X \quad\text{and}\quad \text{total weight} \le Y,
> $$
>
> and for each trip adding the number of distinct destination floors in that trip plus $1$. This can be computed in $O(N)$ time.
