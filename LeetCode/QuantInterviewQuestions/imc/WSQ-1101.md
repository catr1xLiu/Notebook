> [!example] Question 1101 · IMC
> ## Software Engineer Intern Interview

Implement a stack data structure with an additional method increment(k, v), which increments the bottom k elements of the stack by the value v.

[Source](https://www.thewallstreetquants.com/ebook#p=1102)

> [!success]- Solution (Click to expand)
> ## Approach
>
> Implement a stack that supports the usual stack operations together with an additional operation:
>
> - $\text{increment}(k, v)$: add $v$ to each of the bottom $k$ elements.
>
> A direct implementation of $\text{increment}(k, v)$ would require updating up to $k$ elements each time, which is $O(k)$. A more efficient design achieves:
>
> - $\text{push}$: $O(1)$
> - $\text{pop}$: $O(1)$
> - $\text{increment}(k, v)$: $O(1)$
>
> The key idea is to store pending increments separately.
>
> ---
>
> ## Data Structure
>
> Maintain two arrays:
>
> 1. $\text{stack}$: stores the actual pushed values.
> 2. $\text{inc}$: where $\text{inc}[i]$ stores an increment that should be applied to all elements from the bottom up to index $i$.
>
> If the stack has size $n$, then the top element is at index $n-1$.
>
> ---
>
> ## Operations
>
> ### 1. $\text{push}(x)$
>
> Append $x$ to $\text{stack}$ and append $0$ to $\text{inc}$.
>
> ### 2. $\text{increment}(k, v)$
>
> Let
>
> $$
> i = \min(k, \text{size}) - 1
> $$
>
> If $i \ge 0$, do:
>
> $$
> \text{inc}[i] \mathrel{+}= v
> $$
>
> This means that the bottom $\min(k, \text{size})$ elements should eventually receive $v$.
>
> ### 3. $\text{pop}()$
>
> Suppose the top index is $i = \text{size} - 1$.
>
> The value returned is:
>
> $$
> \text{stack}[i] + \text{inc}[i]
> $$
>
> Before removing it, propagate its pending increment downward:
>
> $$
> \text{inc}[i-1] \mathrel{+}= \text{inc}[i]
> $$
>
> for $i > 0$.
>
> Then remove the top entries from both arrays.
>
> This propagation ensures that increments meant for lower elements are preserved.
>
> ---
>
> ## Python Implementation
>
> ```python
> class CustomStack:
>     def __init__(self):
>         self.stack = []
>         self.inc = []
>
>     def push(self, x):
>         self.stack.append(x)
>         self.inc.append(0)
>
>     def pop(self):
>         if not self.stack:
>             return None
>
>         i = len(self.stack) - 1
>         if i > 0:
>             self.inc[i - 1] += self.inc[i]
>
>         val = self.stack.pop() + self.inc.pop()
>         return val
>
>     def increment(self, k, v):
>         i = min(k, len(self.stack)) - 1
>         if i >= 0:
>             self.inc[i] += v
> ```
>
> ---
>
> ## Example
>
> Execute the following operations:
>
> ```python
> s = CustomStack()
> s.push(1)
> s.push(2)
> s.push(3)
> s.increment(2, 100)
> print(s.pop())
> print(s.pop())
> print(s.pop())
> ```
>
> ### State after pushes
>
> $$
> \text{stack} = [1, 2, 3], \qquad \text{inc} = [0, 0, 0]
> $$
>
> ### After $\text{increment}(2, 100)$
>
> Update:
>
> $$
> \text{inc}[1] \mathrel{+}= 100
> $$
>
> so
>
> $$
> \text{inc} = [0, 100, 0]
> $$
>
> ### First $\text{pop}()$
>
> Top index is $2$:
>
> - return
>
> $$
> 3 + 0 = 3
> $$
>
> - propagate $\text{inc}[2] = 0$ to $\text{inc}[1]$
>
> State becomes:
>
> $$
> \text{stack} = [1, 2], \qquad \text{inc} = [0, 100]
> $$
>
> ### Second $\text{pop}()$
>
> Top index is $1$:
>
> - return
>
> $$
> 2 + 100 = 102
> $$
>
> - propagate $100$ to $\text{inc}[0]$
>
> State becomes:
>
> $$
> \text{stack} = [1], \qquad \text{inc} = [100]
> $$
>
> ### Third $\text{pop}()$
>
> Top index is $0$:
>
> - return
>
> $$
> 1 + 100 = 101
> $$
>
> Thus the output is:
>
> ```python
> 3
> 102
> 101
> ```
>
> ---
>
> ## Complexity
>
> Let $n$ be the number of elements currently in the stack.
>
> - $\text{push}$: $O(1)$
> - $\text{pop}$: $O(1)$
> - $\text{increment}(k, v)$: $O(1)$
> - Space: $O(n)$
>
> ---
>
> ## Final Answer
>
> A stack with an efficient $\text{increment}(k, v)$ operation can be implemented by storing deferred increments in a parallel array and propagating them during $\text{pop}$. The implementation above supports all operations in $O(1)$ time.
