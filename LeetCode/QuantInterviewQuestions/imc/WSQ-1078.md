> [!example] Question 1078 · IMC
> ## Software Engineer Interview

Given a string, find the longest possible valid password, where a valid password is defined by specific rules (such as containing at least one uppercase letter, one lowercase letter, and one digit).

[Source](https://www.thewallstreetquants.com/ebook#p=1079)

> [!success]- Solution (Click to expand)
> # Longest Valid Password
>
> A run of the input string is defined as a maximal substring consisting only of alphanumeric characters; any space, punctuation mark, or other symbol breaks a run. Such a run is a valid password precisely when it contains at least one uppercase letter, at least one lowercase letter, and at least one digit. Given a string $S$, we want the length of the longest valid run. If no run of $S$ satisfies all three conditions, the answer is $-1$.
>
> ## Approach
>
> Non-alphanumeric characters can never appear inside a password, so they act purely as separators between candidate runs. Scanning $S$ once from left to right, we split it into maximal runs of consecutive alphanumeric characters and test each one directly.
>
> The algorithm is:
>
> 1. Scan the string from left to right, skipping any non-alphanumeric character.
> 2. On finding an alphanumeric character, extend the run rightward as far as possible while characters remain alphanumeric, tracking whether an uppercase letter, a lowercase letter, and a digit have each appeared.
> 3. When the run ends, check whether all three flags are set; if so, compare its length against the best length found so far.
> 4. Resume scanning immediately after the run.
>
> Each character of $S$ is examined exactly once, either as part of a run or as a separator, so the whole scan is linear in the length of $S$.
>
> ## Solution
>
> Let $S$ be the input string of length $N$, and let $w$ range over the maximal alphanumeric runs of $S$. For a run $w$, define:
>
> - $u(w) = 1$ if $w$ contains an uppercase letter, else $u(w) = 0$,
> - $\ell(w) = 1$ if $w$ contains a lowercase letter, else $\ell(w) = 0$,
> - $d(w) = 1$ if $w$ contains a digit, else $d(w) = 0$.
>
> The run $w$ is a valid password exactly when
>
> $$
> u(w) = \ell(w) = d(w) = 1.
> $$
>
> The answer is
>
> $$
> \max\{\, |w| : w \text{ is a run of } S \text{ with } u(w)=\ell(w)=d(w)=1 \,\},
> $$
>
> or $-1$ if no run of $S$ satisfies this condition.
>
> ## Example
>
> Consider the string
>
> $$
> S = \text{"hello,WORLD123 Ab1Cd2Ef xyZ9!!"}
> $$
>
> Splitting on the non-alphanumeric characters (the comma, the space, and the exclamation marks) gives four runs:
>
> - $\text{"hello"}$: only lowercase letters, no uppercase and no digit, invalid.
> - $\text{"WORLD123"}$: uppercase letters and digits, but no lowercase letter, invalid.
> - $\text{"Ab1Cd2Ef"}$: contains uppercase ($A,C,E$), lowercase ($b,d,f$), and digits ($1,2$), valid, length $8$.
> - $\text{"xyZ9"}$: contains lowercase ($x,y$), uppercase ($Z$), and a digit ($9$), valid, length $4$.
>
> The longest valid run is $\text{"Ab1Cd2Ef"}$, so the answer for this string is $8$.
>
> ## Complexity
>
> If $N$ is the length of $S$, the algorithm makes a single pass over the string, so the running time is
>
> $$
> O(N),
> $$
>
> and the extra space used, beyond storing the input, is
>
> $$
> O(1).
> $$
>
> ## Implementation
>
> ```python
> def longest_valid_password(s: str) -> int:
>     n = len(s)
>     best = -1
>     i = 0
>     while i < n:
>         if not s[i].isalnum():
>             i += 1
>             continue
>         j = i
>         has_upper = has_lower = has_digit = False
>         while j < n and s[j].isalnum():
>             c = s[j]
>             if c.isupper():
>                 has_upper = True
>             elif c.islower():
>                 has_lower = True
>             elif c.isdigit():
>                 has_digit = True
>             j += 1
>         if has_upper and has_lower and has_digit:
>             best = max(best, j - i)
>         i = j
>     return best
> ```
>
> ## Final answer
>
> Scan the string once, splitting it into maximal runs of alphanumeric characters. For each run, check whether it contains at least one uppercase letter, one lowercase letter, and one digit; among the runs that qualify, the answer is the length of the longest one, or $-1$ if no run qualifies. This runs in $O(N)$ time and $O(1)$ extra space.
