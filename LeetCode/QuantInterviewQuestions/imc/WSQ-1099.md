> [!example] Question 1099 · IMC
> ## Software Engineering Intern Interview

1) Given a chessboard size, a knight's starting position, an end position, and a bishop's position, find the minimum number of moves required for the knight to reach the end position. The knight cannot move to any square that the bishop is attacking, unless it captures the bishop on that square.
2) Implement a stack with the following functions: pop, push, inc, isEmpty, and peek. The inc function should increase the first n elements of the stack by a value i.

> [!success]- Solution (Click to expand)
> ## 1) Minimum knight moves with a blocking bishop
>
> ### Approach
>
> Model the chessboard as an unweighted graph:
>
> - Each square is a vertex.
> - An edge connects two squares if a knight can move between them in one move.
> - Squares attacked by the bishop are forbidden, except the bishop’s own square, which the knight may enter in order to capture the bishop.
>
> Since every legal knight move has equal cost, the minimum number of moves is found by **breadth-first search** (BFS).
>
> ---
>
> ### Step 1: Mark the bishop’s attacked squares
>
> Let the board be of size $N \times N$, with coordinates $(r,c)$ where $0 \le r,c < N$.
>
> If the bishop is at $(b_r,b_c)$, then it attacks exactly the squares on its diagonals:
>
> $$
> |r-b_r| = |c-b_c|
> $$
>
> excluding its own square $(b_r,b_c)$.
>
> Thus, a square $(r,c)$ is forbidden if
>
> $$
> (r,c) \ne (b_r,b_c) \quad \text{and} \quad |r-b_r|=|c-b_c|.
> $$
>
> ---
>
> ### Step 2: Knight moves
>
> A knight from $(r,c)$ can move to any of the $8$ possible positions:
>
> $$
> (r\pm 2, c\pm 1), \qquad (r\pm 1, c\pm 2).
> $$
>
> Only moves satisfying all of the following are allowed:
>
> 1. The destination lies inside the board.
> 2. The destination is not attacked by the bishop, unless it is the bishop’s square itself.
>
> ---
>
> ### Step 3: BFS
>
> Start BFS from the knight’s starting square.
>
> - Use a queue storing pairs $\big((r,c), d\big)$, where $d$ is the distance from the start.
> - Maintain a visited array.
> - For each square, try all $8$ knight moves.
> - The first time the end square is reached, the current distance is the minimum number of moves.
>
> If the BFS completes without reaching the target, the answer is $-1$.
>
> ---
>
> ### Correctness
>
> BFS explores positions in nondecreasing order of number of moves. Since each knight move costs exactly $1$, the first time the end square is dequeued or discovered, the path found uses the fewest moves possible among all legal paths. Forbidden bishop-attacked squares are never entered, except possibly the bishop’s own square, so every explored path is valid. Therefore BFS returns exactly the minimum legal number of knight moves.
>
> ---
>
> ### Time and space complexity
>
> There are at most $N^2$ squares, and each square has at most $8$ outgoing knight moves.
>
> - Time: $O(N^2)$
> - Space: $O(N^2)$
>
> ---
>
> ### Implementation
>
> ```python
> from collections import deque
>
> def min_knight_moves(board_size, start, end, bishop):
>     n = board_size
>     sr, sc = start
>     er, ec = end
>     br, bc = bishop
>
>     def inside(r, c):
>         return 0 <= r < n and 0 <= c < n
>
>     def attacked_by_bishop(r, c):
>         return (r, c) != (br, bc) and abs(r - br) == abs(c - bc)
>
>     # If start itself is on an attacked square, the knight cannot stand there initially.
>     # If needed, this can be adjusted by problem convention.
>     if attacked_by_bishop(sr, sc):
>         return -1
>
>     moves = [
>         (2, 1), (2, -1), (-2, 1), (-2, -1),
>         (1, 2), (1, -2), (-1, 2), (-1, -2)
>     ]
>
>     q = deque([(sr, sc, 0)])
>     visited = [[False] * n for _ in range(n)]
>     visited[sr][sc] = True
>
>     while q:
>         r, c, d = q.popleft()
>
>         if (r, c) == (er, ec):
>             return d
>
>         for dr, dc in moves:
>             nr, nc = r + dr, c + dc
>             if not inside(nr, nc):
>                 continue
>             if visited[nr][nc]:
>                 continue
>             if attacked_by_bishop(nr, nc):
>                 continue
>
>             visited[nr][nc] = True
>             q.append((nr, nc, d + 1))
>
>     return -1
> ```

> ## 2) Stack with `push`, `pop`, `inc`, `isEmpty`, and `peek`
>
> ### Approach
>
> A stack supports insertion and removal at the top:
>
> - `push(x)`: add $x$ to the top
> - `pop()`: remove and return the top element
> - `peek()`: return the top element without removing it
> - `isEmpty()`: test whether the stack has no elements
> - `inc(n, i)`: increase the **bottom** first $n$ elements by $i$
>
> A direct implementation of `inc(n, i)` would modify up to $n$ elements, costing $O(n)$. A more efficient design supports all operations in $O(1)$ amortized time by using a lazy increment array.
>
> ---
>
> ### Efficient idea for `inc`
>
> Maintain:
>
> - `stack`: the actual values
> - `add`: an auxiliary array where `add[k]` stores an increment to be applied to all elements from the bottom up to index $k$
>
> If `inc(n, i)` is called, let
>
> $$
> k = \min(n, \text{size of stack}) - 1.
> $$
>
> Then add $i$ only to `add[k]`.
>
> When popping the top element at index $k$:
>
> - its true value is
>
> $$
> \text{stack}[k] + \text{add}[k].
> $$
>
> - before removing it, propagate its pending increment downward:
>
> $$
> \text{add}[k-1] \mathrel{+}= \text{add}[k].
> $$
>
> This ensures that lower elements retain the increment they should still receive.
>
> ---
>
> ### Example
>
> Suppose the stack is
>
> $$
> [1,2,3,4]
> $$
>
> and `inc(3, 10)` is called. Then the bottom three elements should become
>
> $$
> [11,12,13,4].
> $$
>
> Instead of updating all three, store:
>
> $$
> \text{add}[2] = 10.
> $$
>
> If `pop()` removes $4$, nothing changes for the others.  
> If `pop()` removes $3$, then its value is $3+10=13$, and the increment $10$ is pushed down to index $1$, so the remaining stack behaves as
>
> $$
> [11,12].
> $$
>
> ---
>
> ### Implementation
>
> ```python
> class CustomStack:
>     def __init__(self):
>         self.stack = []
>         self.add = []
>
>     def isEmpty(self):
>         return len(self.stack) == 0
>
>     def push(self, x):
>         self.stack.append(x)
>         self.add.append(0)
>
>     def pop(self):
>         if self.isEmpty():
>             return None
>
>         k = len(self.stack) - 1
>         inc = self.add[k]
>
>         if k > 0:
>             self.add[k - 1] += inc
>
>         self.add.pop()
>         return self.stack.pop() + inc
>
>     def peek(self):
>         if self.isEmpty():
>             return None
>         k = len(self.stack) - 1
>         return self.stack[k] + self.add[k]
>
>     def inc(self, n, i):
>         if self.isEmpty():
>             return
>         k = min(n, len(self.stack)) - 1
>         if k >= 0:
>             self.add[k] += i
> ```
>
> ---
>
> ### Complexity
>
> For this implementation:
>
> - `push`: $O(1)$
> - `pop`: $O(1)$
> - `peek`: $O(1)$
> - `isEmpty`: $O(1)$
> - `inc`: $O(1)$
>
> Space usage is $O(m)$ for a stack containing $m$ elements.
>
> ---
>
> ## Final answer
>
> 1. The minimum knight moves problem is solved by **BFS** on the board, treating bishop-attacked squares as blocked except for the bishop’s own square, which may be entered to capture it. The time complexity is $O(N^2)$.
>
> 2. The stack can be implemented efficiently with an auxiliary lazy-increment array so that `push`, `pop`, `inc`, `peek`, and `isEmpty` all run in $O(1)$ time.
