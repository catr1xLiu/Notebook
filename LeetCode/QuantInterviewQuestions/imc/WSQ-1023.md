> [!example] Question 1023 · IMC
> ## Software Developer Interview

What is the difference between a Set and a List?

[Source](https://www.thewallstreetquants.com/ebook#p=1024)

> [!success]- Solution (Click to expand)
> A **List** and a **Set** are both collections of elements, but they differ in two fundamental ways:
>
> ## 1. Order
>
> - A **List** preserves the order of elements.
> - A **Set** does not typically guarantee any order.
>
> Example:
>
> - List: $[a, b, a]$
> - Set: $\{a, b\}$
>
> In the list, the position of each element matters. In the set, only membership matters.
>
> ## 2. Duplicates
>
> - A **List** allows duplicate elements.
> - A **Set** does not allow duplicates.
>
> So if an element appears multiple times:
>
> - In a list, all occurrences are kept.
> - In a set, repeated occurrences are merged into one.
>
> ## Mathematical viewpoint
>
> A **set** is defined purely by which elements belong to it. For example,
>
> $$
> \{1,2,3\} = \{3,2,1\}.
> $$
>
> Order is irrelevant.
>
> A **list** is an ordered sequence. Thus,
>
> $$
> [1,2,3] \neq [3,2,1].
> $$
>
> Also,
>
> $$
> [1,1,2] \neq [1,2],
> $$
>
> while as sets,
>
> $$
> \{1,1,2\} = \{1,2\}.
> $$
>
> ## Practical summary
>
> - Use a **List** when order matters or when duplicates must be preserved.
> - Use a **Set** when you want only unique elements and care only about whether an element is present.
>
> ## Final answer
>
> A **List** is an **ordered collection that can contain duplicates**, whereas a **Set** is an **unordered collection of unique elements**.
