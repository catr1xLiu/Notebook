> [!example] Question 1066 · IMC
> ## Software Engineer Interview

Complete the function findValuation which returns the expected price of a house using linear interpolation of given data. The function must return the price rounded to the nearest integer. Function signature: findValuation(reqArea: int, area: list of int, price: list of int) -\> int. Constraints: 500 \< reqArea \< 10^5, 500 \< area\[i\] \< 10^5 for all i.

[Source](https://www.thewallstreetquants.com/ebook#p=1067)

> [!success]- Solution (Click to expand)
> ## Approach
>
> Given the areas and sale prices of $n$ historic houses, we estimate the price of a house with requested area $\text{reqArea}$ by linear interpolation between the two known data points that bracket it.
>
> - Pair each house as $(\text{area}[i], \text{price}[i])$ and sort by area.
> - If several houses share the same area, collapse them into a single point whose price is the average of theirs, so each distinct area appears once.
> - Find the two consecutive distinct areas $x_0 \le x_1$ that bracket $\text{reqArea}$.
> - If $\text{reqArea}$ lies before the first point or after the last point, extrapolate using the two nearest distinct points on that side, with the same linear formula.
> - If $\text{reqArea}$ matches a known area exactly, return its (averaged) price directly.
> - Otherwise, interpolate between $(x_0,y_0)$ and $(x_1,y_1)$:
>
> $$
> \text{price} = y_0 + (\text{reqArea}-x_0)\cdot\frac{y_1-y_0}{x_1-x_0}
> $$
>
> - Round the result to the nearest integer before returning it.
>
> ## Code
>
> ```python
> def findValuation(reqArea, area, price):
>     pairs = sorted(zip(area, price))
>     n = len(pairs)
>
>     points = []
>     i = 0
>     while i < n:
>         j = i
>         s, cnt = 0, 0
>         while j < n and pairs[j][0] == pairs[i][0]:
>             s += pairs[j][1]
>             cnt += 1
>             j += 1
>         points.append((pairs[i][0], s / cnt))
>         i = j
>
>     m = len(points)
>     if m == 1:
>         return round(points[0][1])
>
>     if reqArea <= points[0][0]:
>         lo, hi = 0, 1
>     elif reqArea >= points[-1][0]:
>         lo, hi = m - 2, m - 1
>     else:
>         lo, hi = 0, m - 1
>         while hi - lo > 1:
>             mid = (lo + hi) // 2
>             if points[mid][0] <= reqArea:
>                 lo = mid
>             else:
>                 hi = mid
>
>     x0, y0 = points[lo]
>     x1, y1 = points[hi]
>     if reqArea == x0:
>         return round(y0)
>     if reqArea == x1:
>         return round(y1)
>
>     estimate = y0 + (reqArea - x0) * (y1 - y0) / (x1 - x0)
>     return round(estimate)
> ```
>
> ## Notes
>
> - Averaging duplicate areas removes any ambiguity about which historic price to anchor to when multiple houses share an area.
> - The bracket is located with a binary search over the sorted distinct areas, which is valid since the areas are strictly increasing after deduplication.
> - Requests outside the observed range are handled by extrapolating along the line through the two nearest distinct points; a clamped variant (returning the nearest endpoint price instead) uses the same interpolation core, differing only in how the two boundary cases are selected.
> - Overall complexity is $O(n\log n)$ for the sort, with the lookup itself taking $O(\log n)$.
