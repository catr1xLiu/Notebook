> [!example] Question 1067 · IMC
> ## Software Engineer Interview

Is the total number of distinct unsigned 32-bit integers different from the total number of signed 32-bit integers?

[Source](https://www.thewallstreetquants.com/ebook#p=1068)

> [!success]- Solution (Click to expand)
> No. They are the same.
>
> A $32$-bit pattern has exactly $2^{32}$ possible distinct bit strings. The interpretation of those bit strings determines whether the values are considered unsigned or signed, but it does not change how many distinct patterns exist.
>
> - For an **unsigned** $32$-bit integer, the values are
>   $$
>   0 \text{ to } 2^{32}-1,
>   $$
>   so the count is
>   $$
>   2^{32}.
>   $$
>
> - For a **signed** $32$-bit integer using the usual two’s-complement representation, the values are
>   $$
>   -2^{31} \text{ to } 2^{31}-1,
>   $$
>   so the count is
>   $$
>   2^{31} + 2^{31} = 2^{32}.
>   $$
>
> Therefore, the total number of distinct unsigned $32$-bit integers and signed $32$-bit integers is identical:
> $$
> 2^{32} = 4,294,967,296.
> $$
