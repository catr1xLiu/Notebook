> [!example] Question 1082 · IMC
> ## Software Developer Interview

Given a binary tree, return all nodes whose value is greater than that of all their ancestors (i.e., nodes that are visible from the root along any path).

[Source](https://www.thewallstreetquants.com/ebook#p=1083)

> [!success]- Solution (Click to expand)
> ## Solution
>
> A node is **visible** if its value is strictly greater than the value of every node on the path from the root to its parent.  
> This suggests a depth-first traversal in which we keep track of the maximum value seen so far along the current root-to-node path.
>
> ### Approach
>
> For each node, maintain a parameter $m$, the maximum value among its ancestors.
>
> - If the current node’s value is greater than $m$, then the node is visible.
> - Update the running maximum to $\max(m, \text{node.val})$ before visiting its children.
> - Recurse on the left and right subtrees.
>
> This visits each node once, so it is efficient.
>
> ### Algorithm
>
> Let `dfs(node, max_so_far)` do the following:
>
> 1. If `node` is `None`, return.
> 2. If `node.val > max_so_far`, add `node.val` to the result.
> 3. Set  
>    $$
>    \text{new\_max} = \max(\text{max\_so\_far}, \text{node.val})
>    $$
> 4. Recurse on the left and right children with `new_max`.
>
> For the root, since it has no ancestors, it is always visible. We can start with $-\infty$ as the initial maximum.
>
> ### Python Implementation
>
> ```python
> def visible_nodes(root):
>     result = []
>
>     def dfs(node, max_so_far):
>         if not node:
>             return
>
>         if node.val > max_so_far:
>             result.append(node.val)
>
>         new_max = max(max_so_far, node.val)
>         dfs(node.left, new_max)
>         dfs(node.right, new_max)
>
>     dfs(root, float('-inf'))
>     return result
> ```
>
> ### Correctness
>
> The algorithm maintains the invariant that `max_so_far` is the maximum value among all ancestors of the current node.
>
> - If `node.val > max_so_far`, then the current node is greater than every ancestor, so it is visible.
> - Otherwise, some ancestor has value at least as large, so the node is not visible.
>
> Since every node is checked exactly once with the correct ancestor maximum, the algorithm returns exactly all visible nodes.
>
> ### Complexity
>
> Let $n$ be the number of nodes in the tree.
>
> - **Time:** $O(n)$
> - **Space:** $O(h)$ for recursion stack, where $h$ is the height of the tree
>
> ### Final Answer
>
> Traverse the tree with DFS while carrying the maximum ancestor value seen so far; add a node to the answer whenever its value is greater than that maximum. This yields an $O(n)$ solution.
